Exp468 Task 6 — CLI·전체 사전검증·두 private 실행

시작 조건: Task 5 publication/replay/dashboard는 e583672d1924fb580c96ccdf246bfee4fadd651d까지 구현·검토·통합됐다. Step 1~2의 CLI/pipeline 사전검증은 실행할 수 있지만 실제 private 실행 두 번은 별도 사용자 승인 뒤에만 가능하다.

고정 명령

evaluate --output PATH --reviewed-commit LOWER40HEX
inspect --root PATH

evaluate output은 /private/tmp/exp468_task6_private_run1_antigravity와 /private/tmp/exp468_task6_private_run2_antigravity만 허용한다. root는 create-only이고 기존 디렉터리·파일·symlink를 덮어쓰지 않는다. evaluate는 현재 HEAD와 reviewed commit이 같고 worktree가 깨끗한지 확인한다.

evaluate 순서

  1. 고정 root·clean reviewed commit 확인
  2. TRAIN 정상 행을 한 번 load하고 96→140 보간을 한 번 수행
  3. Exp465 C0 authority를 준비하고 공개 blocked folds를 확인
  4. 두 seed×다섯 fold를 seed-major 순서로 score
  5. qualification·decision·Task 5 seven-leaf publication 실행
  6. 방금 만든 root를 retained-input replay inspector로 확인하고 canonical stdout 출력

inspect 경계

inspect는 Task 5의 inspect_result_antigravity를 사용한다. 일곱 leaf의 canonical/hash/schema를 확인하고 보존 raw input으로 C0/S10/C10·qualification·decision을 독립 재계산한다. ECG200 loader, 보간, private pipeline, publisher는 호출하지 않는다.

Step 1~2 완료 조건

  • 정확한 CLI, lowercase 40-hex, 고정 root, seed-major 2×5와 query/fit 크기 검사
  • loader·interpolation·authority·score orchestration·publication·inspect 경계와 launcher의 run1 evaluate→inspect→run2 evaluate→inspect 순서 검사
  • focused 두 번, 전체 Exp468, Exp466 회귀, compileall, codemap validate, diff-check

승인 뒤 실제 실행은 네 명령을 따로 입력하지 않고 launcher의 run_private_sequence_antigravity(reviewed_commit)만 사용한다. 이 helper가 각 단계의 동일 clean commit 확인과 성공 후 state 전이를 적용한다.
