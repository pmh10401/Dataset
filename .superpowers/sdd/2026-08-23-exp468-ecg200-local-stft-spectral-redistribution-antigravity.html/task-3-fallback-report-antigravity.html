불변 선택 계약

  • BackendDecisionAntigravity는 frozen·slots dataclass이며 기존 AccelerationAssessmentAntigravity와 별도다.
  • 가속 gate 통과 decision은 non-NumPy 선택과 eligible, parity_passed, deterministic, speedup>=1.1을 모두 요구한다.
  • 실패 fallback decision은 NumPy 선택, 모든 non-NumPy 후보의 비어 있지 않은 실패 이유, 64자리 lowercase 승인 SHA-256을 요구한다.
  • 승인 SHA가 없으면 실패 assessment를 확정하지 않고 PermissionError를 낸다.
