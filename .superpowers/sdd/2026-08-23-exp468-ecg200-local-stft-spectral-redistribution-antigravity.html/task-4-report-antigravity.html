점수·재현 증거

  • scorer는 checked benchmark JSON과 승인 HTML bytes에서 immutable decision을 복원해 gate_passed=false, fallback_authorized=true, selected_backend=numpy, 승인 SHA를 모두 확인한다. 공개 API에는 backend 선택 인자가 없다.
  • normal과 네 합성 scope는 하나의 combined NumPy query batch로 계산하므로 fit LOO calibration은 하나다. normal·synthetic query는 fit reference에 들어가지 않는다.
  • 점수·raw는 exact float64, mask는 bool, indices는 int64이고 모두 owned C-contiguous read-only다. fit_normal_max_raw_js == max(fit_raw_js)를 강제한다.
  • confirmation은 query_raw>0 and query_raw>fit_max이며 C10은 true 위치에서만 max(C0,S10)이다. false 위치는 C0와 array-equal이다.
  • qualification은 assembler를 호출하지 않고 retained 69×140 input과 exact fold indices에서 C0, 합성 rows, S10 raw/rank/confirmation, C10을 다시 계산한다. C0, fit raw, query raw, rank, confirmation, C10의 여섯 개 독립 변조가 모두 거부된다.
  • AUC는 각 fold의 normal query와 같은 query 행의 change score를 mann_whitney_auc_antigravity(normal, changed) 순서로 비교한다. pooled 또는 mean gate가 없다.

고정 gate와 10-fold fixture

failure reason은 nonfinite_scores, period <0.85, period <=C0, period confirmation 0, level·gradual·amplitude regression, normal confirmation 순서다. 각 단일 경계와 전체 복합 순서를 검사했다. C10 평균이 0.2125여도 나머지 gate를 만족하는 fixture는 이유 없이 통과해 mean gate 부재를 확인했다.

테스트 전용 결정론적 69×140 TRAIN-only stand-in에서 두 seed×다섯 exact blocked folds를 score·replay했다. query 크기 (14,14,14,14,13), fit 크기 (55,55,55,55,56), fold row 10개와 seed당 OOF 69개가 exact하다. 이 비과학 fixture의 결과는 0/10 PASS, seed별 normal confirmation 2, 상태 qualification_failed_blocked_before_private_run이다. 이는 failure path 검사용이며 ECG200 실제 자격 결과가 아니다.
