  • 재해시한 decision, metrics, summary, dashboard snapshot, context 위조와 JSON int/bool 유형 위장을 거부한다.
  • HTML export는 replay만 완료로 표시하고 private/official/TEST/FN/routing은 미완료로 유지한다.
