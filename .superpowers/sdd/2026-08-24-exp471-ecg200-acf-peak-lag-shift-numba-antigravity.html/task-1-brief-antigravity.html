Exp471 Task 1 — 고정 계약·Exp470 authority·code map

역할과 범위

Exp471의 이후 Task가 사용할 고정 config, Exp470 exact authority exports, immutable qualification contracts와 versioned code map을 TDD로 만든다. ACF scorer, runtime assessment, fold scoring, qualification 계산, artifact publication, CLI와 어떤 private/official 실행도 구현하거나 실행하지 않는다.

전역 제약

  • 새 파일 이름은 모두 antigravity를 포함한다.
  • ECG200 TRAIN 정상 69개, 96→140 보간, seeds (20260721, 20261721), blocked fold 5개와 네 합성 변화는 Exp470 authority 그대로다.
  • 방법 순서는 ("C0", "E12", "C12")다.
  • 창은 [0:56], [84:140], ACF 계산 lag는 1..25, peak 후보는 2..24다.
  • median은 짝수일 때 가운데 두 값의 산술평균, peak 동점은 작은 lag, peak 없음은 integer 0이다.
  • production backend는 float64 Numba, fastmath=False, cache=False 하나다. NumPy scorer나 자동 fallback은 없다.
  • MLX는 적격성만 평가하며 Numba authority를 바꾸지 않는다.
  • 절대 AUC 0.85를 gate로 쓰지 않는다.
  • official 실행, TEST/FN 접근, routing과 private 실행 1·2는 금지한다.

Task 1.2–1.3 — RED tests first

production 파일보다 먼저 아래 테스트 파일을 작성한다.

  • experiments/exp471_ecg200_acf_peak_lag_shift_numba_antigravity/tests/test_config_antigravity.py
  • tests/test_contracts_antigravity.py
  • tests/test_predecessor_antigravity.py

테스트는 실제 import/behavior를 검사하며 source-text grep이나 mock을 쓰지 않는다. production package가 없기 때문에 import failure로 RED가 되는 것을 확인하고 report에 명령·실패 출력·예상 이유를 남긴다.

config 테스트는 아래 exact tuple을 한 번에 검증하고 frozen mutation, exact-type aliases, reordered tuples를 거부해야 한다.

seeds=(20260721, 20261721)
folds=5
normal_rows=69
source_width=96
interpolated_width=140
onset=56
warp_factor=1.25
early_start=0
late_start=84
window_length=56
acf_lag_min=1
acf_lag_max=25
peak_lag_min=2
peak_lag_max=24
mad_scale=1.4826
method_order=("C0", "E12", "C12")
change_types=("level_shift", "gradual_drift", "amplitude_scaling", "period_change")
required_speedup=1.1

authority 테스트는 Exp471 exports가 wrapper가 아니라 아래 Exp470 objects와 is identity가 같음을 검증한다.

  • load_ecg200_normal_train_antigravity
  • interpolate_to_140_antigravity
  • primary_rows_antigravity
  • capture_exp465_authority_antigravity
  • score_c0_fold_antigravity

contracts 테스트는 Exp470 contracts의 실제 behavior pattern을 유지하되 이름과 score field를 Exp471/C12로 바꾼다. immutable ordered mappings, exact seed-major 10 rows, non-negative exact-int counts, finite AUC in [0,1], strict bools, label_query_count=0, optional lowercase SHA-256와 failure reason tuple을 검사한다.

Task 1.4 — 최소 구현

다음 production 파일만 만든다.

  • config_antigravity.py: Exp471ConfigAntigravity, exact frozen validation, FROZEN_CONFIG_ANTIGRAVITY.
  • sources_antigravity.py, interpolation_antigravity.py, synthetic_antigravity.py, predecessor_antigravity.py: 대응 Exp470 object의 direct re-export만.
  • contracts_antigravity.py: PairRepairCountsAntigravity, Exp471FoldResultAntigravity, Exp471QualificationAntigravity. Exp470 구조를 사용하고 fold result의 score fields는 c0_per_type_auc와 c12_per_type_auc다. Task 4가 값을 계산·채운다.
  • package와 tests의 __init___antigravity.py를 만들지 않는다. Python package marker가 필요하면 기존 관례의 __init__.py만 허용하며 새 filename 정책 예외를 report에 명시한다.
