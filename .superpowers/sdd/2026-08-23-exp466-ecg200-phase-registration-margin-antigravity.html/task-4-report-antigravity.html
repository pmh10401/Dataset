고정 수식과 불변 조건

점수: method 순서는 정확히 ("C0", "P9", "C9")다. C0는 Task 2 score_c0_fold_antigravity의 출력만 사용하고 byte-exact로 보존한다. P9는 Task 3 score_phase_registration_antigravity의 exact anomaly rank다. C9는 각 scope에서 where(confirmed, maximum(C0, P9), C0)이며 confirmation이 false인 원소는 C0와 byte-identical이다.

소유권: retained train, fit/query indices, original/primary scores, fit/query margins, confirmation 배열을 각각 새 C-contiguous 배열로 복사하고 read-only로 고정한다. Mapping도 proxy로 고정하며 caller input과 memory를 공유하지 않는다.

Qualification: 두 frozen seed × 다섯 fold의 정확한 seed-major key 10개만 허용한다. seed마다 OOF query가 정확히 69개 unique index를 한 번씩 덮어야 한다. 모든 score를 먼저 finite 검사하고, 저장된 train/index/authority에서 C0 input score를 exact replay한다. 동일한 retained input으로 normal과 네 primary scope의 P9 margin/rank/strict confirmation을 재실행하고 C9까지 exact replay한 후에만 AUC와 scalar row를 계산한다.

고정 gate: 유형별 AUC >= 0.85, mean AUC >= 0.90, period C9 AUC > C0, gradual C9 AUC >= C0, period confirmation > 0, normal confirmation == 0, finite score를 요구한다. period equality는 실패하고 gradual/threshold equality는 통과한다. failure reason 순서는 deterministic하다.

Decision: eligible decision은 primary_passed_count == primary_required_count == 10이고 failure reason이 없어야 한다. 9/10 eligible record를 constructor 수준에서 거부한다.
