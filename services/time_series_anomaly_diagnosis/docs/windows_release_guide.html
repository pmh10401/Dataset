데이터에서 이상을 찾으세요.

Windows 10/11 64비트용 · CPU 실행 · Python 설치와 CUDA가 필요하지 않습니다.

처음 한 번

  1. GitHub Releases의 diagnosis-windows.zip.001부터 마지막 조각까지 모두 같은 폴더에 내려받습니다.
  2. restore.cmd, restore.ps1, manifest.json도 같은 폴더에 저장합니다.
  3. restore.cmd를 더블클릭합니다. 파일 검사 → 압축 복원 → DB 검사가 순서대로 진행됩니다.
  4. 생성된 TimeSeriesAnomalyDiagnosis 폴더 안의 TimeSeriesAnomalyDiagnosis.exe를 더블클릭합니다. 브라우저에 분석 화면이 열립니다.

분석하기

이름 검색 → 데이터 선택 → 분석 시작 → 작업 대기열의 결과 열기 → 이상 시계열 선택 순서로 확인합니다. 전체 DB가 포함되어 있으며, 분석 불가 항목도 필터를 해제하면 확인할 수 있습니다. 데이터가 포함되어 있다는 것이 모든 데이터의 분석 가능성을 뜻하지는 않습니다.

첫 분석은 계산 준비 때문에 시간이 더 걸릴 수 있습니다. 표본 수 제한으로 확정된 이상치에는 통계적 확신이 더 낮다는 경고가 표시됩니다. 모델의 판단은 연구팀이 검토해야 하며 의료 진단을 대신하지 않습니다.

보관과 종료

실행 중에는 검은 실행 창을 유지하고, 종료할 때는 해당 창에서 Ctrl+C를 누릅니다. DB와 분석 기록은 실행파일 옆 data 폴더에 저장됩니다. 새 버전을 받을 때 기존 폴더에 덮어쓰지 마세요. 압축 조각·복원 ZIP·실행 폴더가 동시에 존재하므로 여유 공간 12GB 이상을 권장합니다.

실행이 안 될 때

모든 압축 조각을 받았는지 확인하세요. 이미 복원한 폴더에는 재복원하지 않습니다. 서명되지 않은 내부 배포본은 Windows에서 경고가 나올 수 있습니다. 조직의 실행 정책을 따르고, 보안 기능을 끄지 마세요. 8485 포트가 사용 중이면 기존 진단 프로그램을 확인하거나 관리자에게 문의하세요. 닫힌 망에서는 승인된 방법으로 배포 파일을 옮긴 뒤 사용할 수 있습니다.
