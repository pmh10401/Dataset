승인된 설계의 실행 계획

Windows·Mac 이상 진단 서비스 구현 계획

현재 동작하는 DB 기반 분석 서비스를 버리지 않고, 경로·실행기·로컬 DB 등록·화면·패키지만 순서대로 교체합니다. 각 Task가 끝날 때마다 테스트와 코드맵을 확인합니다.

에이전트 실행 규칙: 구현 시 superpowers:subagent-driven-development 또는 superpowers:executing-plans를 사용해 Task별로 진행합니다.

목표
한 대의 중앙 서버에서 아이콘으로 실행되고, Windows와 Mac의 연구팀 브라우저가 DB 데이터셋을 골라 분석 결과까지 확인하는 자체 포함 프로그램을 만듭니다.
구조
기존 Python ThreadingHTTPServer, 분석 작업자 1개, 읽기 전용 원본 SQLite, 결과 SQLite를 유지합니다. 새 서버 프레임워크나 별도 작업 큐는 추가하지 않습니다.
기술
Python 3.14.6, SQLite, NumPy 2.3.5, Numba 0.63.1, aeon 1.4.0, scikit-learn 1.7.2, HTML/CSS/JavaScript, PyInstaller 6.22.2.
설계서
교차 운영체제 서비스 설계서
UI 기준

진행 상태

전체 제약

  • 연구팀은 10명 이내이며 중앙 서버 한 대를 사용합니다.
  • 웹 업로드 화면과 업로드 API를 만들지 않습니다. 1.6GB 원본 DB는 패키지에 넣지 않고 중앙 서버에 직접 복사합니다.
  • 원본 DB는 읽기 전용으로 열고, 분석 기록은 별도 SQLite에 저장합니다.
  • 분석은 기존처럼 한 건씩 실행합니다. 요청 조회만 여러 브라우저가 동시에 할 수 있습니다.
  • 현재 검증된 데이터셋별 방법 매핑만 사용합니다. 새 이름을 보고 방법을 추정하지 않습니다.
  • 로컬 등록 시 원본 TRAIN에서 가장 많은 라벨을 정상으로 정합니다. 최다 라벨이 둘 이상이면 임의 선택하지 않고 등록을 거절합니다.
  • CPU·Numba 경로는 CUDA가 없는 PC에서도 반드시 동작합니다. 이 계획에서는 새 CUDA·MLX 계산 코드를 만들지 않습니다.
  • Windows 패키지는 Windows에서, Mac 패키지는 Mac에서 각각 만듭니다.
  • 서비스 폴더의 새 파일 이름에는 실험 번호와 내부 프로젝트 접미사를 사용하지 않습니다.
  • 문서는 HTML로 작성하고 완료된 Task와 Step에만 체크합니다.
  • 모듈 경계나 데이터 흐름이 바뀌면 docs/code_map_v1.html, .json, .lock을 같은 변경에 갱신합니다.
  • 각 커밋 전 Ponytail 검토와 승인 게이트를 실행합니다. push는 별도 요청이 있을 때만 합니다.

Numba 판단: 이상 점수와 재표본화는 현재 Numba 경로를 유지합니다. DB 복사, 경로 계산, HTTP, HTML 생성은 계산 병목이 아니므로 Numba로 바꾸지 않습니다.

def open_source_database(path: Path) -> sqlite3.Connection:
    target = Path(path).resolve()
    connection = sqlite3.connect(
        f"{target.as_uri()}?mode=ro", uri=True, check_same_thread=False
    )
    connection.row_factory = sqlite3.Row
    connection.execute("PRAGMA query_only=ON")
    return connection

def load_model_resources(resource_directory: Path) -> ModelResources:
    directory = Path(resource_directory)
    manifest = json.loads((directory / "model_manifest.json").read_text("utf-8"))
    route_payload = verified_json(
        directory / "routing_catalog.json", manifest["files"]["routing_catalog.json"]
    )
    recovery_payload = verified_json(
        directory / "recovery_catalog.json", manifest["files"]["recovery_catalog.json"]
    )
    return parse_model_resources(route_payload, recovery_payload)
def find_json_by_sha256(
    repository_root: Path, expected: str, excluded_directory: Path
) -> Path:
    excluded = excluded_directory.resolve()
    matches = [
        path for path in repository_root.rglob("*.json")
        if excluded not in path.resolve().parents
        and sha256(path.read_bytes()).hexdigest() == expected
    ]
    if len(matches) != 1:
        raise ValueError(f"expected one JSON with sha256 {expected}, found {len(matches)}")
    return matches[0]

def build_service_resources(
    repository_root: Path,
    output: Path,
    routing_sha256: str,
    recovery_sha256: str,
) -> None:
    sources = {
        "routing_catalog.json": find_json_by_sha256(repository_root, routing_sha256, output),
        "recovery_catalog.json": find_json_by_sha256(repository_root, recovery_sha256, output),
    }
    output.mkdir(parents=True, exist_ok=True)
    for name, source in sources.items():
        shutil.copyfile(source, output / name)
    files = {name: sha256((output / name).read_bytes()).hexdigest() for name in sources}
    (output / "model_manifest.json").write_text(
        json.dumps({"schema": "service_model_resources_v1", "files": files}, sort_keys=True),
        encoding="utf-8",
    )

def resolve_data_directory(explicit: Path | None, executable: Path, platform: str) -> Path:
    if explicit is not None:
        return explicit.resolve()
    if platform == "darwin" and executable.parent.name == "MacOS":
        return executable.parents[3] / "data"
    return executable.parent / "data"

def choose_normal_label(counts: dict[str, int]) -> str:
    if not counts:
        raise ValueError("TRAIN labels are required")
    largest = max(counts.values())
    winners = [label for label, count in counts.items() if count == largest]
    if len(winners) != 1:
        raise ValueError("TRAIN labels must have one unique majority")
    return winners[0]

def derived_label(source_label: str, normal_source_label: str) -> str:
    return "0" if source_label == normal_source_label else "1"

def install_database(source_path: Path, data_directory: Path, report_path: Path) -> ImportSummary:
    data_directory.mkdir(parents=True, exist_ok=True)
    target = data_directory / "univariate_ts.db"
    with NamedTemporaryFile(dir=data_directory, suffix=".sqlite3", delete=False) as handle:
        staged = Path(handle.name)
    try:
        summary = build_derived_database(source_path, staged)
        validate_derived_database(staged, summary)
        os.replace(staged, target)
        report_path.write_text(render_import_report(summary), encoding="utf-8")
        return summary
    finally:
        staged.unlink(missing_ok=True)

validate_derived_database는 PRAGMA integrity_check, 데이터셋별 TRAIN·TEST 개수, 라벨이 0·1뿐인지 검사합니다. render_import_report는 데이터셋 이름, 원본 정상 라벨, 행 수, 성공 상태를 html.escape로 이스케이프한 표로 만듭니다. 서비스는 중지한 상태에서만 등록을 실행합니다. CSV·Excel·웹 업로드는 입력 계약이 정해지지 않았으므로 이 버전에서 만들지 않습니다.
