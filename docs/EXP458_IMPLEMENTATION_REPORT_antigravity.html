Task 3 진실 계약

  • 대상 dataset은 ECG5000_normal_2 하나뿐이다.
  • seed는 20260721, 20261721 두 개를 exact order로 유지한다.
  • 종류 순서는 level_shift, gradual_drift, amplitude_scaling, period_change다.
  • seed별 통과는 Wilson ≤ 0.05, 네 AUC 모두 ≥ 0.85, pooled AUC ≥ 0.90을 동시에 만족할 때만 참이다.
  • qualification 통과는 두 seed가 각각 모두 통과할 때만 참이다.
