Exp465 구현 보고서

이 문서는 Exp465 Task 1–4의 구현 범위와 검증 근거를 기록한다. Task 1–4는 독립 검토까지 완료됐다. 이전 상태는 task_1_review_pass_complete, task_2_review_pass_complete, task_3_review_pass_complete이며 현재 상태는 task_4_review_pass_complete다.

Task 4 구현 범위와 검증

  • 저장된 합격 표시를 믿지 않고 normal 및 네 합성 변화의 원점수에서 AUC·평균·유한값 여부를 다시 계산한다.
  • C8은 10개 기록 모두 통과하고, seed별 정상 confirmation이 0이며, gradual·period AUC가 같은 기록의 C0보다 낮지 않을 때만 통과한다.
  • normal×gradual/period fixed·broken 수와 Wilson 상한은 설명값으로만 보존한다.
  • 일곱 결과 파일을 canonical 형식으로 만들고, 재생 시 score·AUC·Wilson·confirmation·요약·판정·대시보드 변조를 거부한다.
  • 최종 집중 검사 9개를 두 번, Task 3 점수 회귀 검사 3개와 전체 Exp465 검사를 통과했다. compileall과 git diff --check도 통과했다.

Task 4의 집계와 JSON 생성은 작은 CPU 작업이다. MLX를 위해 판정 수학을 다시 쓰면 exact 경계가 바뀌고 1.1배 속도 조건을 정당화할 수 없어 CPU를 유지했다.

첫 검토의 지적을 반영해 seed마다 정확히 69개 OOF를 재생에서도 강제하고, Wilson을 seed 단위 0/69로 계산하며, C0는 보존된 입력과 fold 인덱스로 exact Exp464 scorer를 다시 실행한다. C6/C8은 원시 벡터 근거에서 다시 계산한다. 최종 fresh 검토 결과는 SPEC PASS / QUALITY APPROVED다.

Task 2 구현 범위

  • sources_antigravity.py: TRAIN 이름 강제, TEST 경로 사전 거부, MD5 gate, rsplit(":", 1) 파싱, float64/finite/int ±1 검증, 100×96과 69/31 확인 후 정상 69×96 read-only 반환.
  • interpolation_antigravity.py: 고정 np.linspace 그리드와 행별 단일 np.interp로만 96→140 변환. 첫·끝점 보존, owned/C-contiguous/read-only float64 출력.
  • Tests: source RED 5건과 interpolation RED 5건을 먼저 작성해 import failure로 확인한 뒤 GREEN으로 전환했다.

Task 3 구현 범위와 검증

  • scoring_antigravity.py: Exp465-local frozen/slots FoldMethodScoresAntigravity, fixed C0/C6/C8 projection, and one direct call to Exp464 score_fold_methods_antigravity. It copies no C0, synthetic generator, C6, or C8 mathematics.
  • Tests: fixed finite 20×140 fixture with sorted fit/query indices covers both frozen seeds and all five folds (10 calls), exact equality for all 13 fields and every nested value, read-only mapping checks, plus a scorer-call spy proving every entrypoint invocation calls the imported Exp464 scorer exactly once.

가속화 판단과 안전 경계

Task 1에는 tensor workload가 없다. PyTorch·MLX·MPS는 설계에 따라 나중에 점수 단계에서 다시 평가하며, 현재는 canonical CPU fallback만 기록한다. MLX 채택 조건은 candidate index 일치, 수치 허용 범위, transfer/sync 포함 1.1배 속도, manifest 증거다.

새 Ox Alpha Ultra 세션의 Task 3 독립 검토 결과는 SPEC PASS / QUALITY APPROVED이며 지적 사항이 없다. 계획의 Task 3 heading과 Step 6을 checked로 바꿨다. 이는 점수 모듈 구현 완료를 뜻하며 qualification 성능 결과를 뜻하지 않는다.
