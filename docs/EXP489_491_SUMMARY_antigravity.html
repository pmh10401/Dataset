Exp489–491: 세 실험 완료

이번 고정 설정에서는 세 실험 모두 전체 지표의 개선을 확인하지 못했습니다.

Grok(grok-4.6, high)이 격리된 소스 전용 worktree에서 구현했고, Codex가 통합·수정·실행·결과 검증을 담당했습니다. 독립 Sol 검토에서 발견한 입력 해시 기록 시점 문제도 수정하고 재검토를 통과했습니다.

결과 해석

Exp489는 같은 인코더와 특징을 공유한 쌍 비교에서도 LOF가 악화되어, 이 설정의 점수 함수 교체를 채택할 근거가 없습니다. Exp490은 행동 특성을 추가해도 고정 선형 예측의 오차가 커졌습니다. Exp491 역시 전체 평균에서 상수 예측을 넘지 못했습니다. 이 결과는 시험한 설정에 대한 판단이며, 모든 행동 특성이나 비선형 모형을 기각하는 결과는 아닙니다.

보조 지표에는 부분적인 개선도 있습니다. Exp490에서 Hydra의 AUC 이득 유무를 구별하는 AUROC는 0.5136 → 0.6124로 올랐지만, 해당 목표의 MSE는 악화했습니다. Exp491에서는 6개 목표 중 2개의 MSE가 소폭 개선됐으나 두 목표 묶음의 평균 MSE는 모두 악화했습니다. 이를 근거로 사후 파라미터 조정이나 라우팅 승격은 수행하지 않았습니다.

평가 범위

  • Exp489/490: 정상 TRAIN 행이 5개 이상인 family마다 사전식 첫 데이터셋 하나를 선택했습니다. PigAirwayPressure·PigArtPressure·PigCVP는 모든 파생 데이터셋의 정상 TRAIN 행이 4개여서 고정 5-fold 조건에 따라 제외했습니다.
  • Exp489: 새로 계산한 LocalGap 대조군과 LOF 점수를 먼저 저장한 뒤 TEST 라벨로 회고 평가했습니다. ZF는 평가 정상 최댓값을 넘는 이상 수이며, 운영 환경의 영-오탐 보장이 아닙니다.
  • Exp490 특성 추출은 정상 TRAIN만 사용했습니다. Exp490/491의 목표값에는 역사적 TEST 파생 평가 결과가 포함됩니다. 두 실험은 개발용 메타 분석이며, 손대지 않은 새 데이터의 최종 검증이 아닙니다.
  • family 전체를 제외한 평가를 사용하고, 중앙값 대치·표준화·Ridge 학습은 donor에만 맞췄습니다. 하이퍼파라미터 탐색과 결과에 따른 후보 재선택은 하지 않았습니다.

검증과 실행 기록

  • 관련 테스트 28개와 세 실험의 반복 재현성 smoke를 통과했습니다. 이후 알고리즘 코드는 변경하지 않았습니다.
  • Exp489 125/125, Exp490 125/125, Exp491 1,117행/128-fold 모두 완료했고, 실패는 0건입니다.
  • 최종 결과·manifest·현재 코드·사전등록·입력 해시가 일치합니다. Exp490의 두 비교군은 같은 데이터셋·목표·family 분할·상수 대조군을 사용했습니다.
  • 기존 자료 16개와 원본 DB의 SHA256이 변경되지 않았습니다. 코드맵 검증과 git diff --check도 통과했습니다.
  • 공식 CPU 구현을 유지했습니다. 데이터셋 병렬 단계는 11 workers, 내부 threads는 1이며, 작은 Ridge 평가 단계는 직렬 실행했습니다. MLX/MPS/Numba 평가와 CPU 유지 사유는 각 manifest에 기록되어 있습니다.
  • 정식 실행 시간: Exp489 39.9초, Exp490 58.80분, Exp491 1.80초. 서로 다른 계산량의 작업이므로 모델 간 속도 비교 수치는 아닙니다.
