4. 해석의 한계

이 결과는 이번 고정 구현이 선별 기준을 통과하지 못했다는 뜻입니다. 정상 상단 순위 학습 전체가 효과 없음을 입증하지는 않습니다. 고정 80회 Adam의 목적함수는 154개 분할에서 감소했고 91개에서 증가했으며 5개에서 같았습니다. 초기 목적함수 중앙값은 1.9372927e-05, 최종 중앙값은 1.9170758e-05였습니다. 수렴을 확인한 최적해라고 주장하지 않습니다.

최대 정상 점수의 부드러운 근사에 대한 순위 대리지표를 사용했으며, 정식 partial AUC 해법이나 운영 FPR 보장을 구현한 것이 아닙니다. 정상 TRAIN과 합성 변형만 이용한 선별이며, 반복 탐색과 합성 변형의 편향이 남아 있습니다. 새 후보의 실제 TEST 성능은 측정하지 않았습니다.

5. 검증과 실행 근거

테스트 8개를 최종 코드에서 다시 실행하여 모두 통과했습니다. 수치 미분과 기울기 일치, 순위 역전, 가중치 범위·재현성, 부모 제외와 거리 합 복원, 정상 참조 2개 및 상수 입력, 기존 대조 모델 일치, 배치 독립성, 검증 전용 변형, 선별 조건, 가속 수치 일치와 실제 GPU 연산 검사를 포함합니다. 250개 분할의 세 대조 모델 검출률은 기존 결과와 정확히 일치했고, 부모·적합·보류 분리와 코드·원천·프로토콜 해시 및 선별 결정을 독립 확인했습니다.

NumPy·Numba·Torch CPU의 전체 head 점수·순위·후보 인덱스가 일치했으나 가속 이점이 없어 NumPy를 유지했습니다. MLX는 float64 배열 생성만으로 GPU 계산 지원을 판정하지 않고 실제 GPU 행렬곱을 확인했으며, MLX와 MPS 모두 해당 float64 GPU 경로를 지원하지 않았습니다. 최초의 불충분한 배열 생성 프로브 기록은 별도 보존했습니다. CPU 병렬 실행은 논리 CPU−1인 11개 작업자, 내부 1스레드였습니다.

Grok은 데이터 없는 코드 검토를 수행했고 차단 문제 없음으로 회신했습니다. 공식 구현·통합·실행·결과 검산은 Codex가 담당했습니다.
