Exp470 실행 안내

현재 상태: 구현·사전검증과 private 실행 2회를 마쳤다. 두 결과는 byte 단위로 같았지만 성능 기준은 FAIL이다. official 실행 0회, TEST/FN 접근 0회다.

완료 상태

실행 결과

두 실행의 7개 파일이 모두 같아 재현성은 확인됐다. 그러나 두 seed 모두 period fixed가 0이므로 Exp470은 여기서 종료한다. 이 runbook으로 official 실행, TEST/FN 확인 또는 routing 변경을 시작하지 않는다.

완료한 실행 순서

  1. 현재 commit이 검토한 40자리 소문자 hash와 같고 작업 폴더가 깨끗한지 확인한다.
  2. 첫 private 경로에서 evaluate, 이어서 inspect를 한 번씩 실행한다.
  3. commit과 작업 폴더를 다시 확인한다.
  4. 둘째 private 경로에서 같은 순서를 한 번 실행한다.
  5. 두 경로의 아래 7개 파일을 원시 byte 단위로 비교한다.

기대하는 7개 파일

  • artifact_sha256_antigravity.json
  • context_antigravity.json
  • dashboard_snapshot_antigravity.json
  • decision_antigravity.json
  • failed_folds_antigravity.jsonl
  • method_fold_metrics_antigravity.jsonl
  • method_summary_antigravity.jsonl

중단 조건

승인 token이 틀림, commit이 다름, 작업 폴더 변경, 이미 있는 private 경로, command 실패, JSON 출력 이상, 파일 누락, byte 차이 중 하나라도 생기면 즉시 멈춘다. 기존 파일을 지우거나 다시 사용하지 않는다.

계속 금지된 일

official 실행, TEST/FN/FP/F1 열기, 기준 변경, 결과에 맞춘 조정, routing·champion·pending·promotion 변경은 이 안내만으로 허용되지 않는다.
