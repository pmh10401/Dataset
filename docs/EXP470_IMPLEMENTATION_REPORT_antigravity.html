완료 상태

핵심 결과

  • 새 E11 계산은 Numba만 사용한다. 작은 기준 계산과의 raw 오차는 최대 1.1102230246251565e-16으로, 기준 1e-12보다 작다. 반복 결과 byte도 같다.
  • MLX는 설치되어 있었지만 float64를 지원하지 않아 같은 계산을 안전하게 재현할 수 없었다. 따라서 Numba를 유지한다.
  • C11은 E11이 확인되고 C0보다 클 때만 E11을 쓴다. 그 외에는 C0 byte를 그대로 보존한다.
  • 10개 seed·fold 기록, pair fixed/broken 수, 재계산 결과와 7개 파일의 hash·내용을 다시 비교한다.
  • 독립 검토에서 확인된 overflow 출력, signed-zero fallback, JSON 자료형, MLX 배포 버전 문제가 테스트와 함께 보완됐다.
