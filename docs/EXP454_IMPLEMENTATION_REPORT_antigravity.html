PyTorch / MLX / MPS 가속 평가

Task 1은 문서·ledger·map만 다루므로 tensor 작업이 없다. 이후 평가도 새 score source가 아니다. 고정 CPU runtime만 정규 경로로 둔다.

  • tensor-eligible: 아니오
  • backend: CPython 3.14.6 + NumPy 2.3.5. PyTorch/MLX/MPS는 공식 경로에 없음
  • 전송·컴파일: 작은 정수 confusion을 장치로 옮기는 비용이 이득보다 큼
  • 결정성: CPU와 같은 후보 index·유한 점수만 허용. 불일치 시 CPU 유지
  • 정규 fallback: 고정 interpreter CPU
  • 가속 벤치마크: 알고리즘 동일, 같은 seed, 모든 alpha에서 index 동일, 허용 오차, 전송 포함 1.1배. 실패 시 CPU. MLX/MPS는 한 번에 하나만 실행
