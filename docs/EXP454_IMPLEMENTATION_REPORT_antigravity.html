Closed CLI

허용 명령은 세 개뿐이다. readiness와 evaluate는 소문자 40-hex --reviewed-commit 하나만 받는다. inspect는 인자가 없다. new, resume, retry, override, -r, --commit, --reviewed, 대문자 hex, 39/41 hex, 빠진 flag, 추가 인자는 거부한다. evaluate는 맵 검증 뒤에만 evaluator를 import하고, production 경로는 Task 2 capture_normalized_target_authority_antigravity()만 load한다. test fixture converter는 import하지 않는다.

공식 operator 진입점은 reviewed commit 32240c4e71776633249549a3d1d88b0e404d9463에서 readiness, evaluate, bare inspect 순서로 각각 한 번 실행했고 모두 exit 0이었다. 이후 독립 검토 도중 두 번째 inspect 시도가 실패해 lifecycle은 영구 stopped가 됐다. 이 추가 시도는 평가 결과를 다시 계산하거나 label을 다시 열지 않았고, 기존 12개 결과 파일도 바꾸지 않았다.

PyTorch / MLX / MPS 가속 평가

Exp454는 새 score source가 아니다. Task 5 closed CLI도 tensor 단계가 아니다. 고정 CPU runtime만 정규 경로로 둔다.
