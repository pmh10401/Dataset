라우팅 규칙 v3c 재검증 (antigravity)

v3c 변경 내용

새로 추가된 특징:

  • diff_std_ratio: 신호가 한 스텝에 얼마나 변하는지 (전체 크기 대비)
  • zero_crossing_rate: 평균을 기준으로 몇 번이나 위아래로 왕복하는지

새로 추가된 규칙:

width < 200 AND diff_std_ratio < 0.10
→ minirocket_local_gap
이유: 매우 매끄럽고 느리게 변하는 짧은 신호는 GunPoint 같은 자세 데이터 특징이며, minirocket의 세밀한 커널이 유리.
