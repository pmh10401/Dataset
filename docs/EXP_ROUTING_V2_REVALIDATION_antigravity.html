규칙 변경 내용 (v1 → v2c)

v2c에서 추가된 새 규칙:

width < 200 AND kurtosis > 1.5 AND spectral_entropy < 0.70
→ hydra_local_gap 선택

남은 한계

  • TwoLeadECG: 여전히 hydra 계열이 zero-FP에서 앞섬 (-4). kurtosis가 +0.55로 낮아 새 게이트에 걸리지 않음.
