# Exp389-390 실험 결과 분석

## 결론

Exp389-390은 기존 자동 경보를 변경하지 않으면서 신뢰도 순서를 추가하는 데
성공했다. 최고 신뢰와 확장 신뢰를 합친 361건의 정밀도는 91.41%로, 전체
자동 경보 정밀도 86.34%보다 5.07%p 높다.

이 결과는 자동 경보의 우선순위와 설명력을 개선하지만 TP, FP, FN 또는 F1을
직접 개선하지는 않는다.

## 전체 자동 경보

| 지표 | 결과 |
|---|---:|
| 데이터셋 | 1,117 |
| 실제 이상 | 3,918 |
| 자동 경보 | 2,218 |
| TP | 1,915 |
| FP | 303 |
| FN | 2,003 |
| Micro precision | 86.34% |
| Micro recall | 48.88% |
| Mean dataset F1 | 0.608983 |
| Zero-F1 데이터셋 | 356 |
| 자동 경보가 없는 데이터셋 | 229 |

Zero-F1 356개 중 229개는 경보가 전혀 없었고, 나머지 127개는 경보가
있었지만 TP가 하나도 없었다.

## 신뢰 등급 분리

| 등급 | 경보 | TP | FP | 정밀도 |
|---|---:|---:|---:|---:|
| 최고 신뢰 | 228 | 211 | 17 | 92.54% |
| 확장 신뢰 | 133 | 119 | 14 | 89.47% |
| 일반 신뢰 | 1,857 | 1,585 | 272 | 85.35% |
| 최고+확장 | 361 | 330 | 31 | 91.41% |

최고+확장 등급은 전체 자동 경보의 16.28%이지만 전체 TP의 17.23%를
포함하고, 전체 FP의 비중은 10.23%에 그친다. 따라서 신뢰도 정렬은
실질적인 구별력을 가진다.

일반 신뢰도 정밀도가 85.35%이므로 이를 검토 lane으로 내리면 안 된다.
일반 신뢰는 기존 자동 경보를 유지하되 화면 표시와 확인 순서만 낮추는 것이
적절하다.

## 주의할 점

alpha 0.005에서 네 근거를 모두 계산할 수 있는 데이터셋은 177개이고,
alpha 0.010에서는 252개다. 추가 근거를 계산할 수 없는 데이터셋은 각각
940개와 865개다.

따라서 일반 신뢰는 반드시 낮은 신뢰를 의미하지 않는다. TRAIN 표본 부족으로
추가 검증 자체가 불가능한 경우도 포함한다. UI에서는 `낮은 신뢰` 대신
`일반 신뢰`라고 표시하고, 별도로 `추가 근거 계산 불가` 상태를 보여주는 것이
안전하다.

최고 신뢰 등급에서도 `ECG5000_normal_1`과 `Yoga_normal_2`는 각각
2건의 경보가 모두 FP였다. 최고 신뢰는 확정 판정이 아니라 여러 독립 근거가
강하게 동의한 상태로 설명해야 한다.

## FP 집중도

전체 FP 303건의 50%는 65개 데이터셋, 80%는 156개 데이터셋에서 발생했다.
FP가 일부 데이터셋에만 극단적으로 집중된 구조는 아니다.

주요 FP 데이터셋은 다음과 같다.

| 데이터셋 | 자동 경보 | TP | FP | 정밀도 |
|---|---:|---:|---:|---:|
| StarLightCurves_normal_3 | 79 | 72 | 7 | 91.14% |
| Crop_normal_22 | 22 | 15 | 7 | 68.18% |
| ElectricDevices_normal_2 | 67 | 62 | 5 | 92.54% |
| ECG5000_normal_2 | 13 | 8 | 5 | 61.54% |
| Yoga_normal_2 | 8 | 3 | 5 | 37.50% |

경보량이 크지만 정밀도가 높은 데이터셋과, 경보량은 작아도 정밀도가 낮은
데이터셋을 구분해 대응해야 한다.

## 운영 권고

1. 기존 자동 경보 2,218건은 유지한다.
2. 최고 신뢰 228건을 사용자 화면에서 가장 먼저 표시한다.
3. 확장 신뢰 133건을 두 번째로 표시한다.
4. 일반 신뢰 1,857건은 자동 경보 자격을 유지하되 확인 순위를 낮춘다.
5. 추가 근거가 계산되지 않은 경우와 계산됐지만 동의하지 않은 경우를 UI에서
   구분한다.
6. 다음 모델 개선은 confidence alpha가 아니라 FN 2,003건과 Zero-F1
   356개 데이터셋을 대상으로 별도 실험한다.

이번 결과는 retrospective counterfactual 분석이며 실제 설비 prospective
검증 결과가 아니다. TEST 결과로 alpha나 등급 규칙을 다시 선택하지 않았다.
