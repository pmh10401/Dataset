안전 경계와 concern

한 번의 재시도 wrapper가 run 1 root가 이미 존재하는 동안 create-only publisher를 호출해 publication destination must be a new private path로 종료했다. 이 실패 프로세스는 publisher의 존재 검사에서 중단됐고 root 파일을 쓰지 않았다. 유효한 run 1 root는 이후 replay와 run 2의 exact equality로 검증했다. 이 overlap은 비결과 시도로만 공개하며 추가 private run은 수행하지 않았다. Review SHIP 후 정확한 두 private root만 제거했으며 aggregate logs/report는 유지한다.
