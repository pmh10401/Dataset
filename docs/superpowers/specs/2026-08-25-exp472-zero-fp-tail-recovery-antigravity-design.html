Exp472: Zero-FP Tail Recovery 설계

작성일 2026-08-25 · 상태: 설계 승인 대기

1. 문제

ECG200 두 변형에서 C0 AUC는 정상(0.99/0.84)이지만 zero-FP TP가 0이다. 정상 점수 분포 상단이 이상치와 겹쳐서 "정상 최댓값보다 큰" 기준을 통과하는 이상치가 없다.

2. 원인

원인증거
C0 점수 포화점수 범위 [0,1]. 정상 상위 2%가 0.99 도달, 이상치 0.99·1.0과 동일 천장.
E12 피크 미검출TRAIN early 피크 존재 30/106, late 32/106. 이상치 2개 모두 early=None, late=None → shift=0 → 랭크 ≈0.54 고정.
E12 confirmation 불발confirm 조건 raw > maximum이 절대 참이 되지 않음 → C12=C0과 동일.

3. 제안 접근

접근변경예상 효과리스크
A: C0 raw-distance 복원LocalGap의 정규화 전 raw 평균 거리를 별도 필드로 노출하여 스코어링에 사용꼬리가 펴져서 이상치-정상 분리 폭 증가기존 qualification 재검증 필요
B: E12 confirmation 완화confirmed = raw > percentile(fit_raw, p), p ∈ {90, 95} 스캔confirm 발생률 상승 → C12가 C0과 달라질 여지FP 증가 가능
C: 통계 피처 결합spectral entropy(Exp470), RMS, kurtosis 등을 C0에 concat 후 LocalGapECG200 매끄러운 신호에 대한 분별력 추가피처 수 증가 → 학습 시간 증가

4. 평가 프로토콜

  • 데이터셋: ECG200_normal_1, ECG200_normal_-1 (per-dataset majority-class TRAIN)
  • seed: 20260721, 20261721 (frozen)
  • 지표: AUC, zero-FP TP, FP budget {3,5,10}에서 TP, F1-best
  • baseline: 현재 C0 (AUC만 알려진 상태)
  • routing/champion/promotion 변경 금지

5. 성공 기준

  • zero-FP TP ≥ 1을 달성하는 접근이 하나라도 존재할 것
  • AUC 열화 없을 것 (기존 C0 AUC −0.01 이내)
  • 두 seed 결과 일관성 유지
