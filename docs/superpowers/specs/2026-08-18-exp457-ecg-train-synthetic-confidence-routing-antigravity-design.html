Exp457 — ECG5000 TRAIN 합성 이상 확신 라우팅

목표: Exp456에서 ECG5000 후보를 잘못 고른 이유를 직접 다루고, 후보가 충분히 믿을 만하지 않으면 기존 baseline으로 돌아간다.

1. 한 문장 가설

Hydra LocalGap이 정상 TRAIN에서 낮은 오탐과 충분한 합성 이상 감도를 반복해서 보이고, 동시에 기존 탐지를 버리는 수보다 새로 추가하는 수가 많을 때만 사용하면 ECG5000의 FN을 안전하게 줄일 수 있다.

핵심 문제는 Hydra 자체가 아니라 5개 데이터셋에서 배운 단일 임계값 규칙이 새로운 데이터셋으로 일반화되지 않은 것이다.

3. 데이터와 범위

  • 새 실험 번호는 Exp457이다.
  • 종류는 ecg_train_synthetic_confidence_routing이다.
  • 기준 커밋은 Exp456 최종 커밋 58dae2d425de136cc02bfe665e54bff847418af3이다.
  • 새 과학 변화는 ECG5000의 hydra_local_gap 선택 게이트 하나뿐이다.
  • ChlorineConcentration은 Exp456의 family-wide multirocket_local_gap을 세 데이터셋 모두에 고정한다.
  • 다른 모든 데이터셋은 기존 baseline을 유지한다.
  • ECG5000 TRAIN 라벨은 모두 정상이다. TRAIN 행 수는 2,335 / 1,413 / 76 / 155 / 19다.

4. baseline을 TRAIN에서 재평가하지 않는 이유

기존 baseline은 Exp404에서 이미 고정된 TEST 좌표다. TRAIN 입력을 받아 새 점수를 만드는 하나의 실행 가능한 모델이 아니다. 따라서 TRAIN에서는 baseline과 후보를 억지로 재대결시키지 않는다. 대신 Hydra 후보 자체가 믿을 만한지 절대 기준으로 검사한다.

5. TRAIN 전용 Hydra 검증

  1. 각 ECG5000 TRAIN을 기존 방식과 같은 결정적 5분할로 나눈다.
  2. 각 검증 행은 자기 자신을 제외한 정상 TRAIN으로 학습한 Hydra LocalGap에서 점수를 받는다.
  3. 같은 검증 행에 네 가지 합성 이상을 각각 만든다.
  4. 원본 정상 행과 합성 이상 행을 같은 모델·같은 경험적 p-value 기준 alpha=0.005로 판정한다.
  5. Hydra의 두 고정 seed 20260721, 20261721을 따로 검사한다.

고정 합성 이상

기존 Exp417 정의를 바꾸지 않고 재사용한다.

종류정확한 변화
level shift길이의 40% 지점부터 정상 TRAIN robust scale의 3배를 더한다.
gradual drift40% 지점부터 0에서 robust scale 3배까지 선형으로 증가시킨다.
amplitude scaling중앙값을 중심으로 진폭을 1.5배로 만든다.
period change40% 이후 구간을 고정 비율 1.25로 시간 변형한다.

짧은 spike는 보조 진단으로만 기록하며 합격 판정에는 쓰지 않는다. 실제 TEST 이상 형태를 보고 합성 종류나 크기를 바꾸지 않는다.

6. 두 개의 확신 게이트

게이트 1 — TRAIN 신뢰도

두 Hydra seed가 아래 조건을 각각 모두 만족해야 한다.

  • 정상 OOF 후보율의 95% Wilson 상한이 5% 이하다.
  • 네 가지 주요 합성 이상을 합친 감도가 70% 이상이다.
  • 각 합성 이상 종류의 감도가 모두 50% 이상이다.
  • 모든 점수와 p-value가 유한한 수다.

TRAIN 표본이 적어 alpha=0.005를 충분히 구분하지 못하면 자동으로 실패하며 기준을 느슨하게 만들지 않는다.

게이트 2 — 탐지 구조

Exp456에서 TEST 라벨 없이 계산한 예측 집합 특징에 대해 added_count > removed_count여야 한다. 즉 후보가 버린 기존 탐지보다 새로 추가한 탐지가 더 많아야 한다. 동률이거나 반대면 baseline으로 돌아간다.

최종 라우팅

게이트 1과 게이트 2를 모두 통과한 ECG5000만 Hydra 후보를 사용한다. 하나라도 실패하면 그 데이터셋은 baseline이다.

7. 최종 비교

아래 네 방법만 비교하며 순서를 고정한다.

  1. always_baseline
  2. family_wide_local_gap
  3. oracle_per_dataset — 가능한 최대치 확인용이며 실제 선택에는 사용하지 않는다.
  4. ecg_train_confidence_router — Exp457 제안 방법

라우팅 결정이 고정된 뒤 Exp456의 불변 데이터셋별 혼동행렬을 한 번 재집계한다. 새 TEST 라벨 조회는 필요하지 않으며, Exp456의 혼동행렬·FN·FP·F1 같은 TEST 성능 결과를 라우팅 결정 입력으로 사용해서도 안 된다. 게이트 2에는 라벨 없는 예측 집합 특징만 사용한다.

9. 예상되는 판정 구조

탐지 구조 게이트만 보면 normal_2는 14개 추가 / 5개 제거로 통과하고, normal_1은 12개 추가 / 20개 제거로 실패한다. 그러나 최종 후보 사용 여부는 아직 모르는 TRAIN 신뢰도 게이트까지 통과해야 정해진다.

만약 normal_2만 TRAIN 게이트를 통과하면, Chlorine family-wide 고정과 합쳐 전체 성능은 FN 829, FP 66이 된다. 이것은 예상 가능한 조건부 결과이며, TRAIN 게이트 통과를 미리 가정한 공식 결과가 아니다.

12. 검증 항목

  • 합성 이상 네 종류의 수학적 정의와 40% 시작점이 정확한지 확인한다.
  • 각 검증 행이 자기 학습 reference에 포함되지 않는지 확인한다.
  • 두 seed 중 하나라도 실패하면 baseline으로 돌아가는지 확인한다.
  • added_count == removed_count 및 역전 사례가 baseline인지 확인한다.
  • 입력 순서를 바꿔도 데이터셋 이름으로 같은 결정이 나오는지 확인한다.
  • Exp456의 네 기존 비교값을 정확히 재현한 뒤 Exp457 결과를 추가하는지 확인한다.

13. 계산 장치

HydraTransformer는 공식 aeon CPU 구현을 그대로 사용한다. 이를 MLX로 다시 쓰면 같은 알고리즘이라는 조건을 깨므로 MLX 적용 조건 1을 만족하지 않는다. Exp457은 CPU로 실행하며 새로운 모델 학습이나 GPU 구현을 추가하지 않는다.

14. 승인 상태

승인됨: TRAIN 합성 이상 절대 검증과 added_count > removed_count 구조 게이트를 모두 요구하고, 낮은 확신에서는 baseline으로 복귀한다.
