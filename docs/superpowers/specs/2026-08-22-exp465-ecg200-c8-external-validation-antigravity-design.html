Exp465 — ECG200에서 C8을 그대로 외부 검증

한 줄 목표: ECG5000에서 가능성을 보인 C8이 다른 ECG 자료에서도 같은 엄격한 기준을 통과하는지 확인한다.

1. 왜 이 실험을 하는가?

현재 공식 전체 모델은 정밀도 86.34%이지만 재현율이 48.88%라 실제 이상 3,918개 중 2,003개를 놓친다. 따라서 핵심 문제는 잔여 FN이다.

Exp464의 주 후보 C6은 10개 기록 중 9개만 통과했다. 반면 C8은 기본 검사에서 10/10이라는 단서를 보였다. 그러나 C8에는 C6과 같은 전체 비교 기준이 적용되지 않았으므로 아직 더 좋은 방법이라고 결론낼 수 없다.

Exp465는 C8을 뒤늦게 Exp464의 승자로 바꾸는 실험이 아니다. 새로운 외부 자료와 새로운 사전등록 기준으로 C8을 처음부터 주 후보로 검증한다.

3. 자료 계약

  • 공식 ECG200 보관본의 ECG200_TRAIN.ts만 사용한다. 공개된 MD5는 808875aeac1c358a90c630fe369327c4다.
  • TRAIN 전체가 정확히 100×96, 정상 +1 69개, 심근경색 -1 31개인지 먼저 확인한다.
  • 방법 검증에는 정상 +1 69개만 사용한다.
  • ECG200_TEST.ts는 다운로드·열기·조회하지 않는다.
  • 크기, 라벨 수, 길이, finite 조건 중 하나라도 다르면 계산 전에 중단한다.

4. 길이 96을 140으로 바꾸는 고정 규칙

각 정상 행을 np.interp의 선형 보간으로 한 번만 96→140 변환한다. 원본의 첫 점과 마지막 점은 그대로 보존한다.

source = np.linspace(0.0, 1.0, 96, dtype=np.float64)
target = np.linspace(0.0, 1.0, 140, dtype=np.float64)
x140 = np.interp(target, source, x96)

보간을 마친 140점 정상 자료에 Exp464와 같은 합성 변화를 주입한다. 그 뒤 onset 56, suffix 길이 84, 모든 점수식을 그대로 사용한다.

원래 길이 96에서 onset 38·39를 비교하거나 다른 보간법을 시험하지 않는다. 그렇게 하면 C8 외부 검증이 아니라 새 방법 탐색이 된다.

5. 유일한 주 후보 C8

각 fold의 비주입 fit 정상 행에서 median template를 만든다.

template = median(X_fit, axis=0)
e = x - template
u = e[56:140]
t = linspace(0, 1, 84)
q0 = t / ||t||₂
a0 = dot(u, q0)
c0 = 0 if ||u||₂ == 0 else a0 / ||u||₂
r0 = (1 + count(a0_fit <= a0)) / (n_fit + 1)

if c0 >= 0.95:
    result = max(C0_rank, r0)
else:
    result = C0_rank
  • template, a0_fit과 rank 기준은 해당 fold의 fit 정상 행에서만 만든다.
  • query 원본과 각 합성 변형은 서로 독립적으로 cosine gate를 계산한다.
  • onset 56, cosine 0.95, rank 식과 max 결합을 바꾸지 않는다.

7. 합성 변화와 평가

level shift, gradual drift, amplitude change, period change의 네 합성 변화를 Exp464와 같은 식·크기·난수 순서로 만든다. 각 seed-fold에서 정상과 네 변화의 AUC, 네 AUC 평균과 finite 여부를 기록한다. 정상 confirmation은 seed별 5개 out-of-fold 결과를 합쳐 정확히 69개로 계산한다.

정상 69개에서 confirmation이 0개여도 95% Wilson 상한은 0.05273725818905172라 0.05를 만족할 수 없다. 따라서 Wilson은 설명값으로 기록하고, 합격 기준은 각 seed에서 정상 confirmation이 정확히 0개인 것으로 고정한다.

추가 설명값으로 C0 대비 C8이 바로잡은 normal×gradual 및 normal×period 순서쌍 수와 새로 망친 순서쌍 수를 기록한다. 동점은 양쪽에서 제외한다. 이 수치는 설명용이며 합격선을 새로 고르는 데 사용하지 않는다.

8. C8 합격 조건

C8은 다음 조건을 모두 만족해야 한다.

  • 10개 seed-fold 기록 모두 통과
  • 각 기록의 네 변화 유형 AUC가 각각 0.85 이상
  • 각 기록의 네 AUC 평균이 0.90 이상
  • 모든 입력과 점수가 유한값
  • 각 기록의 gradual AUC가 같은 기록의 C0보다 낮지 않음
  • 각 기록의 period AUC가 같은 기록의 C0보다 낮지 않음
  • 각 seed의 다섯 out-of-fold 정상 결과 69개에서 C8 confirmation이 정확히 0개

0.85가 모든 문제의 절대 정답이라는 주장은 하지 않는다. Exp464와 같은 난이도로 외부 재현성을 비교하기 위해 이번 실험 전에 고정한 값이다.

10. 실행과 재현성

  • 구현 후 서로 다른 private TRAIN root에서 evaluate→inspect를 정확히 두 번 순차 실행한다.
  • 두 실행의 행, 요약, 결정, 대시보드와 모든 결과 파일 byte/hash가 같아야 한다.
  • private 자격 검증과 독립 검토가 통과한 뒤에만 별도 승인으로 공식 실행한다.
  • 새 score-source이므로 전체 실행 전에 MLX 가능성을 확인한다. 같은 입력·seed에서 후보 순서가 같고 수치 허용 범위를 만족하며 1.1배 이상 빠를 때만 MLX를 사용한다. 아니면 CPU를 유지한다.
  • 진행 상황과 결과는 쉬운 한국어 HTML 대시보드에 즉시 반영하고 완료된 단계의 체크박스를 체크한다.

11. 금지 사항

  • ECG200 TEST 파일 또는 TEST 라벨 접근
  • 실패 후 onset, cosine, 보간법, seed, fold 또는 AUC 기준 변경
  • C6 또는 새 변형의 사후 승격
  • Exp465 안에서 실제 라우팅·FN·FP·F1 평가
  • Exp464를 사후 성공으로 다시 기록

FN 해석 제한: Exp465는 실제 심근경색 -1 행을 평가하지 않는다. 정상 69개와 합성 변화의 점수 자격만 검증하므로 실제 FN 감소 근거는 후속 라우팅 실험에서 따로 만들어야 한다.
