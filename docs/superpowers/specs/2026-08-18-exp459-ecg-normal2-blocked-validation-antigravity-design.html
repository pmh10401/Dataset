Exp459 — ECG5000 normal_2 연속 구간 독립 검증

목표: Exp458에서 통과한 ECG5000_normal_2 후보 판단이 특정 TRAIN 행 배치에만 맞은 우연이 아닌지 확인한다.

1. 결론부터

Exp458은 FN을 836에서 829로 7개 줄이고, FP를 64에서 66으로 2개 늘렸으며, F1을 0.5754716981에서 0.5796148426으로 높였다.

Exp459에서는 방법이나 통과선을 다시 고르지 않는다. TRAIN 행을 저장 순서대로 5개 연속 구간으로 나누고, 매번 한 구간을 학습에서 빼고 검사한다. 10개 판단(5구간×2seed)이 모두 통과할 때만 Exp458 라우팅을 안정적인 후보로 인정한다.

2. 이 검증이 독립적인 이유와 한계

  • 검증할 행은 해당 fold의 Hydra와 LocalGap 기준을 만드는 데 사용하지 않는다.
  • 1413개 TRAIN 행은 각각 정확히 한 번만 검증 구간에 들어간다.
  • 무작위로 행을 섞지 않으므로 서로 가까운 저장 구간의 차이를 숨기지 않는다.
  • DB에 실제 측정 시각 열이 없으므로 이것을 달력 시간 검증이라고 부르지 않는다. 정확한 이름은 저장 순서 기반 연속 구간 검증이다.
  • 같은 ECG5000 TRAIN 자료를 다시 나누는 검증이므로, 다른 병원·기기·데이터셋에 대한 외부 검증은 아니다.

각 fold에서 나머지 네 구간으로 표현과 LocalGap 기준을 만들고, 빠진 구간의 정상 행과 그 행에서 만든 네 합성 이상만 점수화한다. fit 행과 검증 행은 겹치지 않는다.

5. 바꾸지 않는 통과선

각 fold와 각 seed가 아래 조건을 모두 만족해야 한다. Exp459 결과를 본 뒤 숫자를 완화하거나 강화하지 않는다.

조건고정 통과선설명
종류별 AUC네 종류 모두 ≥ 0.85한 종류라도 약하면 그 fold는 실패한다.
평균 AUC≥ 0.90네 AUC의 단순 평균이다.
정상 오경보 Wilson 상한≤ 0.05Exp458의 p≤0.005 정상 경보 계산을 그대로 쓴다.
점수와 행 사용유한값, 중복 0, 누락 0모든 TRAIN 행이 한 번만 검증되어야 한다.

AUC는 Exp458과 같은 (합성>정상 승리 + 0.5×동점)/(정상×합성 쌍) 공식을 쓴다.

실패했을 때 같은 Exp459 안에서 임계값, fold 수, seed 또는 합성 이상을 바꾸지 않는다.

7. 성능 결과의 해석

  • Exp459는 TEST 라벨을 다시 읽거나 새 혼동행렬을 만드는 실험이 아니다.
  • stable이면 Exp458의 고정 라우팅 결과 TP 617 / FP 66 / FN 829 / TN 70788 / F1 0.5796148426491311을 구간 변화에도 안정적인 후보로 해석한다.
  • unstable이면 Exp458 공식 결과는 그대로 보존하지만 운영 승격 근거로 사용하지 않는다.
  • champion, pending candidate, 실제 운영 route는 자동으로 바꾸지 않는다.

8. 구성 요소와 데이터 흐름

  1. Exp458 권한 확인: 공식 9-leaf 결과와 reviewed commit을 읽기 전용으로 확인한다.
  2. TRAIN 입력: ECG5000_normal_2 TRAIN을 정확히 한 번 읽고, TEST 라벨 조회 수는 0으로 유지한다.
  3. 연속 fold 생성: 행 순서를 유지한 다섯 query 구간과 그 보완 fit 구간을 만든다.
  4. 점수 계산: fold마다 Hydra/LocalGap을 fit 구간에만 맞추고 query 구간을 점수화한다.
  5. 판정: fold·seed별 네 AUC, 평균 AUC, Wilson 상한을 계산한다.
  6. 저장과 재검사: 입력 구간, 결과, 최종 판단을 저장하고 원자료에서 다시 계산한다.
  7. HTML 대시보드: 10개 판단과 실패 이유를 쉬운 표로 표시한다.

10. 검증 체크리스트

11. MLX와 계산 자원

Hydra는 aeon의 기존 CPU 구현을 그대로 유지한다. MLX로 다시 쓰면 고정 방법이 달라지므로 적용하지 않는다. fold는 순차 실행하고, 동시에 여러 Hydra/MLX 작업을 실행하지 않는다.

12. 기존 테스트의 알려진 상태

Exp459 작업 폴더 시작점에서 Exp458 테스트 62개 중 60개가 통과했다. 실패한 2개는 Task 5 시절의 “Exp458 공식 root가 없어야 한다”는 조건을 유지한 검사다. Task 6에서 root가 정상 생성된 현재 truth와 맞지 않으며 과학 계산 실패가 아니다. Exp459 구현 전 선행 정리로 해당 테스트를 공식 완료 상태와 임시 root 검사로 분리한다. Exp458 결과 파일은 수정하지 않는다.
