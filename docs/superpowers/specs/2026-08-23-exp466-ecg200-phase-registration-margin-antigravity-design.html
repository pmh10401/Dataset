Exp466 — ECG200 고정 위상 정렬 마진 자격 검증

한 줄 목표: C8이 전혀 반응하지 못한 ECG200의 주기 변화를, 고정된 시간축 역정렬이 파형을 얼마나 더 잘 맞추는지로 찾아낸다.

1. 출발점

Exp465 결과C8은 0/10, 최저 period-change AUC는 0.6862244898, 최저 평균 AUC는 0.8679846939였다.
C8 실패 원인period-change confirmation이 10개 fold에서 모두 0이었다. 따라서 period 점수는 C0와 정확히 같았다.
임계값 하향정상 cosine 최대 0.8755가 period 최대 0.8289보다 높다. 임계값을 낮추면 정상부터 반응하므로 기각한다.
기존 주기 특징Exp461의 120차원 FFT+자기상관 특징을 Exp465 보존 입력에 그대로 적용한 feasibility 결과는 단독 최저 period AUC 0.650888, C0 rank-max 결합 0.678571, 결합 최저 평균 0.866071이었다. 모두 현재 결과보다 낮아 정식 후보에서 제외한다.

Terra, Luna, Ox Alpha Ultra와 Sol이 위 증거를 교차 검토했다. 최종 합의는 기존 특징과 임계값을 다시 조정하지 않고, period 생성 구조에 직접 맞는 고정 위상 정렬 마진 하나만 검증하는 것이다.

2. 고정 입력

  • 데이터는 ECG200 TRAIN의 정상 +1 69개만 사용한다. TEST 파일과 TEST 라벨은 열지 않는다.
  • 각 행은 Exp465의 정확한 선형 보간으로 96→140 변환한다.
  • seed는 20260721, 20261721, fold는 각각 5개로 고정한다.
  • onset은 56, suffix 길이는 84다.
  • level shift, gradual drift, amplitude scaling, period change 생성식과 크기·순서는 Exp465와 같게 유지한다.
  • period change의 시간축 배율 1.25는 기존 생성식에서 가져온다. 다른 배율이나 grid를 탐색하지 않는다.

방법역할설명

4. 위상 정렬 마진

fit 행으로 만든 중앙값 template과 각 행의 suffix를 각각 중앙값과 MAD로 표준화한다. 표준화는 level과 amplitude 차이가 주기 신호로 잘못 보이는 것을 줄인다.

  1. 기존 period 생성은 suffix를 source / 1.25에서 다시 읽어 시간축을 늘린다.
  2. Exp466은 공유 가능한 앞부분에서 관측 suffix를 1.25 × source 위치에서 읽어 이 변형을 한 번만 되돌린다.
  3. identity_error는 정렬하지 않은 suffix와 template의 평균 제곱 거리다.
  4. undo_error는 고정 역정렬한 suffix와 template의 평균 제곱 거리다.
  5. margin = identity_error - undo_error로 고정한다. 역정렬이 실제로 도움이 될 때만 양수가 된다.

fit 정상 margin은 각 행을 제외한 중앙값 template으로 계산한다. query margin은 전체 fit template으로 계산한다. P9 확인 조건은 query_margin > 0이면서 query_margin > max(fit_normal_margins)인 경우로 고정한다. 학습되는 threshold나 조정 가능한 alpha는 두지 않는다.

5. 결과 기록

각 seed-fold-method 행에는 다음 값을 저장한다.

  • 네 변화 유형 AUC, 네 AUC 평균, finite 여부
  • normal과 네 변화 유형의 confirmation 수
  • C0 대비 gradual/period AUC 차이와 fixed/broken pair 수
  • fit/query margin 요약, 원시 margin 배열 또는 source-free replay가 가능한 canonical evidence
  • 통과 여부와 고정 failure reason

6. 합격 기준

C9은 다음 조건을 모두 만족해야 한다.

  1. 10개 seed-fold가 모두 finite다.
  2. 각 행의 네 변화 유형 AUC가 모두 ≥0.85다.
  3. 각 행의 네 AUC 평균이 ≥0.90이다.
  4. period-change AUC가 10개 행 모두에서 C0보다 엄격히 높다.
  5. gradual-drift AUC가 10개 행 모두에서 C0보다 낮지 않다.
  6. period-change confirmation이 각 행에서 1개 이상이다.
  7. 두 seed 각각의 OOF 정상 69개 confirmation 합계가 정확히 0이다.
  8. 서로 다른 private root에서 두 번 순차 실행한 결과 파일·해시·판정이 완전히 같다.

7. 중단 규칙

  • 조건 하나라도 실패하면 C9은 qualification 실패로 종료한다.
  • 실패 뒤 같은 실험에서 warp 배율, margin 식, threshold, onset, 보간, seed, fold 또는 합격선을 바꾸지 않는다.
  • Exp466에서는 공식 실행, ECG200 TEST 접근, 라우팅, champion·pending·promotion 변경을 하지 않는다.
  • C9이 10/10으로 통과할 때만 별도 승인을 받아 Exp467에서 실제 잔여 FN, FP와 F1을 평가한다.
  • C9이 실패하면 ramp/phase 계열을 종료하고 국소 STFT 또는 wavelet 변화 점수 하나를 새 실험으로 사전등록한다.

8. 구현과 검증 경계

  • Exp465 source, interpolation, C0 replay, qualification, publication 구조를 복사하지 말고 명시적인 Exp466 adapter와 새 P9 evidence 경계로 재사용한다.
  • 수식·결정성·scale/level 불변성·period 민감도·C0 exact parity·raw evidence replay를 단위 테스트한다.
  • 새 score source 전체 실행 전 CPU와 MLX의 동일 입력·seed parity 및 실제 속도를 확인한다. 후보 index가 같고 전체 단계가 1.1× 이상 빨라질 때만 MLX를 사용한다. 아니면 CPU로 고정한다.
  • 결과는 canonical 7 leaves와 HTML dashboard snapshot으로 남기고, 두 private 실행의 byte/hash equality를 확인한다.
