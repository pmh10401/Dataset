3. 주 후보의 1차원 특징

점진 합성은 index 56부터 시작한다. 따라서 변화 이전 앞부분만으로 중심과 눈금을 고정한다.

  1. prefix = x[0:56]
  2. center = median(prefix)
  3. scale = 1.4826 × median(abs(prefix - center)). 0 또는 비유한 값이면 실패한다.
  4. z = (x - center) / scale
  5. 길이 140의 고정 벡터 b를 만든다. b[0:56]=0, b[56:140]=linspace(0,1,84), 이후 L2 norm으로 나눈다.
  6. 부호 있는 경사 점수는 정확히 f = dot(z,b)다.

이 특징은 합성 gradual 변화가 추가하는 뒤쪽 선형 ramp와 같은 모양을 직접 측정한다. LocalGap, 학습 가중치, fold별 선택은 사용하지 않는다.

4. 순위와 보수적 결합

  • query 점수 s의 순위는 (1 + count(r_i ≤ s)) / (n + 1)이다.
  • r461은 reviewed Exp461 hydra_period_rank_max 순위다.
  • rramp는 앞부분 기준 경사 점수 순위다.
  • 고정 확신 문턱은 기존 α=0.005에서 파생한 1-α = 0.995다.
  • 주 후보 hydra_period_ramp_gated_max는 rramp ≥ 0.995이면 max(r461,rramp), 아니면 정확히 r461다.

새 특징이 매우 확실할 때만 기존 점수를 바꾼다. 확신이 낮으면 Exp461로 돌아가므로 period fold 3의 손상을 줄이는 것이 목적이다.

6. 합격 조건

주 후보 M2만 아래 조건을 모두 만족해야 한다.

  • 10개 seed-fold 기록 모두 통과
  • 네 변화 유형 AUC 각각 ≥0.85
  • 각 기록의 네 유형 평균 AUC ≥0.90
  • 정상 Wilson 상한 ≤0.05, 모든 점수 유한
  • 전체 gradual 최소 ≥0.85이며 0.8402306222021025보다 엄격히 큼
  • 전체 period 최소 ≥0.907392736783864
  • seed 20260721 fold 3 period ≥0.907392736783864
  • seed 20261721 fold 4 period ≥0.9216148584075248

중단: 하나라도 실패하면 공식 실행을 하지 않는다. α, onset, 가중치, seed, fold, 문턱을 바꾸거나 실패 fold를 제외하지 않는다.
