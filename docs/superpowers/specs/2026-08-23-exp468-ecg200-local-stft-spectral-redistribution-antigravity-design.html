Exp468 — ECG200 국소 STFT 주파수 재분배 자격 검증

한 줄 목표: ECG200 한 박동의 뒷부분에서 주파수 구성이 달라지는지를 찾고, 신호가 확실할 때만 기존 C0 점수를 보완한다.
현재 상태: 대화에서 개념 설계와 “ECG200 주기 변화만 주목표로 검증”하는 범위를 승인했다. 이 HTML은 구현 전 최종 문서 검토본이며, 아직 점수 계산이나 공식 실험을 실행하지 않았다.

1. 왜 새 실험이 필요한가

Exp466 결과C9 합격은 0/10이었다. period AUC는 모든 fold에서 0.85보다 낮았고 범위는 0.6862244897959183~0.826530612244898였다.
C0보다 개선period AUC가 C0보다 좋아진 fold는 0/10이었다. 8개는 같고 2개는 더 나빴다.
확인 신호period 확인 신호가 없던 fold가 8/10이었다. 낮은 문턱으로 바꾸는 대신 다른 신호 구조가 필요하다.
다음 질문파형 전체나 한 번의 위상 역정렬이 아니라, 뒷부분의 주파수 구성이 시간에 따라 달라졌는지를 보면 period 변화가 분리되는가?

2. 후보 비교와 최종 선택

방법장점이번 판단
국소 STFT짧은 구간을 차례로 보며 주파수 변화 위치를 남긴다. 모든 값을 샘플 번호로 고정할 수 있다.선택. 숨은 조정값이 가장 적고, 공개 데이터에 없는 실제 Hz 정보를 가정하지 않는다.
Morlet CWT여러 크기의 파동을 동시에 보므로 시간축 확대에 자연스럽다.보류. OpenRouter의 Ox Alpha와 Gemini 2.5 Pro가 추천했지만, 적절한 scale을 주파수로 해석하려면 sampling period가 필요하다. ECG200 공개 설명에는 그 값이 없다.
Wavelet packet주파수 띠별 에너지 비교가 쉽다.보류. wavelet 기저, 분해 깊이와 트리 선택이 추가되어 이번 단일 후보 원칙보다 선택 자유도가 크다.

STFT는 이동 창마다 FFT를 계산해 시간에 따른 스펙트럼 변화를 수치화한다. Hann 창의 50% overlap은 전력 추정과 중복 계산 사이의 일반적인 절충이다. CWT는 유용한 후속 후보지만, PyWavelets 공식 설명도 wavelet과 sampling period에 맞춰 scale을 골라야 하며 너무 작은 scale은 aliasing을 만들 수 있다고 경고한다.

3. 고정 입력과 범위

  • 실험 번호는 Exp468이다. 다른 작업에서 이미 사용 중인 Exp467을 건드리지 않는다.
  • 데이터는 ECG200 TRAIN 100개 중 정상 +1 69개만 사용한다. TEST 파일과 TEST 라벨은 열지 않는다.
  • TRAIN 파일 MD5는 기존과 같은 808875aeac1c358a90c630fe369327c4여야 한다.
  • 각 행은 기존의 정확한 선형 보간으로 96→140 변환한다.
  • seed는 20260721, 20261721, fold는 각각 5개로 고정한다.
  • onset은 56, 분석할 suffix는 [56:140]의 84개 값이다.
  • level shift, gradual drift, amplitude scaling, period change의 생성식·크기·행 순서는 Exp466과 같게 유지한다.
  • 주목표는 period change다. 다른 세 변화는 C0 성능을 해치지 않는지 확인하는 보호 기준이다.

4. 유일한 새 점수 S10

한 행의 suffix 84개를 시작점 0, 14, 28, 42, 56에서 길이 28로 자른다. 따라서 완전한 창 다섯 개만 사용하고 경계 padding은 하지 않는다.

  1. 각 창에서 평균을 빼 level 차이를 제거한다.
  2. 길이 28의 Hann 창을 곱하고, 길이 28의 one-sided real FFT를 계산한다.
  3. 전력을 제곱 크기로 만들고 DC bin을 버린다. 남은 14개 값에는 Nyquist bin이 포함된다. 각 값에 1e-12를 더한 뒤 합이 1이 되도록 나눈다. amplitude 배율은 이 정규화에서 사라진다.
  4. 각 시간 창마다 정상 fit 행들의 주파수 분포를 성분별 중앙값으로 합친 뒤 다시 합이 1이 되게 만든다.
  5. 한 행의 각 창 분포와 정상 중앙값 분포 사이 Jensen–Shannon divergence를 계산한다.
  6. 다섯 divergence의 중앙값을 그 행의 원시 S10 점수로 사용한다. 한 창의 우연한 변화가 전체 확인 신호가 되는 것을 막는다.
m = (p + q) / 2
JS(p, q) = 0.5 * KL(p || m) + 0.5 * KL(q || m)
S10(row) = median(JS(window_0), ..., JS(window_4))

fit 정상 점수는 각 행을 제외한 leave-one-out 중앙값 분포로 계산한다. query 정상과 네 합성 변화는 전체 fit 정상만으로 만든 중앙값 분포와 비교한다.

5. 순위, 확인, 보수적 결합

원시 점수는 기존과 같은 TRAIN-normal anomaly rank로 바꾼다.

S10_rank(query) = (1 + count(fit_score <= query_score)) / (n_fit + 1)

확인 조건은 rank 이전의 원시 JS 발산에 대해 S10_raw(query) > 0이면서 S10_raw(query) > max(fit_normal_S10_raw)일 때로 고정한다. 학습 문턱, alpha, grid search는 없다.

6. 합격 조건

C10은 아래 조건을 모두 만족해야 한다.

  1. 10개 seed-fold의 모든 원시 점수, 순위와 AUC가 finite다.
  2. period-change AUC가 10개 모두 ≥0.85다. 이 값은 절대 법칙이 아니라 Exp460~466과 같은 난이도를 비교하기 위한 기준이다.
  3. period-change AUC가 10개 모두에서 같은 fold의 C0보다 엄격히 높다.
  4. period-change 확인 신호가 10개 fold 각각 1개 이상이다.
  5. level shift, gradual drift, amplitude scaling의 AUC가 어느 fold에서도 같은 C0보다 낮지 않다.
  6. 두 seed 각각에서 OOF 정상 69개의 확인 합계가 정확히 0이다.
  7. 서로 다른 private root의 두 순차 실행에서 결과 파일, 해시와 판정이 byte 단위로 같다.
평균 AUC 0.90을 별도 합격선으로 두지 않는 이유: 사용자가 이번 범위를 period 변화로 고정했다. 대신 period의 절대 성능·C0 개선과 나머지 세 유형의 무하락을 각각 직접 검사한다.

7. 중단 규칙

  • 조건 하나라도 실패하면 C10은 qualification 실패로 종료한다.
  • 실패 뒤 같은 실험에서 창 길이 28, hop 14, Hann 창, FFT 길이, 집계 중앙값, 확인식, seed, fold 또는 합격선을 바꾸지 않는다.
  • STFT가 실패해도 Exp468 안에서 CWT나 wavelet packet으로 바꾸지 않는다. 필요하면 새 실험으로 사전등록한다.
  • Exp468이 통과하기 전에는 ECG200 TEST·실제 잔여 FN·FP·F1, 라우팅, champion·pending·promotion을 평가하거나 변경하지 않는다.
  • 통과할 때만 별도 사용자 승인을 받아 실제 잔여 FN 구조 검증으로 이동한다.

8. 구현 전 검증 경계

  • 새 score-source 전체 실행 전에 동일 입력·seed의 CPU와 MLX를 비교한다. 모든 후보 index가 같고 수치 차이가 허용 범위 안이며 전송·동기화 포함 1.1× 이상 빠를 때만 MLX를 사용한다.
  • 작은 5×28 STFT에서는 CPU가 유력하지만, 실제 benchmark 전에는 결론으로 기록하지 않는다.
  • 단위 검사는 정확한 창 위치, no-padding, DC 제거, amplitude·level 불변성, JS 수식, LOO 분리, strict confirmation, C0 fallback parity와 결정성을 확인한다.
  • 결과 대시보드는 설계·구현·private qualification 상태와 합격 기준을 같은 HTML에서 보여준다. 완료된 단계는 항상 체크한다.
