3. 주기 특징을 만드는 방법

각 길이 140 파형을 전체 [0:140], 앞 절반 [0:70], 뒤 절반 [70:140]의 세 구간으로 본다. 각 구간은 중앙값을 빼고 1.4826 × MAD로 나눠서 단순한 높이 차이보다 모양과 속도 차이에 집중한다. MAD가 0 이하이거나 결과가 유한하지 않으면 즉시 실패한다.

  1. numpy.hanning 창을 곱한 뒤 numpy.fft.rfft 전력값을 구한다.
  2. 0Hz 성분은 제외하고 남은 양의 주파수 bin을 numpy.array_split 순서 그대로 16개 묶음으로 나눈 뒤 각 묶음의 합을 구한다.
  3. 16개 값의 합이 1이 되도록 나눠서 파형 크기의 영향을 줄인다.
  4. 같은 표준화 구간 z에서 lag 1부터 24까지 dot(z[:-lag], z[lag:]) / dot(z, z) 자기상관을 계산한다.
  5. 구간마다 40개 값, 총 3 × (16 + 24) = 120개의 고정 특징을 만든다.

FFT 전력은 어떤 주파수에 힘이 몰렸는지 보여주고, 자기상관은 비슷한 모양이 몇 칸 뒤에 반복되는지 보여준다. 앞·뒤 절반을 따로 계산하므로 파형 중간에 주기가 변하는 상황도 볼 수 있다.

두 순위 중 큰 값

두 점수는 숫자 크기가 서로 다르므로 그대로 더하지 않는다. 각 branch의 정상 reference 점수 r가 n개이고 새 점수가 s일 때, 이상 순위는 (1 + count(rᵢ ≤ s)) / (n + 1)로 고정한다. 결합 점수는 두 이상 순위의 max이다. 따라서 기존 방식이나 주기 방식 중 하나라도 강한 이상 신호를 보이면 결합 점수가 반응한다.

5. 합격 기준

주 성공 조건: hydra_period_rank_max가 아래 조건을 10개 seed-fold 기록에서 모두 만족해야 한다.
  • period_change AUC ≥ 0.85 — 기존에 실패한 두 fold도 반드시 포함한다.
  • 네 변화 유형 각각의 AUC가 모두 0.85 이상이다.
  • 네 유형의 평균 AUC가 0.90 이상이다.
  • 정상 오경보 Wilson 상한이 0.05 이하이고 모든 점수가 유한하다.
  • 기존 두 실패 fold의 period-change AUC가 각각 기존 값보다 엄격히 높아야 한다.

한 건이라도 실패하면 “주기 특징 후보는 아직 라우팅에 사용할 준비가 안 됨”으로 결론낸다. 합격선을 낮추거나 특정 fold를 제외하지 않는다.

새 점수 소스이므로 전체 실행 전에 CPU와 MLX를 같은 입력으로 한 번 비교한다. 후보 순서가 완전히 같고 수치 차이가 허용 범위 안이며 MLX가 1.1배 이상 빠를 때만 MLX를 사용한다. 그렇지 않으면 작은 1,413×140 계산에 더 단순한 CPU NumPy 경로를 유지한다.
