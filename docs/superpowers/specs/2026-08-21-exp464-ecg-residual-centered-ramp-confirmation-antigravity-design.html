3. 고칠 대상

  1. Exp463의 ramp 기저는 뒤쪽 값이 모두 0 이상이라 실제 기울기뿐 아니라 단순한 높이 상승에도 반응했다.
  2. TRAIN에서 0.995보다 드문 점수라는 사실은 그 모양이 gradual이라는 뜻이 아니었다.
  3. 잘못 높아진 점수에 max를 적용하면 정상·period 순위가 올라가도 되돌릴 수 없었다.

Exp464는 임계값을 미세 조정하지 않는다. 특징이 읽는 모양 자체를 바꾼다.

4. 주 후보의 정확한 특징

각 fold에서 fit 행만 사용해 시간 위치별 median template를 만든다.

  1. template = np.median(X_fit, axis=0), j=0..139. NumPy의 짝수 길이 median 규칙을 그대로 사용한다.
  2. 각 행의 residual은 e = x - template다.
  3. 변화 시작점은 기존과 같은 onset=56이다. 뒤쪽 residual은 u=e[56:140]다.
  4. 단순 높이 이동을 제거한다: v = u - mean(u).
  5. t=np.linspace(0.0,1.0,84,dtype=np.float64), q=(t-mean(t))/||t-mean(t)||₂. q의 합은 0이므로 일정한 높이 이동은 점수에 영향을 주지 않는다.
  6. 상승 크기 점수는 a=dot(v,q)다.
  7. 상승 모양 일치도는 c=dot(v,q)/||v||₂다. ||v||₂=0이면 c=0으로 고정한다.
  8. 상승 크기 순위는 fit 행 점수만 사용해 r=(1+count(a_fit≤a))/(n_fit+1)로 계산한다.

template과 a_fit은 해당 fold의 비주입 fit 원본 행만 사용한다. 각 query 원본 행과 그 행에서 만든 네 합성 변형에 아래 식을 서로 독립적으로 적용한다. 정상 행의 cosine으로 합성 행의 gate를 대신 결정하지 않는다. template, fit score, rank reference는 fold 밖으로 공유하지 않는다. prefix MAD는 사용하지 않는다.

5. 보수적 확인 규칙

주 후보 template_residual_centered_ramp_confirmed_max는 다음과 같이 고정한다.

e = x - template
u = e[56:140]
v = u - mean(u)
a = dot(v, q)
c = 0 if ||v||₂ == 0 else a / ||v||₂
r = (1 + count(a_fit <= a)) / (n_fit + 1)

if c >= 0.95:
    result = max(M0_rank, r)
else:
    result = M0_rank
  • c≥0.95는 뒤쪽 residual과 시간 인덱스 사이 Pearson 상관의 사전등록 하한이다. 완전한 선형 상승은 c=1이고 중심화 후 일정한 높이 이동은 c=0이다. 0.95 자체가 유일한 기하학적 값이라는 주장은 하지 않는다.
  • 0.95는 실패 fold, C3–C5 결과 또는 다른 문턱 비교를 보고 바꾸지 않는다.
  • Exp463의 0.995 TRAIN 꼬리 gate는 주 후보에서 사용하지 않는다.
  • 상승 모양이 확인되지 않으면 점수는 정확히 M0로 돌아간다.

이 규칙은 “드문 값인가?” 대신 “실제로 선형 상승과 같은 모양인가?”를 먼저 묻는다.

7. 반드시 기록할 진단

  • 각 seed-fold와 변화 유형별 cosine≥0.95 발화 행 수
  • normal, gradual, period, level, amplitude별 발화 비율
  • C0와 비교해 새 점수가 바로잡은 normal-vs-gradual 순위 쌍 수와 새로 망친 쌍 수. 각 seed-fold에서 모든 query 정상 N_i와 gradual G_j의 순서쌍을 사용한다. score(G_j)>score(N_i)만 올바른 쌍이며 동점은 바로잡음·망침 어느 쪽에도 넣지 않는다.
  • 같은 정의로 normal-vs-period 순위 쌍의 바로잡음·망침 수를 기록한다.
  • 각 방법의 fold별 네 유형 AUC, pooled AUC, 정상 Wilson 상한, finite 여부

이 진단은 원인을 설명하기 위한 것이며 문턱을 다시 고르는 데 사용하지 않는다.

8. C6 합격 조건

주 후보 C6만 다음 조건을 모두 만족해야 한다.

  • 10개 seed-fold 기록 모두 통과
  • 네 변화 유형 AUC 각각 ≥0.85
  • 각 기록의 네 유형 평균 AUC ≥0.90
  • 정상 Wilson 상한 ≤0.05, 모든 점수 유한
  • 전체 gradual 최소 ≥0.85이며 C0의 0.8402306222021025보다 엄격히 큼
  • 각 seed-fold의 gradual AUC가 같은 기록의 C0 gradual AUC보다 낮지 않음
  • 전체 period 최소 ≥0.907392736783864
  • 각 seed-fold의 period AUC가 같은 기록의 C0 period AUC보다 낮지 않음
  • seed 20260721 fold 3 period ≥0.907392736783864
  • seed 20261721 fold 4 period ≥0.9216148584075248

중단: 하나라도 실패하면 공식 실행을 하지 않는다. cosine, onset, seed, fold, 합격 기준을 바꾸거나 실패 기록을 제외하지 않는다.

10. 실행 경계

  • 구현 후 서로 다른 private TRAIN root에서 evaluate→inspect를 정확히 두 번 순차 실행한다.
  • 두 결과의 rows, summaries, decision, dashboard와 모든 leaf bytes/hashes가 같아야 한다.
  • private 자격 검증과 fresh review가 통과한 뒤에만 별도 사용자 승인으로 공식 실행한다.
  • MLX는 같은 입력·seed에서 finite, 후보 순서, 사전등록 수치 허용오차와 1.1배 속도를 모두 만족할 때만 사용한다. 아니면 NumPy CPU를 유지한다.
  • 진행 상황과 결과는 쉬운 한국어 HTML 대시보드에 기록한다.
