Exp456 데이터셋 이름 결합 수정 설계

한 문장 목표: Exp455에서 서로 다른 목록 순서 때문에 중단된 평가를, 각 행의 dataset 이름으로 정확히 연결하도록 고쳐 같은 라우팅 성능을 계산한다.

1. 왜 새 실험이 필요한가

Exp455 공식 평가는 성능 계산 전에 한 번 실패했고 재실행하지 않는다. 실패 원인은 다음과 같다.

목록실제 순서
특징 8행ECG5000 5개 → ChlorineConcentration 3개
authority 대상 8행ChlorineConcentration 3개 → ECG5000 5개

두 목록에는 같은 8개 데이터셋이 있었지만, Exp455 평가기는 같은 위치에 같은 데이터셋이 있어야 한다고 검사했다. 그 결과 ValueError: features must match authority targets in order로 중단되었다.

2. 승인된 결정

유일한 과학적 변경: 목록의 위치가 아니라 dataset 이름으로 authority·특징·라우팅 결정을 1:1 연결한다.
  • authority의 동결 원본 순서는 바꾸지 않는다.
  • 특징과 공개 결과의 승인 순서는 ECG5000 5개 → ChlorineConcentration 3개로 유지한다.
  • 모델, 특징 정의, LODO 규칙, 후보 기법, 성능 기준은 바꾸지 않는다.

  1. Exp455와 동일하게 Exp454의 48개 데이터셋 결과와 8개 label-free 특징을 읽는다.
  2. authority 대상 8행을 dataset → row 표로 만든다.
  3. 특징의 승인 순서대로 같은 이름의 authority 행을 찾는다.
  4. 각 결합에서 dataset·family·method·target length가 모두 맞는지 확인한다.
  5. 기존 LODO 라우터와 평가 계산을 그대로 실행한다.

6. 바뀌지 않는 과학 조건

  • 대상은 ECG5000 5개와 ChlorineConcentration 3개, 총 8개다.
  • 후보는 ECG5000의 Hydra LocalGap과 ChlorineConcentration의 MultiRocket LocalGap뿐이다.
  • 나머지 40개 데이터셋은 baseline을 유지한다.
  • 비교는 always_baseline, family_wide_local_gap, oracle_per_dataset, lodo_router 순서다.
  • 전체 FN은 1,988 미만, FP는 314 이하, F1은 0.6264199935 이상이어야 한다.
  • 두 대상 가족의 FN은 각각 baseline보다 나빠지면 안 된다.
  • 라우터 입력은 TEST 정답과 confusion 값을 사용하지 않는다.
  • 새 학습, 새 특징, 새 점수원, MLX 변경, 후보 추가, 자동 승격은 없다.

7. 정확한 결합 계약

평가기는 다음 조건을 모두 만족해야 계산을 시작한다.

  1. authority 대상 이름과 특징 이름의 집합이 정확히 같다.
  2. 두 쪽 모두 이름이 중복되지 않는다.
  3. 각 이름의 family가 같다.
  4. authority의 method가 그 family에 승인된 method와 같다.
  5. 특징의 target length가 해당 authority 행의 target length와 같다.
  6. 라우팅 결정 8개도 같은 이름 집합을 가지며 각 family·method가 맞는다.

검사를 통과하면 계산 순서는 특징의 승인 순서로 고정한다. 따라서 authority 원본 순서가 달라도 결과는 같아야 한다.

8. 결과 파일과 재검산

Exp455의 8개 결과 파일 이름, 내용 구조, 재계산 규칙을 유지한다. 실험 번호와 결과 해시만 Exp456으로 달라질 수 있다.

  • 평가 결과 4행의 FN·FP·F1
  • 8개 LODO 결정과 가족별 FN 변화
  • 결합에 사용한 8개 dataset 이름과 승인 출력 순서
  • 자체 제외 방식의 결과 파일 SHA-256 목록

inspect는 저장된 결과를 다시 이름으로 결합하고, 같은 LODO 결정과 같은 합계를 얻어야 성공한다.

9. 실패 처리

다음 중 하나라도 발견되면 성능 계산과 결과 발행을 중단한다: 중복 이름, 누락 또는 추가 이름, 잘못된 family·method·target length, 8개가 아닌 특징·결정, 재계산 불일치.

Exp455는 재실행하지 않는다. Exp456 공식 평가도 구현과 독립 검토가 끝난 뒤 사용자의 별도 승인을 받아 한 번만 수행한다.

12. 완료 기준

  • 이름 결합 회귀시험과 Exp455 회귀시험이 모두 통과한다.
  • Exp455 코드·공식 실패 기록·결과 부재 상태가 그대로다.
  • 독립 검토에서 결과에 영향을 주는 결함이 없다.
  • 별도 승인 뒤 공식 Exp456 평가와 inspect가 성공하고, 대시보드가 실제 결과와 일치한다.
해석 한계: 이 수정은 새 라우팅 기법을 만드는 것이 아니다. Exp455가 계산하지 못했던 기존 라우터의 성능을 올바르게 계산할 수 있게 만드는 결합 계약 수정이다.
