Receipt state and durable commit point

Successful leaves are exactly readiness_complete_antigravity.json, predict_started_antigravity.json, predict_complete_antigravity.json, evaluate_started_antigravity.json, evaluate_complete_antigravity.json, inspect_started_antigravity.json, and inspect_complete_antigravity.json. Every leaf is canonical single-link regular no-follow descriptor-pinned JSON with exact fields schema, experiment_id, run_identity, reviewed_commit, phase, event, ordinal, previous_leaf_sha256, prediction_root_identity, evaluation_root_identity, and permanent_stop. The first predecessor hash is null; no timestamps, PID, random value, or nondeterminism is permitted.

The directory and each leaf are created/write/fsync’d no-follow, then the leaf and directory are fsync’d and the name, inode identity, link count, type, canonical bytes, inventory, and predecessor descriptor are revalidated. A successful *_complete_antigravity.json leaf is that invocation’s final durable commit point: after its durable create/write/fsync/revalidation, the wrapper returns immediately. No later operation may reclassify that invocation or create stopped_antigravity.json. A crash before that point leaves only started/partial/invalid receipt state and blocks every later phase permanently.

Independent receipt classification: valid owned means the descriptor-validated fixed schema, experiment identifier, run identity, reviewed commit, root identities, ordinal/predecessor hash chain, canonical bytes, regular single-link no-follow leaves, and exact inventory all bind; it never means merely filename-shaped. The only valid owned inventories are: S0: receipt directory absent, initial namespace candidate (before readiness); S1: readiness-complete; S2: S1 + predict-started; S3: S2 + predict-complete; S4: S3 + evaluate-started; S5: S4 + evaluate-complete; S6: S5 + inspect-started; S7: S6 + inspect-complete. STOPPED: an otherwise valid prefix plus terminal stopped; always reject without mutation. INVALID: foreign, partial, noncanonical, reordered, surplus, replaced, symlinked, multi-link, or receipt-write-failed state; reject byte-identically, no stopped. stopped_antigravity.json has the same fields, event="stopped", and permanent_stop=true; it binds the primary failure phase and exact predecessor hash. Started, complete, and stopped leaves are mutually exclusive where their sequences conflict: stopped is terminal and no later success leaf is permitted.

Audit occupancy and failures

The mandatory ordering is: classify and descriptor-validate receipt state; detect audit occupancy before normal phase work; INVALID or STOPPED rejects without mutation; if a valid S-state has audit occupancy, root/path precondition failure, or a non-exact command predecessor, append stopped, then make one create-only/no-overwrite best-effort audit attempt, preserve an occupied audit byte-for-byte, and raise the primary; only exact predecessor + absent audit + valid path preconditions may do phase work. Occupied or symlinked prediction, evaluation, and audit paths remain preserved as already specified. Receipt byte-preservation applies only to INVALID, foreign, partial, noncanonical, replaced, symlinked, multi-link, or otherwise unowned receipt namespaces. A descriptor-valid owned S1–S7 receipt directory is not generic occupied state: during a failed, direct, repeated, or out-of-order invocation, its only permitted mutation is a single governed terminal stopped_antigravity.json append, followed by no later receipt leaf. In particular, S0 absent receipt may create the governed directory and stopped leaf for a failed precondition such as an occupied audit; preserve that audit, make the no-overwrite audit attempt, and stop. Audit failure is secondary and never masks the primary error; later phases stay blocked. INVALID does not qualify for stopped and remains untouched.

The audit is canonical JSON with phase, root_destinations, recovery_state, primary_error, cleanup_notes, and permanent_stop; root destinations is exactly [] for readiness and otherwise ordered prediction/evaluation path strings.
