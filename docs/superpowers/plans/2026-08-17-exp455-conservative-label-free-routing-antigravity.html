Exp455 보수적 라우팅 구현 계획

작업자 필수 절차: 각 Task는 superpowers:subagent-driven-development 또는 superpowers:executing-plans로 하나씩 실행한다. 모든 단계의 체크박스는 실제 완료 직후에만 체크한다.

목표: ECG5000의 Hydra LocalGap과 ChlorineConcentration의 MultiRocket LocalGap만 대상으로, 정답 없는 특징을 사용하는 leave-one-dataset-out 라우터를 만들고 전체 FN·FP·F1 기준을 평가한다.

구조: Exp454와 Exp404/Exp446의 동결 결과를 읽는 authority 계층, 정답 없는 특징 계층, 단순 규칙을 고르는 router 계층, 저장된 confusion으로 결과를 계산하는 evaluation 계층을 분리한다. 라우팅 규칙 선택은 가족별로 검증 데이터셋을 하나씩 제외해 수행한다.

기술: Python 3.14, 표준 라이브러리, dataclasses, unittest, 정적 HTML, 기존 Exp454/Exp448 source-free capture 함수.

승인된 설계: docs/superpowers/specs/2026-08-17-exp455-conservative-label-free-routing-antigravity-design.html, SHA-256 ae391bdaa9b34b8d603722262887143e0bdf8284bdcbf0fa1b059d4841c0369a.

Global Constraints

  • 실험 ID는 Exp455, 종류는 conservative_label_free_routing다.
  • 새 파일 이름은 모두 antigravity를 포함하며 새 __init__.py를 만들지 않는다.
  • 후보는 ECG5000 + Hydra LocalGap, ChlorineConcentration + MultiRocket LocalGap 두 개뿐이다.
  • 대상 8개 외 40개 데이터셋은 baseline을 그대로 사용한다.
  • 라우터 입력에 TEST 정답, confusion 값, 데이터셋 변형 번호를 넣지 않는다.
  • 주요 기준은 FN < 1,988, 안전 기준은 FP ≤ 314와 F1 ≥ 0.6264199935다.
  • Exp455는 새 score source가 아니므로 MLX 평가는 적용하지 않는다.
  • 공식 Python은 /Users/mac/Documents/Dataset/venvs/detection-coverage-antigravity-aeon140-py314/bin/python으로 고정한다.
  • 설계·계획·사전등록·runbook·구현 기록·대시보드는 HTML로 작성한다.
  • 각 코드 변경 전 현재 Exp455 code map에서 callers, effects, tests를 확인하고 같은 커밋에 map을 동기화한다.
  • Task 6 전에는 공식 Exp455 결과 폴더를 만들거나 공식 평가 명령을 실행하지 않는다.

    def threshold_rules_antigravity(feature_name, values):
    ordered = sorted(set(values))
    rules = [RouteRuleAntigravity(None, None, "never"), RouteRuleAntigravity(None, None, "always")]
    for left, right in zip(ordered, ordered[1:]):
        threshold_twice = left + right
        rules.extend((RouteRuleAntigravity(feature_name, threshold_twice, "lte"), RouteRuleAntigravity(feature_name, threshold_twice, "gt")))
    return tuple(rules)

def applies_antigravity(rule, value):
    if rule.candidate_when == "never": return False
    if rule.candidate_when == "always": return True
    return 2 * value <= rule.threshold_twice if rule.candidate_when == "lte" else 2 * value > rule.threshold_twice
