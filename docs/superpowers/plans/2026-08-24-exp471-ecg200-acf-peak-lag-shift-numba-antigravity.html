Exp471 ECG200 ACF peak-lag 이동 Numba 구현 계획

For agentic workers: 구현 시 superpowers:subagent-driven-development(권장) 또는 superpowers:executing-plans를 반드시 사용한다. 각 단계는 아래 HTML checkbox로 추적한다.

목표: ECG200 TRAIN-only에서 앞·뒤 ACF peak-lag 이동 한 가지가 C0의 잔여 정상–period 순서 오류를 안전하게 고치는지 Numba로 검증한다.

구조: Exp470의 입력·보간·합성 변화·C0·pair-repair authority를 정확히 가져오고, Exp471은 ACF peak-lag, E12/C12 결합과 해당 raw evidence만 새로 구현한다. 새 수치 경로는 Numba 하나이며 Python 기준 검사와 MLX 적격성 smoke는 결과 실행 전에 끝낸다.

기술: Python 3, Numba, llvmlite, 기존 ndarray 기반 Exp470 authority, unittest, canonical JSON/JSONL, self-contained HTML.

설계서: Exp471 승인 설계서

전역 제약

  • 새 파일 이름에는 모두 antigravity가 포함되어야 한다.
  • ECG200 TRAIN 정상 69개, 96→140 보간, seed (20260721, 20261721), blocked fold 5개와 네 합성 변화는 Exp470 authority 그대로다.
  • 새 후보는 E12 ACF peak-lag 이동 하나뿐이며 방법 순서는 ("C0","E12","C12")다.
  • 창은 [0:56], [84:140], ACF 계산 lag는 1..25, peak 후보는 2..24다. 다른 창과 lag를 탐색하지 않는다.
  • median은 짝수일 때 가운데 두 값의 산술평균이다. peak 동점은 작은 lag, peak 없음은 integer 0이다.
  • 새 점수의 production backend는 float64 Numba, fastmath=False, cache=False 하나다. NumPy scorer나 자동 fallback은 만들지 않는다.
  • Python 기준 대비 ACF·raw 최대 오차는 1e-12 이하여야 하며 peak lag·rank·confirmation·fixed/broken은 정확히 같아야 한다.
  • MLX는 전체 실행 전에 적격성만 평가하고 Numba authority를 대신하지 않는다.
  • 절대 AUC 0.85를 gate로 사용하지 않는다. seed별 period fixed/broken과 보호 변화 broken, 정상 confirmation, exact fallback이 성능 gate다.
  • official 실행, TEST/FN 접근, routing은 금지한다. private 실행 1·2도 Task 6 완료 뒤 별도 승인을 받아야 한다.
  • Ox Alpha Ultra가 구현에 참여하면 공식 폴더와 분리된 전용 worktree만 쓰고, Codex가 diff·테스트·결과를 최종 검증한다.
  • 각 Task는 RED 확인 → 최소 구현 → GREEN 두 번 → code map 갱신 → 독립 검토 → commit 순서로 끝낸다.

def median_python_antigravity(values):
    ordered = sorted(float(value) for value in values)
    middle = len(ordered) // 2
    return ordered[middle] if len(ordered) % 2 else (ordered[middle - 1] + ordered[middle]) / 2.0

def peak_shift_row_python_antigravity(row):
    peaks = []
    presence = []
    for start in (0, 84):
        window = [float(value) for value in row[start:start + 56]]
        center = median_python_antigravity(window)
        mad = median_python_antigravity(abs(value - center) for value in window)
        scale = 1.4826 * mad
        if not math.isfinite(scale) or scale <= 0.0:
            raise ValueError("window MAD must be positive and finite")
        z = [(value - center) / scale for value in window]
        denominator = math.fsum(value * value for value in z)
        acf = [math.fsum(z[t] * z[t + lag] for t in range(56 - lag)) / denominator for lag in range(1, 26)]
        candidates = [(acf[lag - 1], lag) for lag in range(2, 25) if acf[lag - 1] > 0.0 and acf[lag - 1] > acf[lag - 2] and acf[lag - 1] >= acf[lag]]
        peak = min((-value, lag) for value, lag in candidates)[1] if candidates else 0
        peaks.append(peak)
        presence.append(bool(candidates))
    return peaks[0], peaks[1], presence[0], presence[1], peaks[1] - peaks[0]
@numba.njit(cache=False, fastmath=False)
def dominant_peak_from_acf_numba_antigravity(acf):
    best_lag = 0
    best_value = -np.inf
    for lag in range(2, 25):
        value = acf[lag - 1]
        eligible = value > 0.0 and value > acf[lag - 2] and value >= acf[lag]
        if eligible and (value > best_value or (value == best_value and lag < best_lag)):
            best_value = value
            best_lag = lag
    return best_lag, best_lag != 0

@numba.njit(cache=False, fastmath=False)
def _window_peak_numba_antigravity(row, start):
    values = row[start:start + 56].copy()
    center = _median_copy_numba_antigravity(values)
    deviations = np.empty(56, dtype=np.float64)
    for index in range(56):
        deviations[index] = abs(values[index] - center)
    scale = 1.4826 * _median_copy_numba_antigravity(deviations)
    if not np.isfinite(scale) or scale <= 0.0:
        raise ValueError("window MAD must be positive and finite")
    z = (values - center) / scale
    denominator = 0.0
    for index in range(56):
        denominator += z[index] * z[index]
    acf = np.empty(25, dtype=np.float64)
    for lag in range(1, 26):
        numerator = 0.0
        for index in range(56 - lag):
            numerator += z[index] * z[index + lag]
        acf[lag - 1] = numerator / denominator
    return dominant_peak_from_acf_numba_antigravity(acf)

def peak_shift_row_numba_antigravity(row):

    late, late_present = _window_peak_numba_antigravity(row, 84)

@numba.njit(cache=False, fastmath=False)
def assemble_raw_rank_numba_antigravity(fit_shifts, query_shifts):
    fit_raw = np.empty(fit_shifts.size, dtype=np.float64)
    for excluded in range(fit_shifts.size):
        others = np.empty(fit_shifts.size - 1, dtype=np.float64)
        position = 0
        for index in range(fit_shifts.size):
            if index != excluded:
                others[position] = fit_shifts[index]
                position += 1
        fit_raw[excluded] = abs(fit_shifts[excluded] - _median_copy_numba_antigravity(others))
    center = _median_copy_numba_antigravity(fit_shifts.astype(np.float64))
    maximum = np.max(fit_raw)
    query_raw = np.empty(query_shifts.size, dtype=np.float64)
    ranks = np.empty(query_shifts.size, dtype=np.float64)
    confirmed = np.empty(query_shifts.size, dtype=np.bool_)
    for query_index in range(query_shifts.size):
        raw = abs(query_shifts[query_index] - center)
        query_raw[query_index] = raw
        count = 0
        for fit_index in range(fit_raw.size):
            if fit_raw[fit_index] <= raw:
                count += 1
        ranks[query_index] = (1.0 + count) / (fit_raw.size + 1.0)
        confirmed[query_index] = raw > 0.0 and raw > maximum
    return fit_raw, query_raw, ranks, confirmed, maximum
