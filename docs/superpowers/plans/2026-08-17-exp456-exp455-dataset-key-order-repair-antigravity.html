Exp456 데이터셋 이름 결합 수정 구현 계획

작업 방법: Task를 하나씩 순서대로 진행한다. 각 Task는 RED → 최소 구현 → GREEN → 검토 → 커밋으로 끝낸다. 체크박스는 실제 완료 직후에만 체크한다.

목표: Exp455의 위치 기반 8행 비교를 데이터셋 이름 기반 결합으로 바꾸고, 나머지 과학 조건은 그대로 둔 채 공식 라우팅 성능을 계산할 수 있게 한다.

구조: Exp455를 Exp456 패키지로 통제 복사한다. authority와 특징의 원본 순서는 유지하고, 평가·재검산 경계에서만 이름으로 1:1 결합한다. 결과 파일과 대시보드의 성능 항목은 기존 구조를 유지한다.

기술: Python 3.14, 표준 라이브러리, dataclasses, unittest, 정적 HTML.
