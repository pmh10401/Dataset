Exp480 family 균형 경험 라우팅 구현 계획

Agentic workers: 이 계획을 구현할 때는 superpowers:subagent-driven-development 또는 superpowers:executing-plans를 사용하고, 각 체크박스를 실제 완료 직후에만 체크합니다.

목표: 데이터셋 이름을 방법 선택 특징으로 쓰지 않으면서, 같은 원본 family의 파생 데이터셋이 KNN 투표를 반복 지배하지 못하게 하고 잔여 FN을 성능 기준으로 줄일 수 있는지 검증합니다.

구조: 고정된 1,117개 데이터셋의 네 후보 점수와 TRAIN-only 7개 특징을 읽어 별도 SQLite 파생 경험 데이터베이스를 만듭니다. 라우터는 각 후보를 MiniRocket과 독립 비교하고, 가까운 데이터 중 family마다 가장 가까운 한 행만 투표에 남깁니다. 모든 판정은 out-of-family 방식으로 다시 계산하며 통과 전에는 공식 라우터를 수정하지 않습니다.

기술: Python 3.14, NumPy, SQLite, pytest, 선택적 MLX/MLX-Metal, 정적 HTML.

설계서: 2026-08-31 Exp480 설계서

전체 제약

  • family는 데이터셋 키의 첫 번째 _normal_ 앞부분으로만 정합니다. 이름이 비슷한 데이터셋을 추가로 묶지 않습니다.
  • 방법 선택 입력은 width, n_train, spectral_entropy, skewness, kurtosis, diff_std_ratio, zero_crossing_rate뿐입니다.
  • MiniRocket, MultiRocket, Hydra, Hydra+MultiRocket의 기존 1,117개 점수를 재사용합니다. 점수 계산 방식과 전처리는 바꾸지 않습니다.
  • 원본 DB, Exp474~479 결과, 기존 체크포인트와 공식 라우터는 읽기 전용입니다.
  • Exp480 파일 이름에는 모두 antigravity를 포함합니다.
  • Task 6 공식 실행은 별도 사용자 승인 전에는 실행하지 않습니다.
  • MLX는 동일 입력·시드에서 유한 출력, 후보 이웃 인덱스 완전 일치, 수치 허용오차 충족, 전송·동기화 포함 1.1배 이상 속도 향상을 모두 만족할 때만 사용합니다. 아니면 CPU를 사용하며 worker는 최대 7개입니다. MLX/MPS-heavy 프로세스는 한 번에 하나만 실행하고 MLX와 외부 다중 프로세스를 겹치지 않습니다.
  • 공식 결과 JSON에는 시각과 실행 시간을 넣지 않아 반복 실행의 결과 bytes가 같게 합니다. 시각·장치·실행 시간은 별도 실행 manifest에 기록합니다.

CREATE TABLE dataset_evidence(
  dataset TEXT PRIMARY KEY, source_family TEXT NOT NULL, proposal TEXT NOT NULL
);
CREATE TABLE train_features(
  dataset TEXT PRIMARY KEY REFERENCES dataset_evidence(dataset),

def build_evidence_database_antigravity(rows, target, provenance):
    temporary = target.with_name("evidence_temporary_antigravity.sqlite3")
    connection = sqlite3.connect(temporary)
    connection.executescript(SCHEMA_ANTIGRAVITY)
    for row in sorted(rows, key=lambda item: item.dataset):
        connection.execute("INSERT INTO dataset_evidence VALUES(?,?,?)",
                           (row.dataset, row.source_family, row.proposal))
        connection.execute("INSERT INTO train_features VALUES(?,?,?,?,?,?,?,?)",
                           (row.dataset, *row.features))
        connection.executemany("INSERT INTO candidate_metrics VALUES(?,?,?,?)",
            ((row.dataset, metric.method, metric.auc, metric.zf)
             for metric in row.scores))
    connection.executemany("INSERT INTO provenance VALUES(?,?)",
                           sorted(provenance.items()))
    assert connection.execute("SELECT count(*) FROM dataset_evidence").fetchone()[0] == 1117
    assert connection.execute("SELECT count(*) FROM candidate_metrics").fetchone()[0] == 4468
    assert connection.execute("PRAGMA foreign_key_check").fetchall() == []
    connection.execute("VACUUM")
    connection.close()
    temporary.replace(target)
    return sha256(target.read_bytes()).hexdigest()

def nearest_family_indices_antigravity(distances, families, k):
    chosen = []
    seen = set()
    for index in np.argsort(distances, kind="stable"):
        family = families[int(index)]
        if family not in seen:
            seen.add(family)
            chosen.append(int(index))
            if len(chosen) == k:
                break
    return np.asarray(chosen, dtype=np.int64)
