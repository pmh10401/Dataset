Scope and provenance

Exclude PigAirwayPressure, PigArtPressure and PigCVP: all their derived datasets have only4 normal TRAIN rows, incompatible with frozen5-fold scoring. Exp491 uses all 1117 existing rows. Exp489: fixed MiniRocket, LocalGap versus LOF

Freeze seed 20260721, 4096 requested kernels, original 5 folds and reference subsampling (max1000), RobustScaler(10,90), query chunks128. Fit one encoder per fold shared by both heads. LOF novelty=True, n_neighbors=min(3,nref-1), metric=minkowski,p=2, contamination=auto, n_jobs=1; higher anomaly score=-score_samples. Score only held-out/final queries. Same preprocessing as Exp479. Recompute paired LocalGap control. Freeze and persist scores before opening labels. Report mean AUC, total ZF, per-family deltas, wins/losses and harm. One arm, no tuning.

Exp490: normal-only behavioral descriptors

Four fixed Exp449 representations; same original 5 folds. Refit each fold twice with seed unchanged: A original reference, B sorted deterministic sample of max(2,floor(.8*nref)) capped at nref drawn only from A reference using seed+104729+fold_index. Held-out indices never used in either fit. For each model: two tail ratios (q95-q50)/(q75-q25+1e-9), (q99-q50)/(q75-q25+1e-9) from A OOF, and Spearman rank correlation of A/B OOF. Six pairwise Spearman correlations of models A OOF. Total18 features; constant correlation=0 with explicit diagnostic count. Only normal TRAIN loader, finite-row filtering and Exp479 lower-median standardization. Compare 24D vs42D features through identical Exp491 protocol on the same125 rows. No synthetic anomaly claims.

Exp491: cached gain prediction

Fixed Ridge alpha10, 6 outputs: three alternative-minus-MiniRocket AUC deltas and three signs of ZF deltas. Leave one whole source family out. Fit imputation medians, standardization mean/std and Ridge only on donors. Loss weight each donor row=1/(number of rows in its family), so each family total weight1. Constant comparator is donor family-weighted target mean. Report family-mean per-output squared error, paired loss changes, directional accuracy and gain-sign discrimination where both classes exist. No hyperparameter search, no local gate change, no outcome-chosen favorable neighbors, no route promotion. A failed linear probe does not rule out every model.

Runtime and verification

CPU-parallel stages use detected CPUs minus1 (currently12 ->11) and inner threads1. Every manifest records PyTorch/MLX/MPS/Numba assessment, versions, timing and fallback reasons. Official aeon/sklearn CPU algorithms remain canonical unless exact full-stage parity and speed are proven; no GPU rewrite for this study. Source hashes, code hashes, preregistration hash and result hash bind caches. Fail on unexpected population, stale cache, nonfinite data, source mutation, partial failures, or existing finalized results. Small deterministic smoke before real runs. Read-only DB. Grok receives source only, no raw data, TEST labels or secrets.
