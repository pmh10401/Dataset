Exp457 ECG5000 TRAIN 합성 이상 확신 라우팅 구현 계획

작업자 필수 방식: Task별 TDD와 검토를 사용한다. 각 단계가 끝나면 이 HTML의 해당 체크박스를 즉시 체크한다.

Goal: TRAIN에서 Hydra 후보의 신뢰도를 확인하고, 낮은 확신에서는 baseline으로 돌아가는 ECG5000 라우터를 만든다.

Architecture: Exp456의 불변 결과를 기준으로 새 Exp457 패키지를 만든다. TRAIN 전용 합성 이상 검증과 라벨 없는 탐지 구조 게이트가 모두 통과한 ECG5000만 Hydra를 사용하며, 결과는 집계 전용 HTML 대시보드에 표시한다.

Tech Stack: Python 3.14, NumPy 2.3.5, aeon 1.4.0, scikit-learn 1.7.2, 표준 라이브러리, unittest, 정적 HTML.

Global Constraints

  • 최종 설계: docs/superpowers/specs/2026-08-18-exp457-ecg-train-synthetic-confidence-routing-antigravity-design.html, SHA256 3b702e0224dd86e1d0c93268b8a2e2691ea3858cbd30a4792f9c6539c0424e20.
  • Exp456 기준 커밋은 58dae2d425de136cc02bfe665e54bff847418af3이며 Exp456 코드·문서·결과를 수정하지 않는다.
  • 새 과학 변화는 ECG5000 Hydra 선택 게이트 하나뿐이다.
  • ChlorineConcentration 세 데이터셋은 family-wide MultiRocket 후보로 고정한다.
  • Hydra 설정은 seed 20260721/20261721, 5-fold, alpha=0.005, kNN 3, kernels 8, groups 64를 유지한다.
  • 합성 이상은 Exp417의 level shift, gradual drift, amplitude scaling, period change 정의를 그대로 사용한다.
  • 게이트 1은 정상 OOF Wilson 95% 상한 ≤5%, pooled sensitivity ≥70%, 종류별 sensitivity ≥50%, 두 seed 모두 통과다.
  • 게이트 2는 정확히 added_count > removed_count다.
  • 최종 합격은 FN ≤834, FP ≤66, F1 >0.5764150943396227을 모두 만족해야 한다.
  • TEST 혼동행렬·FN·FP·F1은 라우팅 결정에 사용하지 않는다. 최종 결정 후 Exp456 불변 혼동행렬을 재집계할 때만 사용한다.
  • 모든 새 파일 이름에 antigravity를 포함하고 새 __init__.py는 만들지 않는다.
  • 문서는 HTML로 작성한다. 코드맵 정책 때문에 JSON/lock만 예외다.
  • 공식 결과 폴더는 /Users/mac/Documents/Dataset/exp457_ecg_train_synthetic_confidence_routing_antigravity_20260818다.
  • 공식 명령은 별도 사용자 승인 후 Task 6에서만 실행한다.
  • MLX는 공식 aeon Hydra를 다시 작성해야 하므로 적용 조건 1을 충족하지 않는다. CPU 구현을 유지한다.
