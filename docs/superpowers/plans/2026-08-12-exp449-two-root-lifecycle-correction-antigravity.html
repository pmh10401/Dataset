Exp449 two-root lifecycle correction implementation plan

For agentic workers: REQUIRED SUB-SKILL: use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Each checkbox is disabled and begins unchecked; do not mark controls until the named action, evidence, fresh Terra review, and fresh Sol review have actually completed.

Goal: replace the impossible single-root official lifecycle with a safe two-root readiness → predict → evaluate → inspect lifecycle while preserving Exp449 Tasks 1–6 and preventing any official command during implementation verification.

Architecture: Predict exclusively creates the immutable prediction-authority root and freezes 96 label-free candidates. Evaluate descriptor-captures that root before its sole label session, exclusively creates a separate evaluation-publication root with exactly 12 final leaves, and never changes prediction bytes. Bare inspect descriptor-captures both complete roots and performs source-free semantic replay. Failures permanently stop the experiment and use a create-only fixed audit without masking the primary error.

Tech Stack: Python 3.14.6; unittest; canonical JSON/JSONL; POSIX no-follow descriptors; SQLite read-only only in the evaluation label boundary; aeon 1.4.0 CPU transformers; NumPy 2.3.5; scikit-learn 1.7.2; git; self-contained HTML; JSON/lock code map.
