Exp461 ECG 주기 특징 성능 검증 구현 계획

작업자 필수 절차: superpowers:subagent-driven-development 또는 superpowers:executing-plans를 사용해 Task를 하나씩 실행한다. 완료된 Task와 Step의 HTML 체크박스는 검증과 검토가 끝난 뒤에만 체크한다.

목표: 기존 Hydra, 주기 특징 단독, 두 점수의 순위 결합을 같은 TRAIN blocked-fold 조건에서 비교하고, 결합 방식이 period-change 실패 2건을 포함해 10/10 합격하는지 판정한다.

구조: Exp460 공식 결과를 입력 권한으로 고정하고, Exp459의 TRAIN·fold·perturbation·Hydra 기준선을 그대로 재사용한다. 새 코드는 120차원 주기 특징과 세 방법 비교에만 집중하며, TEST label과 라우팅 적용은 포함하지 않는다.

기술: Python 3.14.6, NumPy 2.3.5, aeon 1.4.0, unittest, canonical JSON/JSONL, HTML dashboard.

설계서: Exp461 설계서 — SHA-256 3b1d6bc519a4acc000f45f30ba8ae5d610dcd0d2aa5e1cb61bd53837ba28f2c2.

Exp461의 성공은 “새 방법이 평균적으로 좋아 보인다”가 아니다. 주 후보가 같은 TRAIN blocked 검증 10건에서 모두 합격하고, 특히 기존의 period-change 실패 2건을 모두 0.85 이상으로 올려야 한다. 실패하면 라우팅이나 TEST 평가로 넘어가지 않는다.
