구조Exp465의 loader·96→140 보간·C0 replay·2×5 fold 경계를 그대로 사용한다. 새 P9 module은 정렬 전후 거리를 계산하고, C9은 정상 fit 최대 margin을 엄격히 넘는 query에서만 C0와 P9 rank의 max를 쓴다. qualification, canonical publication과 replay가 이 수학을 독립 재계산한다.

  • 모든 새 파일명은 antigravity를 포함한다.
  • ECG200 TRAIN 정상 69개만 사용한다. TEST 파일·라벨 query·공식 명령 수는 항상 0이다.
  • TRAIN MD5 808875aeac1c358a90c630fe369327c4, 입력 100×96, 정상 69, 보간 폭 140을 바꾸지 않는다.
  • seed (20260721, 20261721), 5 fold, onset 56, suffix 84, warp 1.25, 공유 길이 67을 바꾸지 않는다.
  • method order는 (C0, P9, C9), 유일한 primary candidate는 C9다. P9는 설명용이다.
  • C9 gate는 유형별 AUC ≥0.85, 평균 ≥0.90, period AUC가 매 fold C0보다 엄격히 높음, gradual AUC가 매 fold C0 이상, period confirmation 매 fold 1개 이상, seed별 정상 confirmation 정확히 0, finite, private 2회 exact equality다.

  • full run 전에 CPU/MLX 동일 입력·seed parity와 단계 전체 속도를 측정한다. 후보 index가 같고 MLX가 1.1× 이상 빠를 때만 MLX를 사용한다.
