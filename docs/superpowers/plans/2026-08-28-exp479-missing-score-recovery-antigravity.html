Exp479 성능 미산출 155개 복구 구현 계획

목표: 길이가 서로 달라 기존 평가에서 빠진 155개 데이터셋을 Numba 선형 재표본화로 복구하고, 기존 네 방법의 성능과 공식 라우팅 결과를 계산합니다. 기존 962개 결과는 다시 계산하거나 바꾸지 않고, 마지막에 155개 결과와 합쳐 1,117개 전체 수치를 만듭니다.

현재 판단: 파생 데이터셋 안의 TRAIN label=0은 정상 클래스가 맞습니다. 데이터셋 이름의 _normal_숫자는 원본에서 어떤 라벨을 정상으로 골랐는지를 나타낼 뿐이며, Exp479 대상 선정 기준으로 사용하지 않습니다.

@numba.njit(cache=True)
def resample_row_linear_antigravity(row: np.ndarray, target_length: int) -> np.ndarray:
    if row.size == target_length:
        return row.copy()
    output = np.empty(target_length, dtype=np.float64)
    if target_length == 1:
        output[0] = row[0]
        return output
    scale = (row.size - 1) / (target_length - 1)
    for index in range(target_length):
        position = index * scale
        left = int(position)
        right = min(left + 1, row.size - 1)
        weight = position - left
        output[index] = row[left] * (1.0 - weight) + row[right] * weight
    return output
