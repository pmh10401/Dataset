Exp454 Exp449 authority 타입 경계 복구 구현 계획

Agent 실행 규칙: Task별로 진행하고 완료된 Task와 Step만 체크한다. Grok 4.6/high는 전용 worktree에서 독립 분석·수정안 구현을 맡을 수 있다. Codex가 diff 통합, 테스트, 결과 검증과 최종 판단을 맡는다. 공식 실험 worktree에서 Grok 쓰기는 금지한다.

Goal: 실제 Exp449 authority를 Exp454 내부 타입으로 한 번 변환해, 과학 계산을 바꾸지 않고 평가가 label 단계와 실제 결과 계산까지 진행되게 한다.

Architecture: Exp454는 Exp453의 controlled fork다. 유일한 동작 변경은 predecessor 경계의 normalize_exp449_target_authority_antigravity()다. 그 뒤 evaluator, bootstrap, replay와 12-leaf 결과 형식은 Exp453와 같다.

Tech Stack: Python 3.14.6, NumPy 2.3.5, aeon 1.4.0, scikit-learn 1.7.2, stdlib, SQLite read-only label session, canonical JSON/JSONL, unittest.

def normalize_exp449_target_authority_antigravity(authority: object) -> NormalizedTargetAuthorityAntigravity:
    datasets = getattr(authority, "target_dataset_names", None)
    raw_rows = getattr(authority, "target_baseline_rows", None)
    raw_global = getattr(authority, "baseline_confusion", None)
    if type(datasets) is not tuple or type(raw_rows) is not tuple or len(datasets) != 48 or len(raw_rows) != 48:

    rows = []
    for expected_order, (dataset, raw) in enumerate(zip(datasets, raw_rows, strict=True)):
        if (type(dataset) is not str or type(raw.dataset_order) is not int or raw.dataset_order != expected_order

    global_confusion = ConfusionAntigravity(raw_global.tp, raw_global.fp, raw_global.fn, raw_global.tn)
    return NormalizedTargetAuthorityAntigravity(datasets, tuple(rows), global_confusion)
