Exp459 ECG normal_2 연속 구간 검증 구현 계획

에이전트 작업 규칙: superpowers:subagent-driven-development를 사용해 Task별로 구현하고, 각 Task 뒤에 새 검토자를 둔다. 모든 진행 항목은 아래 비활성 체크박스로 기록한다.

목표: Exp458의 ECG5000_normal_2 라우팅 규칙이 저장 순서 기반 다섯 연속 구간에서도 안정적인지, Exp458 통과선을 바꾸지 않고 검증한다.

구조: Exp458의 TRAIN loader, Hydra/LocalGap 점수 계산, AUC와 Wilson 공식을 통제된 복제로 재사용한다. 달라지는 과학 요소는 무작위 fold 대신 정확한 다섯 연속 query 구간을 사용하는 것뿐이다. 결과는 10개 fold-seed 판단, 두 seed 요약, 최종 stable/unstable로 저장하고 source-free replay와 HTML 대시보드로 검증한다.

기술: Python 3.14.6, NumPy 2.3.5, aeon 1.4.0, SQLite read-only TRAIN source, unittest, canonical JSON/JSONL, HTML.

전역 고정 조건

  • 과학 기준 predecessor는 Exp458 최종 커밋 fc530cd2b392394aa7ffbd1408bc06d5b1b7c806와 공식 artifact-map SHA-256 7ef36f232db5d2f2396f3dcdeda15af2e93c34e18a6e05dc411e37fe855737f9다.
  • 대상은 ECG5000_normal_2 TRAIN 1413×140 하나뿐이다. TEST 라벨 조회는 항상 0이다.
  • fold query 크기와 순서는 정확히 (283,283,283,282,282)이며 shuffle을 호출하지 않는다.
  • seed는 정확히 (20260721, 20261721), 합성 종류는 정확히 (level_shift, gradual_drift, amplitude_scaling, period_change)다.
  • 각 fold·seed에서 종류별 AUC 모두 ≥0.85, 평균 AUC ≥0.90, 정상 Wilson 상한 ≤0.05를 요구한다.
  • 10개 판단이 모두 통과해야 stable이다. 하나라도 실패하면 unstable이며 같은 실험에서 기준을 바꾸지 않는다.
  • Exp458 공식 결과, 제품 코드, champion, pending candidate, 운영 route는 바꾸지 않는다.
  • Hydra는 aeon CPU 구현을 유지한다. MLX 재구현은 고정 방법을 바꾸므로 하지 않는다.
  • 새 문서와 대시보드는 HTML이며, 모든 새 파일 이름에 antigravity를 포함한다.
  • 공식 Exp459 명령은 Task 5 구현·비공식 실측·독립 검토와 별도 사용자 승인 전 0회다.

def blocked_plan_antigravity(n_rows: int):
    indices = np.arange(n_rows, dtype=np.int64)
    queries = tuple(np.array(part, dtype=np.int64, copy=True)
                    for part in np.array_split(indices, 5))
    return tuple(
        BlockedFoldAntigravity(
            fold_index=i,
            fit_indices=np.concatenate(queries[:i] + queries[i + 1:]),
            query_indices=query,
        )
        for i, query in enumerate(queries)
    )
