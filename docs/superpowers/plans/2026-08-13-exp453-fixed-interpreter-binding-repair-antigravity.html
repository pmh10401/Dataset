Exp453 고정 Python 실행 경로 복구 구현 계획

Agent 실행 규칙: Task별로 진행한다. Grok 4.6/high는 읽기 전용 독립 검토·원인 분석·대안 제안을 담당한다. Codex가 최종 판단, 코드 통합, 테스트, 결과 검증을 담당한다. Grok이 수정안을 만들어야 하면 전용 worktree를 사용하며 공식 실험 worktree에는 쓰기 권한을 주지 않는다. 완료된 Task와 Step만 체크한다.

Goal: Exp452의 과학 계산을 바꾸지 않고, Exp453의 세 공식 명령이 반드시 고정 Python 환경에서 실행되도록 만든다.

Architecture: Exp453는 Exp452의 controlled fork다. Launcher 앞단의 stdlib-only runtime binding이 잘못된 venv를 고정 venv로 한 번 전환한다. Exp452 failure evidence와 Exp449 frozen prediction을 각각 별도 predecessor authority로 검증한다.

Tech Stack: Python 3.14.6, NumPy 2.3.5, aeon 1.4.0, scikit-learn 1.7.2, stdlib, SQLite read-only label session, canonical JSON/JSONL, unittest.
