Exp451 RDST + LocalGap 자격검증 구현 계획

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

Goal: 정상 TRAIN에서 공식 aeon RDST 특징을 만들고 기존 LocalGap 점수기로 48개 대상 데이터셋을 label-free 평가하여, Exp448 기준보다 FN을 줄이면서 FP를 늘리지 않는지 검증한다.

Architecture: Exp451은 Exp448 publication과 source DB를 읽기 전용으로 고정하고, aeon 1.4.0 RandomDilatedShapeletTransform(y=None)을 fold마다 새로 학습한다. Exp449의 검증된 LocalGap·경험적 보정·bootstrap·저수준 원자 저장만 읽기 전용으로 재사용하고 Exp451 고유 prediction/evaluation root는 분리한다.

Tech Stack: Python 3.14.6, aeon 1.4.0, NumPy 2.3.5, scikit-learn 1.7.2, Numba 기반 공식 RDST, SQLite immutable read, unittest, canonical JSON/JSONL, versioned HTML/JSON/lock code map.
