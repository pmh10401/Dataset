목표와 구조

Goal: 공개 receipt/count 권한을 제거하고, lifecycle 내부 성공 commit만으로 progress와 failure audit를 산출한다.

Architecture: module-private slotted session이 exact inventory와 성공 commit state를 소유한다. production과 synthetic lifecycle은 같은 commit/progress/prefix/failure 경계를 사용하며 terminal descriptor validator와 artifact 형식은 유지한다.

Tech stack: Python 3.14, os.open/dir_fd/O_NOFOLLOW, ProcessPoolExecutor(max_workers=11), unittest, deterministic Exp449 codemap builder.

Global Constraints

  • 모든 새 파일명에는 antigravity가 포함되고 __init__.py를 만들지 않는다.
  • exact 96 ordered units, worker 11, parent contiguous commit을 변경하지 않는다.
  • 공식 실행, TEST labels, DB/root/audit mutation, dashboard/site/network, Task 6을 금지한다.
  • 문서는 self-contained HTML만 사용한다.
  • 코드 경계 변경 시 Exp449 HTML/JSON/lock을 함께 재생성하고 functional parent에 결속한다.
  • Task 5 전체 구현·검증·fresh Sol ship 전에는 기존 Task 5 체크박스를 체크하지 않는다.
