Exp468 — ECG200 국소 STFT 주파수 재분배 구현 계획

Agent 작업자 필수 지침: 이 계획은 Task별로 실행한다. 권장 방식은 superpowers:subagent-driven-development이며, 현재 세션에서 순차 실행할 때는 superpowers:executing-plans를 사용한다. 각 Task는 RED 테스트, 최소 구현, GREEN 검증, 독립 검토, 커밋을 하나의 단위로 끝낸다. 완료한 Task와 Step의 HTML checkbox는 즉시 체크한다.
목표ECG200 TRAIN-only에서 5개 국소 STFT 창의 주파수 재분배 점수 S10을 만들고, 신호가 확실할 때만 C0를 보완하는 C10이 period change를 안정적으로 개선하는지 검증한다.
구조Exp466의 ECG200 loader, 96→140 보간, 네 합성 변화, 2×5 fold와 C0 점수를 그대로 재사용한다. 새 모듈은 suffix 84개를 5개 창으로 나눠 STFT 분포와 Jensen–Shannon 발산을 계산한다. C10은 원시 JS가 정상 fit 최댓값을 엄격히 넘을 때만 max(C0, S10_rank)를 사용한다.
기술Python 3, NumPy, Numba, MLX/MPS, 표준 라이브러리 dataclass/JSON/SHA-256/unittest, 자체 포함 HTML 대시보드

전체 고정 조건

  • 모든 새 파일명에는 antigravity를 포함한다. 모든 사용자 문서는 HTML로 작성한다.
  • ECG200 TRAIN 100×96 중 정상 69개만 사용한다. TRAIN MD5는 808875aeac1c358a90c630fe369327c4다. TEST 파일·TEST 라벨·실제 FN은 열지 않는다.
  • 보간 폭 140, seed (20260721, 20261721), seed당 5 fold, onset 56, suffix [56:140]를 바꾸지 않는다.
  • 창 시작점은 (0,14,28,42,56), 길이 28, hop 14, padding 없음, 대칭 Hann np.hanning(28), RFFT 길이 28, DC 제외 후 14 bin, epsilon 1e-12, 자연로그 JS, 5창 중앙값이다. hann_definition="numpy_hanning_symmetric"은 수학 기준 w[n]=0.5-0.5*cos(2*pi*n/27)을 뜻하며 backend를 고르지 않는다.
  • 변화 순서는 (level_shift, gradual_drift, amplitude_scaling, period_change)로 고정하고 두 AUC tuple을 이 순서에 묶는다. 네 번째 period_change는 Task 2가 Exp466에서 그대로 연결하며 AUC 계산은 Task 4가 맡는다.
  • method order는 (C0,S10,C10)이며 유일한 주 후보는 C10이다. C10은 strict raw-JS confirmation에서만 C0와 S10 rank의 max를 사용한다.
  • 합격은 10개 모두 finite, period AUC ≥0.85, period AUC > C0, period confirmation 1개 이상, level/gradual/amplitude AUC ≥ C0, seed별 OOF normal confirmation 0, private 두 실행 byte equality를 모두 요구한다. 평균 AUC gate는 없다.
  • 실패 뒤 같은 실험에서 창·hop·window·FFT·epsilon·JS 집계·문턱·seed·fold·합격선을 바꾸지 않는다. CWT나 wavelet packet은 Exp468에 추가하지 않는다.
  • 전체 실행 전에 NumPy 기준, Numba, MLX/MPS를 동일 입력·seed로 비교한다. finite, raw score 허용오차 1e-12, confirmation index exact equality를 만족하고 전체 10-fold workload가 1.1× 이상 빨라야 가속 backend로 채택한다. 이 gate 정의는 바꾸지 않는다. 2026-08-24 승인 보완은 gate_passed=false를 유지한 채 fallback_authorized=true, selected_backend=numpy를 별도 감사 사실로 기록하는 Task 3 완료 예외다.
  • 각 코드 Task 시작 전 docs/codemap/codemap_exp468_antigravity.lock을 확인하고 JSON에서 호출자·영향·테스트를 읽는다. 경계가 바뀌면 HTML/JSON/lock 세 파일을 같은 commit에서 갱신한다.
