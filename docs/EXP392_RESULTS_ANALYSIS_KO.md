# Exp392 정답 기반 점수원 역 탐색 결과

## 실험 목적

Exp392는 TP·FP·FN·TN을 사후에 이용해 유망한 점수원과 조합을 찾는
연구용 역 탐색이다. 운영 자동 경보를 최적화하거나 변경하지 않았다.

## 검증 범위

| 항목 | 값 |
|---|---:|
| 데이터셋 | 1,117 |
| TEST 인스턴스 | 195,900 |
| 기준 FN | 2,003 |
| 단일 근거 관측 | 54 |
| 2·3개 근거 조합 | 1,944 |
| 상보성 비교 | 216 |

prepare 단계에는 TEST 라벨과 평가 지표가 없으며, 동결 파일 SHA256
검증 후 evaluate 단계에서만 TEST 라벨을 읽었다.

## 전체 결과

| 연구 분류 | 관측 수 |
|---|---:|
| unsupported | 1,937 |
| research_signal | 59 |
| preregistration_candidate | 2 |

두 `preregistration_candidate`는 서로 다른 발견이 아니다. 후보 인덱스
SHA256이 완전히 같아 하나의 고유 후보 패턴이다.

대표 규칙:

`EWMA ∩ 정상거리`, Alpha `0.010`

`EWMA ∩ 정상거리 ∩ 시간구조`, Alpha `0.010`도 동일한 50개 인덱스를
만들었다. 이는 해당 50개에서 시간구조 조건이 후보를 더 줄이지
않았다는 뜻이다.

## 대표 후보 패턴

| 구분 | 후보 | TP | FP | 정밀도 |
|---|---:|---:|---:|---:|
| 전체 | 50 | 31 | 19 | 62.00% |
| 기존 검토와 겹침 | 29 | 24 | 5 | 82.76% |
| 기존 검토 밖 | 21 | 7 | 14 | 33.33% |

겉으로는 전체 정밀도가 62%지만, 좋은 성과의 대부분은 이미
Standard/Priority review에 있던 후보에서 나온다. 기존 검토 밖의
새 후보를 자동 경보로 올리면 정상 14건과 이상 7건이 추가되어
정밀도가 33.33%에 그친다.

따라서 이 결과는 자동 경보 확대 근거가 아니라 **기존 검토 후보의
우선순위를 높이는 근거**로 해석해야 한다.

## 계보 집중도

- Crop TP: 17건
- MelbournePedestrian TP: 8건
- 나머지 TP: 6건
- 최상위 계보 TP 비중: 54.84%
- TP 기여 계보: 6개

한 계보가 80% 이상을 차지하지는 않지만 Crop과
MelbournePedestrian의 비중이 크다. 신규 데이터에서 동일한 관계가
유지되는지 검증하기 전에는 일반화된 운영 규칙으로 볼 수 없다.

## 운영 결론

1. 기존 자동 경보 2,218건은 변경하지 않는다.
2. Exp392 후보를 자동 경보에 추가하지 않는다.
3. 후속 실험은 기존 review lane 안에서 `EWMA ∩ 정상거리`가 검토
   순서를 개선하는지만 동결 검증한다.
4. Alpha 0.010은 사후 발견값이므로 그대로 운영값으로 채택하지 않는다.
5. 후속 실험도 먼저 Shadow/review로 제한한다.
6. 신규 잠금 데이터 또는 prospective validation 전에는 배포하지 않는다.

## 프로젝트 원칙과의 관계

Exp392는 의도적으로 TEST 정답을 사용했으므로 strict TRAIN-only
실험이 아니다. 다만 사용 범위를 가설 발견으로 제한했고, 어떤
결과도 자동 경보·threshold·routing에 반영하지 않았다.
