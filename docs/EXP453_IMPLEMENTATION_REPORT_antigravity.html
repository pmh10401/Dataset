합성 테스트는 실제 Exp449 객체를 Exp453 로컬 타입으로 바꾼 fixture를 사용해 이 경계를 놓쳤다. 다음 실험은 실제 Exp449 authority를 그대로 평가기에 전달하는 end-to-end 회귀 테스트를 먼저 추가해야 한다.
