서비스 반영 결과

학습 자료가 적어 p ≤ 0.005에 도달할 수 없을 때만, 가능한 가장 작은 p값의 시계열을 소표본 검토 우선 후보에 보여줍니다.

  • 기존 자동 이상 판정 기준은 바꾸지 않았습니다.
  • 후보를 자동 이상으로 승격하지 않습니다.
  • Trace_normal_2의 #49가 검토 우선 후보로 표시됩니다.

승인된 비교 방법

기존 방식: p값이 0.005 이하인 시계열만 자동 이상으로 선택합니다.

실험 방식: 0.005에 도달할 수 없는 경우에만, 가능한 가장 작은 p값인 1/(학습 수+1)까지 비교합니다.

  • TEST 라벨은 후보 선택이 끝난 뒤에만 열어 정탐·오탐·미탐을 계산합니다.
  • 전체 778개에서 오탐이 늘지 않고 미탐이 줄어야 자동 탐지 규칙으로 통과합니다.
  • 오탐이 늘면 자동 탐지에는 넣지 않고, 사람이 먼저 볼 검토 후보로만 사용합니다.
  • 라벨 결과로 데이터셋 이름별 허용 목록을 만들지 않습니다.
