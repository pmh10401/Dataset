Exp530 — 전체 실험 전 수치 검증

현재 구현은 수치 검증을 통과하지 못했습니다. 새 TEST 점수나 라벨은 읽지 않았으며, 성능 개선 여부는 아직 측정하지 않았습니다. 이 결과는 Ledoit–Wolf 기법 자체가 나쁘다는 뜻이 아닙니다.

검증 대상

Exp502의 원본·제곱 MiniRocket 특징, 정상 참조, 스케일링과 최근접 3개 평균 점수를 유지하고 공분산 축소 계수만 OAS에서 sklearn Ledoit–Wolf로 바꾸는 후보입니다. Pro 자문 후 정상 TRAIN과 기술적 산술 입력으로 검증했습니다. 산술 입력은 합성 이상 성능 평가가 아닙니다.

확인한 내용

  • 빠른 Gram 계수 계산은 작은 반올림 차이로 고정 임계값 판정이 달라져 제외했습니다.
  • 원본 sklearn 계수는 실제 정상 데이터 4종 × 참조 수 2·32의 8개 검사에서 반복 계산과 기존 OAS 계수 대입 검사를 통과했습니다.
  • 참조 2개를 모두 사용하는 경우의 이웃 순서 차이는 선택 집합을 바꾸지 않습니다. Grok 검토를 바탕으로 4개 중 3개를 선택하는 별도 검사를 추가했습니다.
  • 80자리 고정밀 공분산 검산과 비교한 8,064차원 중복 참조 사례에서 점수 오차 허용치와 정확한 점수 순위 기준을 통과하지 못했습니다. 허용치를 넘는 비동점 순위 역전은 관측하지 않았고, 고정 임계값 판정은 네 사례 모두 같았습니다.
