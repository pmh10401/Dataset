Exp516 · 정상 데이터만으로 데이터셋별 Laya 학습

정상 전용 Laya는 기존 Exp502의 계열평균 탐지율을 넘지 못했습니다. 기존 56.1879%, Laya 21.8718%, 차이 -34.3161 pp입니다.

1,119개 데이터셋을 모두 처리했습니다. 정상 TRAIN만 학습·보정에 사용했고 합성 이상과 TEST 정답은 학습에 사용하지 않았습니다. 기존 모델과 짝을 맞출 수 있는 1,118개가 전체 비교 대상입니다. TRAIN이 1개인 Phoneme_normal_39는 기존 모델 계산이 불가능하여 별도 coverage로 남겼습니다. 과거에 노출된 TEST 재평가이므로 새로운 미관측 데이터에서의 성능이나 운영 오탐 보장을 뜻하지 않으며 모델을 승격하지 않았습니다.

방법과 공정한 비교 범위

각 데이터셋에서 원본 사전학습 Laya를 새로 시작했습니다. 기존 합성 이상으로 미세조정한 Exp514 가중치는 사용하지 않았습니다. 정상 시계열의 네 요약 특징 중 하나를 가리고 그 값을 예측하도록 학습했습니다. 네 번의 예측 오차 평균이 이상 점수입니다. 가린 값은 해당 입력 문장에서 완전히 제거했습니다.

Laya 마지막 head 내부 LayerNorm 1,536개 가중치와 새 회귀 readout 3,076개를 학습합니다. encoder와 나머지 transformer 가중치는 고정합니다. 전체 모델 미세조정이 아닙니다. 고정 LayerNorm+학습 readout, 작은 수치 MLP, 항상 정상 중심값 0을 예측하는 방법도 비교합니다. 정상 패턴과 다른 값을 탐지할 수 있지만 일부 이상을 잘 복원하거나 정상 입력을 과적합할 가능성은 그대로 존재합니다.

정상 fit 최대 64개, 8 epoch, 마지막 가중치, 같은 초기값·순서·seed를 고정했습니다. 중앙값/IQR은 fit만 사용했습니다. 남은 정상 TRAIN 중 최대 1,000개는 진단용 보정에 사용합니다. Exp502는 원래 정의대로 최대 1,000개 정상 reference와 전체 시계열 MiniRocket 특징을 사용합니다. 입력 정보와 학습 표본 예산이 다르므로 동등 자원 대결이 아니라 실제 기존 최상위 모델과의 비교입니다.
