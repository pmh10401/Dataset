고정한 방법과 검증 범위

원래 Exp502의 FIT·CAL·전처리·시드·임계값을 보존하고 재현 점수의 수치·순위·판정을 대조했습니다. 새 방식은 표준화 전 평균·모표준편차와 파형 거리를 동일한 정상 FIT 행에 대해 함께 비교합니다.

t_j = median over SCALE × FIT of |raw_j(u) − raw_j(i)|
d_m(u,i) = Euclidean distance of raw moments / t_j
a = median over SCALE × FIT of d_shape
b = median over SCALE × FIT of d_m
D(x,i) = hypot(d_shape(x,i)/a, d_m(x,i)/b) / sqrt(2)
score(x) = mean of the 3 smallest D(x,i), using the same reference IDs

수치 안정성을 위해 원시 통계에서 FIT 중앙값을 뺀 뒤 나눕니다. 척도 0은 해당 후보를 평가 불가로 기록합니다. 동점은 정상 행 ID 순으로 처리합니다. 가중치·대안 모델·합성 이상 탐색은 없습니다.

TEST 114,550행 중 114,550행을 평가했고 0행을 제외했습니다. 56개 전체 점수·행 ID·임계값을 동결한 뒤 라벨을 재사용했습니다. 라벨 접근 후에는 학습·재점수화를 차단하며, 검증은 동결 자료의 산술과 판정·집계를 재현합니다.

서로 다른 TRAIN 역할에 동일 값이 들어 있는 중복군은 33개 데이터셋에서 1,391개 확인했습니다. 원래 행 ID와 분할을 유지했으며 중복 자료가 독립적인 증거를 늘려 주지는 않습니다.

공동 최근접 이웃은 라벨 접근 전에 전체 FIT 후보를 별도 순위 계산과 직접 합산으로 대조했습니다. 최종 검산은 저장한 선택 이웃의 성분 거리·점수와 보정 판정·집계를 확인합니다. 최종 검산만으로 전체 모델 변환과 모든 후보 거리를 다시 계산한 것은 아닙니다.
