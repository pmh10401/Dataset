학습 내용과 계산 장치

두 학습 모델에 똑같은 네 숫자(roughness, peak, autocorrelation, trend)를 제공했습니다. fit 표본에서 정규화하고 [-99,99]로 제한한 뒤 소수점 한 자리로 맞췄습니다. 수치 MLP는 4→32→1, Laya는 전체 인코더와 act_head를 고정하고 두 Transformer 결정 층·type embedding·marker scorer를 학습했습니다. 점수는 반올림한 API 확률 대신 true−false 원시 logit 차이입니다. Laya 자체의 전체 시계열 표현 학습은 시험하지 않았습니다.

학습 가능한 Laya 파라미터 14,770,945. 최종 8번째 epoch만 사용했고 평가 결과에 따른 재학습·하이퍼파라미터 탐색은 하지 않았습니다. 각 계열 정상 64개와 합성 256개, 고정 클래스 가중 BCE, batch32, AdamW, Laya LR3e-5, MLP LR1e-3입니다.

MPS 역전파는 유한했고 gradient 비교를 통과했습니다. 학습 단계 속도는 6.19x, 최대 logit 오차는 6.68e-06. 그러나 CPU 임계값 경계 판정이 1개 달라져 사전 규칙에 따라 CPU를 선택했습니다. 이 작은 smoke는 보정 표본 자체도 판정 비교에 포함하는 보수적인 검사입니다. MLP는 CPU가 더 빨랐습니다. MLX는 동일한 미분 가능한 구현을 새로 이식해야 하므로 사용하지 않았고, MiniRocket의 기존 Numba 구현은 유지했습니다.

Core ML과 Neural Engine 적용

학습된 모듈을 원본 전체 모델에 적용하고 upstream BC1S 그래프로 변환했습니다. 갱신된 type embedding과 토큰 lookup은 호스트에, 전체 encoder·결정 head·scorer는 Core ML 그래프에 있습니다. 캐시된 결정 모듈만을 전체 모델로 간주하지 않았습니다.

FP32 원본/BC1S 비교 최대 오차 1.01e-05. FP16 CPU+NE 점수를 12,560개 입력 전부에서 평가했습니다. 동일한 16개 입력의 CPU_ONLY 대비 CPU_AND_NE 반복 3쌍 속도 중앙값은 2.66x. 호스트 embedding·mask·predict를 포함하지만 캐시된 tokenization과 최초 변환/로드는 제외합니다. 이 값은 MLP 대비 속도가 아닙니다.

속도 해석 제한: 같은 시간 측정 표본에서 CPU_ONLY와 CPU_AND_NE의 logit 차이 점수는 최대 5.19165만큼 달랐습니다. 따라서 위 수치는 같은 패키지의 실행 설정별 소요 시간 비교이며, 수치·판정 동등성을 통과한 가속으로 인정하지 않습니다. 아래 정확도·판정 비교는 원본 PyTorch와 CPU_AND_NE 사이의 별도 검증입니다.

범위와 제한

평가 계열은 학습 18계열 밖에서 정상 TRAIN≥2,032개를 가진 모든 계열이며, 여러 class 변형이 있으면 표본 수가 가장 큰 것을 택했습니다. 계열마다 seed20260921로 32 fit / 1,000 calibration / 1,000 held normal을 분리했습니다. 합성 이상은 held normal 중 64개에 고정된 여덟 변형을 적용했습니다. 같은 부모를 공유하므로 독립 이상 2,560개로 가정한 유의성 검정을 하지 않았습니다. 전체 TRAIN이 정상 라벨뿐이므로 실제 이상의 대표성은 미확인입니다. 정상 1,000개/계열로 운영 오탐률 0.1%를 보장할 수 없습니다. 계열 분리는 이번 신경망 학습 기준이며 과거 연구 노출 전체를 제거했다는 뜻은 아닙니다.
