8. 다음 검증은 무엇을 분리해야 하는가

정상 TRAIN만 사용한 동일 행 비교가 다음 단계다. 정상 TRAIN에서 평가용 E를 먼저 떼고, 나머지 R의80%와100%로 각각 모델을 학습해 같은 E를 채점한다. 두 학습 집합은 중첩시키고 시드·참조 상한을 고정한다. E는 특징 변환·스케일러·최근접 참조에 절대 넣지 않는다. 모든 가능한 데이터셋과 불가능 사유를 기록한다.

이 비교는 동일한 정상 행에서 학습 표본과 모델 변경만으로 점수 척도가 얼마나 움직이는지 확인한다. 필요하면 R의 OOF 보정으로 E의 오탐률도 측정한다. 여기서80%는 R의80%이며 원래 전체 TRAIN을 임의로64% 사용한다는 뜻은 아니다. 순수한 실제 TRAIN/TEST 분포 변화까지 확정하려면 추가 증거가 필요하다.

이 정상 전용 인과 검사는 이번 캐시 진단에서 실행하지 않았다. TRAIN 자기참조 점수를 보정에 쓰거나 TEST 정상 점수로 기준을 낮추는 방식은 사용하지 않는다. Exp533의3개 데이터셋 square-joint CV+ 파일럿(700정상에서 FP4→5)은 별도 방법의 제한적 근거이며 이번 서비스 전체의 인과 검증을 대신하지 않는다.
