연구 보고서의 정적 게시 사본입니다. 본문은 당시 결과이며 현재 배포 상태를 뜻하지 않습니다. 링크를 저장소 기준으로 바꾸고 실행 스크립트와 미게시 그림을 제외했습니다. 실시간 진행 표시·대화형 기능은 갱신되지 않습니다. 원본 경로·해시·게시 사본 정보

기존 데이터베이스로 서비스 시작

프로젝트의 univariate_ts.db를 서비스 입력으로 사용합니다. 1,119개 데이터셋의 이름과 학습·평가 시계열을 읽고, 검증된 경로가 있는 데이터셋을 분석할 수 있습니다. 원본 DB는 읽기 전용으로 열며 분석 기록은 별도 파일에 저장합니다.

실행

저장소 루트에서 실행합니다. 기록 파일 경로는 쓰기 가능한 디렉터리로 정하세요.

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python3 -m services.time_series_anomaly_diagnosis.application_server \
  --host 127.0.0.1 --port 8485 --public-host 127.0.0.1 \
  --source-database /Users/mac/Documents/Dataset/univariate_ts.db \
  --history-database /path/to/analysis_history.sqlite3

브라우저에서 http://127.0.0.1:8485/를 열고 데이터셋을 선택한 다음 분석 시작 → 분석 기록 → 결과 열기를 사용합니다. 시계열을 선택하면 점수, 정규화한 비교 그래프와 DB에 저장된 원래 측정값을 볼 수 있습니다. 같은 기록 파일을 지정해 재시작하면 결과를 다시 조회합니다.

데이터와 결과의 의미

  • DB의 instances.values_blob는 little-endian float32 시계열입니다. instance_index가 구간 ID입니다. DB에는 측정 시각이 없으므로 원본 그래프의 가로축은 샘플 번호입니다.
  • 분석에는 각 데이터셋의 정상 TRAIN 구간을 사용합니다. 기존 TEST 라벨은 모델 학습이나 임계값 조정에 사용하지 않고, 분석 후 평가에만 사용합니다.
  • 검증된 모델 경로가 없거나 정상 학습 구간이 부족한 데이터셋은 목록에 표시하되 분석을 시작할 수 없습니다. 사용 가능 여부는 화면에서 확인합니다.
  • 결과는 구간 단위 이상 검토용입니다. 그래프만으로 구간 안의 고장 시각이나 원인을 확정하지 않습니다.
