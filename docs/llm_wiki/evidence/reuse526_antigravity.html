연구 보고서의 정적 게시 사본입니다. 본문은 당시 결과이며 현재 배포 상태를 뜻하지 않습니다. 링크를 저장소 기준으로 바꾸고 실행 스크립트와 미게시 그림을 제외했습니다. 실시간 진행 표시·대화형 기능은 갱신되지 않습니다. 원본 경로·해시·게시 사본 정보

Exp526을 0.5% 실험 후보로 활용

Exp526의 동결 점수와 판정을 다음 연구에서 바로 불러올 수 있습니다. 기본 선택은 Exp502이고, Exp526은 목표 오탐률 0.5%에서 명시적으로 선택하는 실험 후보입니다. 학습된 모델 파일을 배포하거나 기본 운영 모델로 승격한 것은 아닙니다.

현재 활용할 수 있는 결과

기존 TEST 56개 데이터셋·14계열·114,550행(정상 112,259행, 이상 2,291행)의 결과입니다. 이번 작업은 기존 결과 재사용 기능이며 새 실험으로 얻은 개선이 아닙니다.

추가 탐지 58건, 새 미탐 4건으로 순증 54건입니다. 추가 오탐 142건과 제거된 오탐 147건이 함께 있으므로, 이 결과를 단순 OR 결합의 성능으로 해석하면 안 됩니다.

탐지율 차이는 +0.992%p이며, 계열 단위 bootstrap 2,000회(시드 20260922)의 95% 구간은 [-0.028, +2.778]%p입니다. 0을 포함하므로 개선 확정은 아닙니다. 순증 탐지 54건 중 52건이 Crop 계열에서 발생했습니다. Crop만 선택해 적용하지 않습니다. 모든 데이터셋에서 실제 오탐률 0.5% 이하를 보장하지 않습니다.

사용 범위

  • Exp502: 기본 비교 모델. 기존 0.1%·0.5%·1% 임계값을 그대로 사용합니다.
  • Exp526: 0.5%에서만 명시적으로 선택할 수 있습니다. 다른 예산에서는 오류로 중단하며 모델을 자동 변경하지 않습니다.
  • 0.1%에서 Exp502가 평가 가능한 집단은 5개 데이터셋·4계열입니다. 나머지 51개는 unavailable이며 판정을 빈칸으로 내보냅니다.
  • 새 시계열 입력이나 새로운 행은 지원하지 않습니다. 학습된 모델 파일이 없으므로 이 도구는 원시 데이터 추론기가 아닙니다.

0.1%의 5개 평가 가능 데이터셋에서 계열평균 탐지율은 Exp502 19.58%, Exp526 3.09%였습니다. 1%의 56개 집단에서도 43.609%→43.502%로 소폭 낮아졌습니다. 0.5%의 개선을 다른 예산으로 일반화하지 않습니다. 이미 본 TEST 결과를 보고 후보로 보존한 판단 자체도 탐색적입니다.

바로 사용할 파일

  • Exp526 · 0.5% · 114,550행 판정 CSV / 지표·원본 해시·데이터셋별 임계값
  • Exp502 · 0.5% · 114,550행 판정 CSV / 비교 기준의 지표와 출처
  • 실험 후보 정의와 사용 제한
  • 원래 Exp526 실험 보고서

CSV에는 데이터셋, 계열, 원본 행 ID, 모델, 오탐 예산, 저장된 점수, 임계값, 판정, 적용 가능 상태가 들어 있습니다. TEST 라벨과 원본 시계열은 포함하지 않습니다. 행 식별자는 데이터셋 이름과 행 ID의 쌍입니다.

실행 방법

다음 명령은 프로젝트의 해당 worktree 루트에서 실행합니다. 요약 조회는 파일을 생성하지 않습니다.

cd '/Users/mac/Documents/Time Series/.worktrees/exp482-gate-failure-decomposition-antigravity'

# 기본: Exp502, 0.5%
.venv/bin/python -m experiments.exp526_candidate_reuse_antigravity.reuse_antigravity

# Exp526 실험 후보, 0.5%
.venv/bin/python -m experiments.exp526_candidate_reuse_antigravity.reuse_antigravity --model exp526 --alpha 0.005

# 엄격한 예산: Exp502, 0.1%; 부족한 보정 표본은 unavailable
.venv/bin/python -m experiments.exp526_candidate_reuse_antigravity.reuse_antigravity --model exp502 --alpha 0.001

# 검증
.venv/bin/python -m unittest -v experiments.exp526_candidate_reuse_antigravity.test_reuse_antigravity

--export를 붙이면 별도 폴더에 CSV·출처 JSON을 생성합니다. 이미 생성된 파일은 덮어쓰지 않습니다. 위의 0.5% 파일 두 쌍은 준비되어 있으므로 링크로 이용하면 됩니다.
