Crop 24개 데이터셋, TEST 24,000행(정상 23,520·이상 480) 대상입니다. Exp524에서 발견한 단서를 점수 하나로 시험했습니다. 기존 TEST가 노출된 뒤 고른 한 계열에 대한 탐색적 비교이며 전체 14계열의 결과가 아닙니다.

결론

정상 AUDIT 목표 초과: 새 점수는 28/4,800개(0.583%), Exp502는 21/4,800개(0.438%)였습니다. 새 점수는 사전에 정한 0.5% 관측 기준을 충족하지 못했습니다. 아래 TEST 수치는 그대로 남긴 탐색적 비교입니다. 이 점추정 판정만으로 모집단 오탐률 초과나 conformal 수학적 보장 실패가 증명되지는 않습니다.

탐지율이 Exp502보다 높아지지 않았습니다. 오탐 감소나 일부 미탐 회복만으로 성능 개선이라고 표현하지 않습니다.

0.5% 목표에서 탐지율 49.792% → 46.667%, 실제 TEST 오탐률 0.174% → 0.395%입니다. 새 점수의 정상 AUDIT 오탐률은 0.583%입니다.

기존 세 모델 공통 미탐 215개 중 63개를 새 점수에서 탐지했습니다. 이는 단독 점수의 포착 건수이며 결합 모델의 추가 탐지율이 아닙니다.

고정한 방법

저장된 원본 한 행의 평균과 모집단 표준편차를 계산했습니다. 각 특징의 정상 FIT 중앙값을 빼고 Q90−Q10으로 나눈 절댓값 중 큰 값을 점수로 사용했습니다. 척도 하한은 1e−12×max(1,|중앙값|), 분위수는 NumPy linear입니다. CAL에서 conformal 문턱을 정하고 엄격한 >로 판정했습니다. 데이터셋별 가중치·후보 선택·OR 결합·Laya는 사용하지 않았습니다.

동일한 FIT 400·CAL 200·AUDIT 200행을 사용했습니다. FIT/CAL 매개변수와 임계값을 TEST 값보다 먼저 동결하고, 모든 TEST 점수·행 ID를 저장한 다음 기존 라벨을 다시 읽었습니다. 이전 실험의 노출 이력과 사후 가설 선택 편향이 사라지는 것은 아닙니다.

최종 판단과 실행 기록

Exp502를 유지하고 이번 단독 점수 실험은 종료합니다. 새로 탐지한 74개보다 새로 놓친 89개가 많아 이상 탐지는 15개 줄었고, 정상 오탐은 52개 늘었습니다. 1% 보조 기준에서도 탐지율은 56.667%→51.042%, 실제 오탐률은 0.425%→0.719%로 나빠졌습니다.

공통 미탐 포착 63/215개(29.30%)는 기존 세 모델과 다른 정보를 가진다는 단서입니다. Exp524의 단순 범위 이탈 74/215개와는 정의가 다릅니다. 다른 모델과의 결합 이득은 이번 실험으로 확인되지 않았습니다. 새 모델 탐색이나 후속 결합 실험을 자동으로 시작하지 않습니다.

AGY의 경계·집계 체크리스트와 그록의 방법론 검토를 반영했습니다. 그록의 첫 답변은 퍼센트 단위를 오해했으나, 실제 확률 0.001/0.005/0.01을 전달한 뒤 정정된 완결 답변을 받았습니다. Pro 자문과 선택적 Sol 코드 검토는 응답을 받지 못했고 승인 근거로 사용하지 않았습니다. Codex가 구현·실행·검산을 담당했습니다.

검산 통과: 라벨 접근 전 원본 43,200행의 통계를 scalar 방식으로 대조했고, 동결 점수 43,200개와 conformal 판정 115,200개를 독립 산술로 확인했습니다. preflight·score·evaluate·verify는 모두 종료 코드 0으로 완료했습니다. 기존 실험 점수와 DB는 변경하지 않았습니다.

CPU NumPy를 사용했습니다. Numba는 초기 컴파일을 포함한 전체 단계가 더 느렸습니다. MPS·MLX float32는 정밀도 검사를 통과하지 못했고, MLX float64는 실제 GPU 연산에서 지원되지 않았습니다. 타이밍은 같은 크기의 결정적 계산 예제에 대한 비교이며 전체 프로젝트 속도 개선을 의미하지 않습니다.

HTML 표·수치·상대 링크는 정적으로 확인했습니다. 브라우저 렌더링 검증은 수행하지 않았습니다.
