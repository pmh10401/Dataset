5. 확인한 한계와 다음에 결정할 문제

  1. 기존 점수의 보완 범위가 작습니다. 56개에서 Exp502 미탐 1,463개 중 1,340개(91.59%)는 α=0.5%의 다른 두 단일 모델도 놓쳤습니다. 남은 이상이 모든 새 방법으로도 불가능하다는 뜻은 아닙니다.
  2. 오탐 초과 4개는 모두 Crop 파생 데이터셋입니다. CAL은 각각 200개이며 TEST 정상 980개 중 FP가 5~6개(0.510%~0.612%)였습니다. 3개에서는 별도 TRAIN AUDIT에서도 초과가 관측됐습니다. 표본 변동과 분포 차이 중 무엇이 원인인지는 확정하지 못했습니다.
  3. 적용 범위가 보정 표본 수에 제한됩니다. 원본 전체 1,119개와 최근 56개는 같은 범위가 아닙니다. 1,117개 순위 비교는 Cornell 매핑과 Phoneme 최소 TRAIN 문제로 2개 제외, Exp516·518의 1,118개 비교는 Cornell을 포함하고 Phoneme 한 개를 제외했습니다.
  4. 새로운 일반화 증거가 필요합니다. 기존 TEST는 이미 여러 번 노출됐습니다. 이를 설명용으로 분석한 후 같은 자료에서 다시 튜닝하고 새로운 검증 성과로 주장할 수 없습니다.
