모델·서비스·실행 구조

GitHub 문서 게시본: 2026-09-29 연구 작업트리의 기록이다. 최신 서비스 코드 전체의 배포본이 아니며, 미게시 자료와 원본/게시 사본의 구분은 출처 목록에 있다.

두 흐름의 기준을 구분한다

흐름모델/점수보정·정책원본
Exp502 연구행 표준화된 raw와 centered-square의 MiniRocket 특징 결합, RobustScaler, OAS, 가까운 정상 3개 평균 거리실험별 full-FIT 순위 또는 별도 FIT/CAL 고정 문턱. Exp521의 FIT와 full-TRAIN Exp502는 같지 않음.[e502] [e521]
기존 DB 서비스MiniRocket·MultiRocket·Hydra LocalGap 중 저장된 경로. 두 시드의 중앙값.5-fold OOF 정상 p값과 full-FIT 추론, 기존 최소 p-floor 경보. 연구 점수와 임계값을 그대로 섞지 않음.[e537] [e539]
원시 CSV 입력정상 기준과 query를 새 DB로 등록, 고정 single_minirocket정답 없는 입력. 정상 기준 199개 미만이면 0.5% 자동 경보 차단. 데이터셋 이름으로 과거 경로를 가져오지 않음.[csv]
Exp539 라우터 시험정상 TRAIN 7개 요약값 → 수치 분류기 / GLiClass. 숫자 탐지기는 동결.원본 연결 그룹의 5-fold 교차검증. 파인튜닝해도 고정 MiniRocket과 동일 결과.[e539]

입력에서 사용자 보고까지

  1. DB 목록과 가용성을 확인한다. DB는 읽기 전용이며 분석 기록은 별도 저장한다. 원본 DB의 x축은 측정 시각이 아닌 샘플 번호다. [start]
  2. 정상 TRAIN으로 전처리와 기준 모델을 만든다. 메타데이터만 믿지 않고 실제 길이를 확인하며 가변 길이는 기존 TRAIN 기준 길이 재표본화를 재사용한다. 상수열·잘못된 BLOB 등을 임의 대체하지 않는다. [recovery]
  3. 고정 점수·p값·선택 정책으로 구간별 판정을 만들고 저장한다. 연구용 추가 amplitude 점수에는 자동으로 호환되는 p값이나 임계값이 생기지 않는다. [shared]
  4. 웹 화면에서 분석 기록, 원본 값, 정상 기준 비교, 점수와 검토 대상을 보여 준다. 정답이 없는 실제 CSV에서 탐지율·FPR을 직접 계산했다고 주장하지 않는다. 점수 1−p는 이상일 확률이 아니다. [start] [csv]

실행 명령과 CSV 형식은 원본 사용 안내를 따른다. 이번 위키 작성에서 서버를 시작하거나 새 사용자 입력을 실행하지 않았다.

중복 계산을 줄인 범위

동일한 입력·행 순서·전처리·참조·시드의 full-FIT raw MiniRocket 특징을 LocalGap과 square_joint가 공유한다. 다른 OOF fold, 다른 시드, 다른 FIT/CAL은 다른 모델이므로 공유 대상으로 합치지 않는다. 별도 영속 캐시 서비스는 추가하지 않았다. [shared]

원래 전체 후보 계산을 함께 돌린 경로 대비 고정 입력 실행 시간은 1.821→1.129초(약 38.0%)였다. 필요한 square_joint만 따로 계산한 경로 1.182초 대비 순수 공유 이득은 약 4.5%였다. 미선택 후보 제거 효과까지 모두 ‘공유만으로 38%’라고 부르지 않는다. 전체 크기·전체 데이터셋의 속도비나 메모리 절감으로 일반화하지 않는다.

전체 1,119개 중 정상 TRAIN의 작은 FIT/query 표본을 분리할 수 있는 1,117개에서 두 점수의 오차는 0이었다. 전체 행의 성능 재평가와는 다른 검사다. 리팩터링 당시 회귀 193개도 통과했다는 원본 기록을 보존한다. 이번 위키 작성에서 그 회귀 검사를 다시 실행하지 않았다. [shared] [refactor]

계산 백엔드에 대해 남긴 판단

공유 점수의 기준은 공식 MiniRocket/Numba와 float64 NumPy/SciPy 거리다. 새 Numba나 Torch 변환은 전체 단계 비용에서 이득이 없었고 MLX/MPS의 정확한 float64 경로는 지원되지 않았다. Hydra 자체는 공식 PyTorch CPU 변환을 사용하며 모든 변환을 Numba라고 부르지 않는다. [refactor] [e538]

새 계산 경로는 동일 입력·시드, 유한 출력, 수치 오차, 순위·후보 인덱스·판정 일치, 전송·동기화 포함 시간을 검사해야 한다. 과거에 한 가속 경로가 실패했다고 다른 정의가 모두 불가능한 것은 아니다. worker 수·허용치·backend는 각 동결 manifest를 따른다. 오래된 일반 지침을 현재 사용자 지시보다 우선하지 않는다.
