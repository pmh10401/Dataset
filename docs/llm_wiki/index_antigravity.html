  • 연구 비교 기준: Exp502의 raw + centered-square MiniRocket/OAS 경로를 보존한다. 현재 서비스와 같은 모델·같은 FIT·같은 보정 방식이 아니므로 두 기준을 하나로 부르지 않는다. [e502] [e535]
  • 유보한 신호: Exp526의 +0.992%p는 5회 재학습 비교 Exp527에서 +0.224%p로 작아졌고, 둘 다 신뢰구간이 0을 포함한다. 개선 확정이나 자동 적용의 근거는 없다. [e526] [e527]
  • 제외한 방향: 시험한 Laya 구성, 단순 점수 결합, 시간 4구간 PPV, 직접 파형 거리, GLiClass 라우터를 현행 모델 교체 후보로 채택하지 않았다. 모든 유사 기법이 불가능하다고 일반화하지 않는다. [e516] [e522] [e528] [e536] [e539]
