# 점수원 조사 결과 목록

## 표 읽는 방법

아래 첫 표는 Exp236의 고정 1,117개 데이터셋에서 `alpha=0.005`로 다시
맞춘 비교다. `단독`은 점수원이 독자적으로 고른 전체 후보, `Hard 확인`은
기존 자동 경보와 겹친 후보, `Standard 우선`은 기존 일반 검토와 겹친 후보,
`Lane 밖`은 기존 Hard/Standard/Priority 어디에도 없던 후보다.

표 안의 값은 `TP / FP (Precision)`이다. Exp236 자체의 Hard precision은
84.55%, Standard precision은 52.84%다.

## 전체 결론

1. 기존 자동 경보의 신뢰도 표시에는 ROCKET 안정 합의, 순서 패턴 분포
   변화, 마스킹 구간 문맥 복원 오차가 가장 유망하다.
2. 일반 검토 우선순위에는 ROCKET 계열과 순서 패턴, 마스킹 구간 문맥
   복원 오차가 유효하다.
3. 기존 lane 밖 탐지는 최고 precision도 32.82%여서 자동 경보 확대에
   사용할 수 없다.
4. 이미지·shapelet·스펙트럼 점수원은 전체 대체 모델보다 specialist 또는
   review evidence로 사용하는 편이 일관되게 안전했다.
5. 모든 결과는 기존 TEST의 후향 분석이며, 운영 승격에는 신규 holdout 또는
   shadow validation이 필요하다.
