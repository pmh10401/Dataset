왜 Exp464를 따로 만든가

Exp463에서 M0 9/10은 기본 성능을 지켰고, M1 0/10은 새 특징 단독이 너무 약하다는 뜻이었다. M2 7/10은 일부를 회복했지만 period를 끝까지 지키지 못했다. M4 9/10은 “공통 ECG 모양을 먼저 빼는 일”이 중요하다는 힌트를 줬다. 하지만 M4도 그대로 승격할 정도로 충분하지 않았기 때문에, 이번 Exp464에서는 M4를 진단 근거로만 사용하고 새 C6를 유일한 주 후보로 고정한다.

  • focused Task 2 suite 10개는 두 번 모두 통과했고, Exp463 foundation 회귀도 다시 확인했다.
  • 실제 TRAIN source는 read-only smoke로만 한 번 확인했다. private run, official command, TEST label query는 하나도 실행하지 않았다.
  • champion, pending candidate, routing, promotion은 기존 값 그대로 유지한다.
  • code map은 Task 2 closeout truth와 다음 소비자인 Task 3 scorer를 함께 기록한다.
