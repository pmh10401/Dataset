# Exp391 FN/Zero-F1 회수 가능성 감사 결과

## 목적

Exp391은 기존 자동 경보를 변경하는 실험이 아니다. Exp291/Exp389의
동결된 자동 경보가 놓친 이상(FN)을 Exp357의 아홉 가지 독립 근거가
어디까지 다시 찾을 수 있는지 확인한 후향 감사다.

모든 Alpha와 동의 수를 그대로 보고했으며 TEST 결과로 운영 규칙을
선택하지 않았다.

## 기준 성능

| 항목 | 값 |
|---|---:|
| 데이터셋 | 1,117 |
| 자동 경보 | 2,218 |
| TP | 1,915 |
| FP | 303 |
| FN | 2,003 |
| Zero-F1 데이터셋 | 356 |

Exp391 실행 전후의 자동 경보와 검토 lane은 동일하다.

## 가장 중요한 진단

FN은 큰 데이터셋에 집중되어 있다.

| TEST 크기 | 데이터셋 | FN | Zero-F1 |
|---|---:|---:|---:|
| 100 이상 | 329 | 1,731 | 84 |
| 100 미만 | 788 | 272 | 272 |

전체 FN의 86.42%가 TEST 100 이상 데이터셋에서 발생한다. 따라서
Zero-F1 데이터셋 개수만 줄이는 것보다 큰 데이터셋에서 많은 FN을
줄이는 것이 실제 탐지 범위 개선에 더 중요하다.

## 자동 경보 확대 진단

큰 Zero-F1 데이터셋에 대해 사전 고정된 Alpha 0.005 조합을 비교했다.

| 동의 수 | 추가 후보 | 회수 FN | 추가 FP | 후보 정밀도 |
|---:|---:|---:|---:|---:|
| 1 | 119 | 26 | 93 | 21.85% |
| 2 | 22 | 6 | 16 | 27.27% |
| 3 | 18 | 6 | 12 | 33.33% |

새 근거를 자동 경보에 직접 합치면 놓친 이상보다 정상 오탐이 더 많이
추가된다. 현재 결과만으로 자동 경보 범위를 확대하는 것은 사용자
신뢰와 오탐 억제 목표에 맞지 않는다.

## 검토 후보 활용 가능성

전체 기존 검토 lane은 837건이며 TP 391, FP 446으로 정밀도는
46.71%다. TEST 100 이상 데이터셋에서는 654건 중 TP 306, FP 348로
정밀도 46.79%다.

Alpha 0.005의 1표 근거가 기존 검토 후보와 겹친 부분은 197건이며
TP 101, FP 96으로 정밀도 51.27%다. Zero-F1 구간에서는 21건 중
TP 15, FP 6으로 71.43%다. 이는 자동 경보 승격 근거가 아니라,
사람이 확인할 기존 후보의 순서를 정하는 보조 신호로 추가 검증할
가치가 있다는 뜻이다.

## 제한

- EWMA Alpha 0.005에서 Zero-F1 후보 5건이 모두 TP였지만 두
  MelbournePedestrian 데이터셋에 집중된 작은 사후 관찰이다.
- 이 관찰로 EWMA나 Alpha 0.005를 운영 규칙으로 선택하지 않는다.
- Exp391은 retrospective counterfactual audit이며 prospective
  validation이 아니다.
- feature/source configuration의 end-to-end TRAIN-only provenance를
  새로 검증한 실험이 아니다.

## 결론

1. 자동 경보 확대는 보류한다.
2. 다음 실험은 큰 데이터셋의 기존 검토 후보만 대상으로 한다.
3. 근거 수와 TRAIN-normal reliability로 검토 순위를 만들되 자동
   경보에는 영향을 주지 않는다.
4. prediction과 평가를 분리하고, 순위를 동결한 뒤 TEST 라벨로
   사후 평가한다.
