고정한 과학 정의

  • suffix [56:140]의 길이는 84이며, 시작점 (0,14,28,42,56)에서 길이 28인 창 다섯 개만 사용한다.
  • 대칭 Hann의 기준식은 w[n]=0.5-0.5*cos(2*pi*n/27)이다. hann_definition은 이 수학 기준을 뜻하며 실행 backend를 고르지 않는다.
  • RFFT 길이는 28, DC 제외 bin은 14, epsilon은 1e-12, JS 로그는 자연로그다.
  • AUC 위치 순서는 (level_shift, gradual_drift, amplitude_scaling, period_change)다. 네 번째 period_change는 Task 2에서 Exp466 합성 범위를 그대로 연결하고, AUC 계산은 Task 4에서 한다.
  • method order는 (C0,S10,C10), 유일한 주 후보는 C10, period AUC 하한은 0.85다. 평균 AUC 기준은 없다.

Task 1에는 가속할 점수 연산이 없다. Numba/MLX 선택은 Task 3에서 같은 입력과 seed의 결정성, 수치 일치, 후보 index 일치, 전송·동기화 포함 1.1배 속도 기준을 확인한 뒤에만 한다.

  • publish_result_antigravity는 기존 root를 덮지 않고 정확히 일곱 leaf만 만든다. JSON은 UTF-8, sort_keys=True, compact separator, NaN 금지, 마지막 newline 하나를 사용한다.
