Holdout 신규 데이터셋 일반화 검증 (antigravity)

실험 설계

학습에 전혀 사용되지 않은 UCR 가족 5개(GunPoint, Wafer, TwoLeadECG, FaceFour, SyntheticControl)에 대해:

  1. label-free 특징(width, spectral_entropy, skewness 등) 추출
  2. 결정 트리 규칙으로 방법 예측
  3. 실제 4가지 후보 메서드를 모두 실행해 최적 방법 확인
  4. 라우터 선택이 최적인지 판단

해석 및 결론

  • AUC 관점: 라우터가 합리적 선택을 함 (80% 정확). 특히 entropy > 0.70 → minirocket 규칙이 SyntheticControl을 정확히 포착.
  • zero-FP 관점: 개선 여지 있음. Wafer처럼 width≈150이지만 hydra가 압도적인 경우를 구분할 추가 신호 필요.
  • 핵심 발견: width만으로는 부족하고, kurtosis(Wafer +1.86 vs GunPoint -1.19)가 유망한 보조 신호.

권장 다음 단계

  1. 규칙 v2: width < 200 && kurtosis > 1.5 → hydra_local_gap 추가 제안
  2. Wafer·TwoLeadECG 같은 "중간 길이 ECG류"는 kurtosis로 구분 가능성 확인
  3. holdout 5개 + 학습 8개 통합 데이터셋으로 규칙 재학습 후 LOFO 재검증
  4. 사용자 승인 후 공식 파이프라인 반영
