Exp454 실행 안내서

현재 단계: 구현 전이다. 지금은 공식 명령과 TEST label을 사용하지 않는다.

무엇을 고치는가

실제 Exp449 authority를 받은 뒤, 평가기 안으로 넣기 전에 normalize_exp449_target_authority_antigravity()로 Exp454 불변 타입을 한 번만 만든다. 그 뒤 계산과 12-leaf 형식은 Exp453와 같다.

구현 완료 뒤의 명령 순서

  1. readiness --reviewed-commit LOWER40HEX
  2. readiness가 성공한 경우에만 evaluate --reviewed-commit LOWER40HEX
  3. 평가 결과 12개 파일이 완성된 경우에만 bare inspect
각 명령은 별도 승인 뒤 한 번만 실행한다. 어느 단계든 실패하면 다음 명령을 실행하지 않고 Exp454를 끝낸다. 같은 Exp454를 재시도하지 않는다. 공식 실행 전에는 label session, query, row가 모두 0이어야 한다.

결과 확인

공식 evaluate에서만 48개 순서 고정 query와 72,300개 TEST row를 읽는다. 96개 ordered index와 confusion, FN, FP, F1, bootstrap, decision, 12개 파일 SHA를 독립적으로 다시 계산한다. 계산 결과가 같을 때만 inspect를 실행한다.

역할 분담

Grok 4.6/high는 읽기 전용으로 원인과 대안을 검토한다. Codex가 코드를 합치고 테스트하며 최종 결과를 판단한다. Grok에는 공식 실험 worktree 쓰기 권한을 주지 않는다.
