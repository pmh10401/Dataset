AUC 계산 계약

AUC는 (anomaly>normal wins + 0.5*ties)/(n_normal*n_anomaly)로 계산한다. 점수가 높을수록 더 이상에 가깝다는 기존 방향을 유지하고, tie는 반승으로 계산한다.
