Exp456 실행 안내서

현재 단계: Task 1 governance만 완료되었으며 구현·공식 명령은 아직 시작하지 않았다.

순서와 차단 규칙

  1. Task 2에서 Exp455 통제 복사와 동등성 검증을 한다.
  2. Task 3에서 dataset 이름 결합과 replay를 구현·검증한다.
  3. Task 4에서 닫힌 CLI와 전체 검증·독립 검토를 마친다.
  4. Task 5는 사용자의 별도 승인 뒤에만 공식 evaluate, 성공 시 inspect를 정확히 한 번씩 실행한다.
현재 official_evaluate_started=false, official_inspect_started=false, result_root_created=false다. 공식 실행, label query, 결과 root 생성은 Task 1에서 금지된다. Exp455는 official_evaluation_failed_immutable_no_retry로 보존하며 다시 실행하지 않는다.

공식 결과가 생기기 전 FN·FP·F1과 가족별 FN 변화는 not_available이다. 결과가 통과해도 routing, champion, pending candidate, promotion은 변경하지 않는다.
