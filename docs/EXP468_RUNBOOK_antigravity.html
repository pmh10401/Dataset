Task 6 승인 뒤 단일 실행 경로

사용자 checkpoint 승인 뒤에는 아래 helper 한 경로만 사용한다. 네 개의 evaluate/inspect 명령을 따로 입력하면 sequence-state 검사를 우회하므로 공식 실행으로 사용하지 않는다.

python3 -c 'import subprocess; from scratch.run_exp468_ecg200_local_stft_spectral_redistribution_antigravity import run_private_sequence_antigravity; run_private_sequence_antigravity(subprocess.check_output(("git","rev-parse","HEAD"), text=True).strip())'

helper는 고정 interpreter와 저장소 경로를 사용해 run1 evaluate→inspect→run2 evaluate→inspect를 순차 실행한다. 각 단계 직전에 같은 clean reviewed commit을 확인하고 성공한 단계만 외부 canonical state에 기록한다.
