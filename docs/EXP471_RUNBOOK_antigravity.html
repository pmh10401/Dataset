1. CLI 표면

evaluate와 inspect만 허용합니다. root 인수는 아래 두 고정 경로만 받고, commit은 현재 HEAD와 같은 40자 소문자 hex여야 합니다. launcher는 저장소 밖 작업 디렉터리에서도 동작합니다.

python3 scratch/run_exp471_ecg200_acf_peak_lag_shift_numba_antigravity.py evaluate +  --root /private/tmp/exp471_task6_private_run1_antigravity +  --commit <REVIEWED_COMMIT>

python3 scratch/run_exp471_ecg200_acf_peak_lag_shift_numba_antigravity.py inspect +  --root /private/tmp/exp471_task6_private_run1_antigravity

2. 사전 조건

  1. <REVIEWED_COMMIT>이 현재 HEAD이고 worktree가 clean인지 확인합니다.
  2. /private/tmp/exp471_task6_private_run1_antigravity와 run2 경로가 존재하지 않는지 확인합니다.
  3. 사용자가 private run 1·2를 명시적으로 승인했는지 확인합니다.
git rev-parse HEAD
git status --porcelain
test ! -e /private/tmp/exp471_task6_private_run1_antigravity
test ! -e /private/tmp/exp471_task6_private_run2_antigravity
