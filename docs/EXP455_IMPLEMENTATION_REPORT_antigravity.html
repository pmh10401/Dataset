Exp455 구현 기록

Task 1은 planned-only governance surface를 만들었다. Task 2는 Exp454의 12개 고정 결과와 Exp446 stable-26, Exp404 Hard 좌표를 읽어 48개 immutable authority row와 8개 label-free 특징 row를 만들었다.

실제 source는 한 번만 읽었고 label_query_count=0이었다. TEST 정답은 읽지 않았으며, 특징에는 confusion, TP, FP, FN, TN, TEST label, 변형 번호 필드가 없다.

Task 3은 각 가족 안에서만 다른 데이터셋으로 규칙을 고르는 LODO 라우터를 추가했다. 규칙은 8개 정수 특징의 중간 경계와 양방향만 사용하며, 순서는 FN 최소, FP 최소, 정확한 Fraction F1 최대, candidate 사용 수 최소, 고정 lexical 순서다. held-out outcome을 바꿔도 해당 fold의 규칙과 선택은 변하지 않음을 테스트했다.

Task 4는 48개 행을 한 번씩 더해 baseline, 가족 전체 candidate, 데이터셋별 oracle, LODO router 네 비교를 계산한다. 결과 파일은 임시 주입 경로에만 8개 leaf로 저장하고, 다시 읽을 때는 규칙과 합계를 새로 계산한다. 파일 내용과 해시를 같이 바꿔도 계산값이 달라지면 거부한다.
