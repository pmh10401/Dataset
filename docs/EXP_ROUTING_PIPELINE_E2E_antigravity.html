사용 방법

  1. 공식 파이프라인에서 CANDIDATE_MATRIX 조회하는 부분을 찾습니다.
  2. 다음처럼 교체합니다: 
    # 이전:
# methods = dict(CANDIDATE_MATRIX_ANTIGRAVITY)[family]

# 새로:
from experiments.exp_routing_label_free_antigravity.pipeline_integration_antigravity import (
    get_candidates_for_dataset_antigravity,
)
methods = get_candidates_for_dataset_antigravity(dataset_name)
  3. 학습 가족은 자동으로 기존 값을 유지하고, 미학습 가족은 자동으로 라우팅됩니다.
