최적화 교체보다 학습용 정상의 역할 분리가 우선입니다

같은 특징·손실·가중치 범위에서 최적화를 개선했지만 보류 합성 변형의 검출률은 기존 Exp502를 넘지 못했습니다. 반면 같은 거리 참조와 표본 수를 사용한 비교에서, 표현 학습 참여 여부에 따른 정상 점수 차이가 50개 계열 모두에서 관측됐습니다.

Exp509는 학습 신호를 점검하는 진단입니다. 실제 이상 TEST를 평가하지 않았고 새 모델을 승격하지 않았습니다. 아래 검출률은 보류 정상 TRAIN에서 만든 합성 변형의 검출률입니다. 전체 1,117개에서의 기존 최고 관측 개선은 Exp502의 상대 +3.73%로 유지되며, 10% 목표는 아직 미달성입니다.

1. 표현 학습 참여 여부에서 큰 차이가 확인됐습니다

외부 적합 F를 거리 참조 R, 표현 학습 참여 비교군 S, 표현 학습 제외 비교군 B로 나눴습니다. 표현·스케일러·OAS는 R+S에서만 맞추고, S와 B 모두 같은 R만 거리 참조로 사용했습니다. 두 비교군의 표본 수와 변형 시드도 같으며 어느 쪽도 거리 참조 자체에 포함되지 않았습니다.

표현 학습에 참여한 정상은 합성 이상과 이미 쉽게 분리되는 반면, 참여하지 않은 정상에서는 학습 손실에 유의하게 기여하는 합성 표본이 더 많았습니다. 이는 순위 학습용 정상의 역할 분리를 시험할 근거입니다. 학습 신호가 정확히 0이라는 뜻은 아니며, sigmoid 기준은 사전에 고정한 진단 정의입니다.

표현·스케일러·OAS 중 특정 구성 요소만의 인과 효과를 분리한 실험은 아닙니다. 원래 정상 TRAIN에서 결정한 길이·행별 정규화는 상속했습니다. 이 차이가 Exp510의 성능 향상을 보장하지 않으며, 센서의 원시 측정값이 15배 달라졌다는 의미도 아닙니다.

3. 다음 설계의 우선순위

Exp510에서는 정상 기준 집합 A, 순위 학습 집합 B, 외부 검증 집합 C를 분리하는 방향을 우선합니다. A에서만 표현·스케일러·OAS·참조를 만들고, A에 참여하지 않은 B의 정상과 그 변형으로 가중치를 학습해야 합니다. 학습 후 A+B로 표현을 다시 맞추어 점수 공간을 바꾸지 않는 첫 비교가 필요합니다.

참조 감소의 영향을 구분하기 위해 기존 Exp502, A만 사용하는 비가중 모델, 같은 A와 별도 B를 사용하는 가중 모델을 함께 비교해야 합니다. 약해진 대조군만 이겨서는 성공으로 보지 않습니다. 분할 비율·표본 하한·종료 조건을 실행 전에 고정하고 기존 선별 기준을 유지합니다.

분할별 초기 손실에서 계산한 비악화 해의 RMS 가중치 변화 상한의 중앙값은 1.39%입니다. 이는 현재 학습 문제가 이미 쉬운 상태에서 반복 횟수만 늘려도 큰 변화가 나오기 어려울 수 있음을 설명합니다. 일부 특징의 큰 변화나 검출률 개선 가능성 자체를 배제하는 수치는 아닙니다.

이번에 Exp510은 실행하지 않았습니다. Exp509의 승인 범위인 진단과 후속 설계 근거 정리까지만 완료했습니다. 전체 목표는 FPR≤0.1% 계열 평균 60.0476% 이상, FP0 비악화이며 변경하지 않았습니다.

기존 Exp508 회귀 검사 8개와 새 진단 검사 5개, 총 13개가 통과했습니다. 새 검사는 경계 제약 최적화, 수치적 정류 조건, 강볼록 목적함수 오차 상한, 손실 통계, 역할 분리, 원래 최적화 관측과 거리 항등식을 확인합니다. 모든 분할에서 기존 Exp508의 네 모델·여덟 변형 검출률과 정상 꼬리·학습 목적함수를 재현했습니다.

별도 검산기가 15,250개 저장 배열의 해시를 확인하고 손실·제약 반영 기울기 조건·역할 분리·검출률·집계를 다시 계산했습니다. 전체 기울기 벡터 자체는 원래 검증된 목적함수가 생성했으며, 새로 모든 특징 행렬을 저장해 기울기를 독립 재생성한 것은 아닙니다. 원래 기울기의 수치 미분 검사를 회귀 검사에 포함했습니다.
