Exp455 실행 안내서

현재 단계: 공식 Exp455 evaluate는 clean commit b1ac9c24eea25b1da055d7076240d3058ffce613에서 정확히 한 번 실행됐고, 특징과 authority 대상 순서가 달라 exit 1로 중단됐다. 공식 inspect는 실행하지 않았고 결과 폴더는 없다. Exp455를 다시 실행하지 않는다.

완료된 흐름

  1. Exp454 immutable evidence를 읽기 전용으로 검증했다.
  2. 8개 dataset의 label-free 특징과 leave-one-dataset-out 결정을 합성 검증했다.
  3. 승인된 clean commit에서 공식 evaluate를 한 번 실행했고 순서 계약 충돌로 중단했다.
Exp455는 official_evaluation_failed_immutable_no_retry 상태다. evaluate/inspect를 다시 실행하지 않는다. routing 활성화, champion 또는 pending candidate 변경, promotion도 금지된다. 순서 계약 수정은 새 실험 번호에서만 진행한다.
