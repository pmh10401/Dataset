Prediction과 label boundary

48 target datasets의 모든 candidate prediction 및 SHA inventory가 immutable일 때까지 TEST label을 열지 않는다. 정확히 한 ordered session이 72,300 rows를 소비하며 remaining 1,069 datasets는 immutable Exp448 aggregate confusion으로만 합성한다. 현재 session count와 label access는 0이다.

CPU·accelerator·launcher

preflight logical CPUs = 12, official outer workers = 11, every transformer n_jobs=1. launcher는 import 전 정확히 다음 일곱 environment variable을 1로 고정한다:

OMP_NUM_THREADS=1; OPENBLAS_NUM_THREADS=1; MKL_NUM_THREADS=1; VECLIB_MAXIMUM_THREADS=1; NUMEXPR_NUM_THREADS=1; BLIS_NUM_THREADS=1; AEON_NUM_THREADS=1

readiness는 MLX/mlx-metal/PyTorch/MPS version/device와 tensor eligibility를 기록한다. 공식 aeon transform은 CPU-only로 유지한다. 어떤 accelerated stage도 frozen algorithm/feature/score/threshold/routing을 보존하고 deterministic parity, numerical tolerance, finite output, all-alpha index identity, 1.1x exact-stage speed gate를 통과하기 전에는 canonical이 아니다. heavy MLX/MPS process를 병렬로 두지 않는다.

Dashboard checkpoint

existing owner-only dashboard에는 phase/status, aggregate candidate counts, backend decision category, label-access state와 완료 뒤 aggregate FN/FP/F1/qualification만 게시할 수 있다. raw labels, indices, internal family/dataset lists, per-instance data, hashes, paths, logs, DB, checkpoint, secret은 금지한다. dashboard publication의 실패는 scientific artifact 변경 또는 rerun을 허가하지 않는다.

비승격

FP <= 314, FN < 1988, F1 non-regression 및 target-family FN 감소는 candidate qualification gate일 뿐 champion, pending candidate, routing, promotion, operational alert를 자동 변경하지 않는다.
