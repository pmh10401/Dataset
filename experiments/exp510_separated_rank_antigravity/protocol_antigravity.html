Exp510: 정상 기준과 순위 학습 표본의 역할 분리

2026-09-18 승인한 후보 하나를 평가한다. Exp509의 진단을 바탕으로 정상 기준 A와 순위 학습 B를 분리한다. 기존 Exp502 및 동일 A를 사용하는 비가중 대조군을 모두 넘어서는지 확인한다. Exp507~509의 코드·결과·코드맵은 보존한다.

1. 분할 및 최소 표본 수

기존 50계열·계열당 한 데이터셋의 정상 TRAIN을 seed=20260721의 동일 외부 5분할 F/C로 나눈다. |F|≥32이면 seed=20260721+2510으로 F 내부 인덱스를 섞고, 앞 floor(|F|/4)개를 B, 나머지를 A로 지정한 뒤 각각 정렬한다. A가 약 75%, B가 약 25%이다. C는 생성자·표현 적합·가중치 학습에 전달하지 않는다.

정상 참조가 32개 미만이면 A/B 학습을 하지 않고 두 새 점수를 기존 Exp502의 square_joint와 정확히 같게 반환한다. 이는 정상 TRAIN 수만으로 정한 사전 폴백이다. 점수 오류나 TEST 값으로 폴백을 선택하지 않는다. 모든 표본은 기존 전처리의 전체 정상 TRAIN 기준 길이와 행별 z 정규화를 상속한다. 따라서 길이 추정까지 A 전용이라고 주장하지 않는다.

2. 표현과 학습

공식 Exp502의 원시·평균 중심화 제곱 MiniRocket, RobustScaler 10–90, 잔차 보존 OAS를 재사용한다. 새 모델의 인코더·척도·공분산·정상 참조는 A에서만 만든다. 전체 F에서 학습하는 기존 대조군은 별도의 객체이며 새 모델과 적합 상태를 공유하지 않는다. 가중치 학습 후 A+B로 다시 맞추지 않는다.

B가 128개 이하이면 전부 사용하고, 초과하면 seed=20260721+1510의 고정 무작위 128개 부모를 정렬하여 사용한다. 기존 네 변형을 seed=20260721+1508로 부모에서 만든다. 정상 B와 합성 변형 모두 동일 A만 참조한다. B와 A가 분리되어 있으므로 별도의 부모 참조 제거는 없다.

비가중 OAS 거리에서 가까운 k=min(3,|A|) 참조 선택
G_j(q)=mean_k((q_j-r_kj)^2/d_k); d_k=0이면 해당 기여=0
scale=median_A(mean min(3,|A|-1) 자기 제외 거리)+1e-9
새 비가중 점수=sum_j(G_j)/scale
역할 분리 학습 점수=(G/scale)·w
loss=mean(softplus(0.25+0.1·logsumexp(Nw/0.1)-Aw))+0.1·mean((w-1)^2)

수식의 N과 A는 각각 정상·합성 기여 행렬이며, 정상 기준 집합 이름 A와 구분한다. 가중치 초기값 1, 범위 [0.25,4], 공식 SciPy L-BFGS-B 및 Exp509의 동일 목적함수·해법을 사용한다. maxiter=2000, maxfun=5000, maxls=40, maxcor=20, gtol=1e-8, ftol=1e-15, jac=True이다. 재시작·반복 예산 확대·가중치나 온도 검색은 없다.

종료 상태와 projected-gradient, 강볼록 목적함수 오차 상한, 초기·최종 손실을 기록한다. 사전 반복 한도 내 유한한 최종 가중치를 사용하며 수렴 미확정을 숨기거나 다른 모델로 바꾸지 않는다. 비유한 입력·출력은 오류로 중단한다. 이 손실은 학습용 순위 대리지표이며 실제 FPR 보장이나 정식 partial AUC 해법이 아니다.

4. 결과를 보기 전에 고정한 통과 조건

기존 네 대조군 각각에 대해 변형별 검출률은 분할 평균 후 50계열 동일 가중이다. 새 후보는 다음을 모두 만족해야 전체 평가로 진행한다.

① 기존 변형의 최저 검출률이 네 대조군의 해당 최저 검출률 중 최댓값보다 0.02 이상 높음. ② 기존 네 변형 전체 평균이 네 대조군 평균의 최댓값 이상. ③ 검증 전용 네 변형 평균이 네 대조군 평균의 최댓값 이상. ④ 정상 꼬리 지표가 MiniRocket의 3배 이하. 꼬리는 (max−median)/(q75−q25+1e-9), 분할 평균 후 계열 중앙값이다. 기준 꼬리의 분모 하한 1e-9는 기존 규칙을 유지한다.

평균 비악화도 각 대조군을 모두 대상으로 하므로, 참조가 줄어 약해진 모델만 이기는 것으로 통과할 수 없다. 실패 시 기존 Exp502를 유지하고 Exp510을 종료한다. 모집단·분할·최적화·문턱·변형·통과 조건을 관측 후 완화하지 않는다.

5. 조건부 전체 평가

TRAIN 통과와 독립 검산 뒤에만 동일 1,117개 데이터셋·128계열에서 전체 점수를 생성한다. 기존 정상 참조 상한 1000, seed=20260721+7919+4096으로 먼저 참조를 선택하고 그 안에서 동일 A/B 규칙을 적용한다. 기존 전처리·제외 규칙·TEST 인덱스를 유지한다. 정상 수가 적은 경우도 삭제하지 않고 위의 사전 폴백을 적용한다.

기준 MiniRocket 및 Exp502 점수·순위를 재현한다. 코드·후보·프로토콜을 TEST 값 조회 전에 고정하고, 모든 점수·메타데이터 해시를 고정한 뒤 평가용 TEST 라벨을 읽는다. FP0, FPR≤0.1%·0.5%·1%의 계열 평균·데이터셋 평균·이상 표본 가중 평균과 seed=20260721의 계열 paired bootstrap 2,000회를 보고한다. 목표는 MiniRocket 대비 FPR≤0.1% 계열 검출률 상대 10% 이상, FP0 계열 검출률 비악화다. 수치 목표는 0.6004757235442457이다.

반복 노출된 개발 벤치마크다. 미사용 holdout 또는 새로운 장비의 일반화·운영 오탐률을 보장하지 않는다. 합성 TRAIN 선별 성능과 실제 TEST 관측 성능을 분리하여 보고한다.

6. 검증·가속·출처

역할 분리, B 변경 시 새 모델의 A 적합 상태 불변, 기존 대조군 재현, 동일 A 비가중 점수와 거리 합 항등식, 작은 표본 폴백, 상수·짧은 입력, 질의 배치·순서 불변을 검사한다. 로컬에 역할 인덱스와 학습 점수·가중치·기울기, 보류 점수 배열·해시를 보존하여 별도로 집계와 결정을 검산한다. 원본 파형·특징 행렬·개별 데이터는 Grok 등 외부 모델로 보내지 않는다.

공식 MiniRocket과 SciPy 최적화기를 재작성하지 않는다. 전체 적합·점수 단계의 NumPy/Numba/Torch CPU 동등성·안정 순위·정상1000개 예산0/1/5/10 후보 인덱스, 최초·준비 후 시간, 변환·컴파일 비용을 기록한다. MLX/MPS는 실제 float64 GPU 행렬곱을 확인한다. 정확성과 전체 단계 1.1배 이점이 확인되지 않으면 NumPy/SciPy float64를 유지한다. CPU 작업자는 논리 CPU−1, 내부 스레드1이다.
