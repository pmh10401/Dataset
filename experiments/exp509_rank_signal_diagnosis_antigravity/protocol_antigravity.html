Exp509: 학습 신호와 최적화 진단

2026-09-18 사용자가 승인한 실행 범위는 Exp509 하나이다. 정상 TRAIN 50계열·250개 고정 분할을 진단하고 후속 설계의 근거를 제시한다. Exp510, 전체 TEST 평가, 새 모델 승격은 실행하지 않는다. 기존 실험의 코드·결과·코드맵은 보존한다.

1. 같은 목적함수의 최적화만 비교

Exp508과 같은 외부 적합 F 및 보류 C를 사용한다. 기존 TailRankHeads의 fit_tail_weights 호출을 프로세스 안에서 일시적으로 감싸 N·A를 관측하고 원 함수를 그대로 호출한 후 finally로 복원한다. 파형·특징·표현·OAS·참조·손실·정규화·가중치 범위가 같은 조건에서 초기값 1, 기존 80회 Adam, L-BFGS-B를 비교한다. 원래 모든 fold의 일반·검증 전용 변형 검출률과 정상 꼬리, 초기·최종 목적함수를 재현해야 한다.

temperature=0.1, margin=0.25, regularization=0.1
loss=mean(softplus(margin+temperature*logsumexp(Nw/temperature)-Aw))+0.1*mean((w-1)^2)
bounds=[0.25,4], L-BFGS-B starts at all ones
maxiter=2000, maxfun=5000, maxls=40, maxcor=20, gtol=1e-8, ftol=1e-15

수렴 여부는 종료 메시지와 별도로 ||w−clip(w−gradient,0.25,4)||∞≤1e-8로 확인한다. 반복 한도에 도달해도 재시작·예산 확대·조용한 폴백을 하지 않는다. 강볼록성 μ=0.2/p에서 d=w−clip(w−gradient/μ,0.25,4), gap=gradient·d−μ||d||²/2는 정확한 연산을 가정한 목적함수 오차 상한이다. 부동소수점 수치를 증명서라고 과장하지 않으며 projected gradient와 함께 기록한다.

초기 손실 L0가 주어졌을 때 손실이 증가하지 않는 해는 RMS(w−1)≤sqrt(L0/0.1)를 만족한다. 일부 특징의 큰 변화나 검출률 개선 가능성까지 배제하는 한계는 아니다. 정상 최대값, 합성 이상 점수 차이, sigmoid≥0.01·0.1인 학습 표본 비율, 유형별 동일 가중 손실을 확인한다. 손실의 softmax 정상 표본 유효 개수도 기록한다.

2. 표현 학습 참여 여부를 같은 거리 조건에서 비교

F를 seed=20260721+2509+fold로 R,S,B로 나눈다. |S|=|B|=floor(|F|/4), 나머지가 R이며 모두 분리한다. A=R∪S로만 공식 Exp502 표현·스케일러·OAS를 맞춘다. 두 집단 모두 같은 OAS 공간, 같은 R 전용 거리 참조, 같은 R의 자기 제외 3이웃 거리 중앙값+1e-9를 사용한다. S와 B 어느 쪽도 거리 참조 자체에는 들어가지 않는다. S는 표현 적합에 참여했고 B는 참여하지 않았다는 차이를 비교한다.

S,B의 표본 수와 변형 시드(20260721+1508) 및 기존 네 변형을 동일하게 맞춘다. B로 새 가중치를 학습하지 않고 초기 가중치 1에서 정상 상단과 합성 분리 난도를 진단한다. C는 역할 선택이나 적합에 사용하지 않는다. 기존 전체 정상 TRAIN에서 정한 길이와 행별 z 전처리는 그대로 상속한다. 따라서 모든 전처리가 내부 A에서만 정해졌다고 주장하지 않는다. 이 비교만으로 표현·스케일러·OAS 중 어느 구성 요소가 원인인지, 후속 모델이 개선될지를 확정하지 않는다.

3. 검증·데이터·가속 경계

TEST 값·라벨은 읽지 않는다. 원본 파형이나 특징 행렬을 외부 모델에 보내지 않는다. 검산을 위해 분할 역할, 초기/Adam/L-BFGS-B의 가중치·기울기·학습 점수, 보류 정상·변형 점수, 동일 조건 S/B 점수를 로컬 압축 배열로 보존한다. 별도 검산기는 이 점수에서 손실·기울기 조건·검출률·집계를 다시 구하고 해시를 확인한다. 일반·검증 전용 변형은 각각 Exp508의 종류·강도·시드를 그대로 유지한다.

공식 SciPy L-BFGS-B 및 NumPy float64를 사용한다. Numba/Torch CPU의 기존 동일 목적함수 구현을 새 최적화 전체 단계에서 합성 입력으로 비교하고 최초·준비 후 시간과 점수·순위·예산 인덱스 동등성을 기록한다. MLX/MPS는 실제 float64 GPU 연산을 확인한다. 공식 최적화기·MiniRocket은 재작성하지 않는다. GPU 동등성이 없으면 CPU를 유지하며 논리 CPU−1 작업자, 내부 스레드 1을 적용한다. 추가 통계·정렬은 NumPy를 유지하며 단순히 GPU 사용을 위해 바꾸지 않는다.

공식 실행 전에 소스·규칙·단위검사·가속 검토를 해시로 고정한다. 데이터셋별 체크포인트는 해시와 완료 상태 확인 후에만 재사용한다. 표본 누락·비유한·기준 재현 실패는 중단하며 데이터셋을 추가 제외하지 않는다. SciPy 기준: 공식 L-BFGS-B 종료 조건.

4. 해석과 후속 경계

250개 분할을 50개 독립 계열로 부풀려 해석하지 않는다. 보류 검출률은 분할 평균 후 계열을 동일 가중한다. 학습 조건 차이는 계열별 분할 중앙값·전체 중앙값과 일관된 방향의 계열 수로 제시한다. 이는 반복 노출된 정상 TRAIN을 이용한 진단이며 새로운 실제 이상 검출 성능이 아니다. 기존 선별 조건(+2%p·평균 비악화·검증 전용 평균 비악화·정상 꼬리)을 완화하지 않는다. 전체 목표는 FPR≤0.1% 계열 검출률 0.6004757235442457 이상, FP0 비악화로 그대로다.
