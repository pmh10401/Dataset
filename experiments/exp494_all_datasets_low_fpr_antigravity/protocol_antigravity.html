Exp494 전체 데이터셋 저오탐 평가

사용자의 전체 데이터셋 측정 요청에 따른 Exp493 고정 모델의 평가 범위 확대. 새 모델 선택이나 목표 재학습을 하지 않는다.

  1. 원본 1,119개를 목록화한다. 기존 정상 클래스 매핑이 없는 CornellWhaleChallenge와 정상 TRAIN이 1개인 Phoneme_normal_39는 기존 정의상 평가 불가로 명시한다. 나머지 1,117개를 모두 처리한다.
  2. MiniRocket LocalGap/LOF, MultiRocket LocalGap, Hydra와 Hybrid의 기존/안정화 LocalGap 점수 정의·seed·TRAIN 전처리는 Exp489/492/493과 동일하다. 검증된 125개 현재 점수와 특징을 재사용하며, 누락된 점수만 생성한다. 이전 버전의 전체 점수 캐시는 현재 점수와 혼합하지 않는다.
  3. 정상 TRAIN≥5인 956개에서만 5-fold A/B 행동 특징을 계산한다. 나머지 161개는 네 모델의 고정 full-fit TEST 점수와 LOF를 계산할 수 있지만 42D 특징을 만들지 않는다. 42D를 임의의 MiniRocket fallback으로 대체하지 않는다.
  4. 라우터의 학습 모집단은 Exp493의 원래 125개 대표 데이터셋으로 고정한다. 기존 24D/old42D/stable42D × old/stable 목표의 6개 Ridge와 두 선택 기준을 동일한 donor-only 전처리·alpha=10·family 가중치로 재구성한다. 평가 대상과 같은 원본 family를 모두 제외하여 예측한다. 새 TEST 결과를 라우터 학습에 쓰지 않는다. 원래 125개 예측과 경로가 재현되어야 한다.
  5. 전체 점수·TRAIN 특징을 저장하고 고정 경로를 저장한 뒤 확장된 TEST 라벨로 평가한다. 기존 개발 라벨이 이미 알려진 사실과 cohort 반복 사용을 명시한다.
  6. FPR 비교 구간은 이전 답변과 동일한 0, 0.001, 0.005, 0.01로 고정한다. 관측 FP 허용 수 floor(alpha*n_normal)에서 동점 분할 및 보간 없이 가능한 최대 TPR을 계산한다. TEST ROC 진단이며 운영 임계값 교정이나 오탐 보장이 아니다.
  7. 전체 1,117개/128 family에서 고정 모델과 24D를 비교한다. 모든 모델의 공통 956개/125 family 비교도 별도로 한다. 주 집계는 family 내 데이터셋 평균 후 family 동일 가중 평균이다. 데이터셋 동일 가중 평균·이상 샘플 가중 평균·ZF 합계·AUROC와 coverage도 함께 공개한다.
  8. 공식 aeon/torch CPU/scikit-learn/scipy 구현과 기존 Numba 커널을 재사용한다. 새 tensor score 알고리즘은 없다. MLX/MPS float64 제약 및 공식 변환기 불변성을 확인하고 CPU를 유지한다. 새 집계는 NumPy와 독립 ROC/순서통계량으로 교차 확인한다. CPU 병렬은 논리 CPU 수−1, inner threads=1이다.
  9. smoke에서 원래 데이터셋의 full TEST 점수, 두 18D 특징, 동점 처리, 작은 TRAIN 및 family 제외 예측을 확인한다. 수치 허용오차는 기존 점수 rtol=1e-10/atol=1e-8, 특징 rtol=atol=1e-10, 라우터 예측 rtol=atol=1e-12다. 비교 구간의 실제 선택 인덱스는 동일해야 한다. 기존 공식 결과를 수정하지 않는다.
