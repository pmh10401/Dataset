TEST 평가 전 고정한 상수 학습 행 처리

전체 점수 생성 중 UWaveGestureLibraryZ_normal_8의 정상 TRAIN index 85가 정확히 상수여서 Exp479 표준화가 거부했다. 원본 행을 제외하지 않고 float64 행 표준화에서 정확히 표준편차가 0인 행의 분모만 1로 둔다. 이 행은 0 벡터가 된다. 분산이 양수인 행에는 기존 산술을 그대로 적용하고 bitwise 일치를 검사한다. TEST 행과 인덱스는 그대로 유지한다. 모든 모델에 동일한 입력을 제공한다.

과거 foundation.py의 작은 표준편차 처리 관례와 일관되지만, 과거 962개 캐시 생성 임시 스크립트가 없어 해당 데이터셋의 역사적 재현으로 주장하지 않는다. 근접 상수 행의 임계값이나 기존 모델 정의를 새로 도입하지 않는다. 이 보충 규칙은 확장 TEST 라벨을 열기 전에 기록한다.

기존 53개 코드 해시, 기존 프로토콜, 성공 체크포인트를 보존한다. 실패 로그도 보존한다. 이 데이터셋만 별도 출처로 점수를 생성하고 복구 코드·프로토콜·회귀 검사를 별도 해시에 묶는다. 전체 1,117개 점수 확인 및 경로 저장 후 기존 평가 함수를 호출한다. 모델 재선택·재학습·임계값 최적화는 추가하지 않는다.

NumPy float64 표준화 및 기존 Numba 리샘플러를 유지한다. 추가되는 분모 조건은 병목 단계가 아니므로 추가 JIT 및 GPU 왕복 변환을 도입하지 않는다.
