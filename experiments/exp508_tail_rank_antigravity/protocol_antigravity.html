Exp508: 정상 상단 순위 학습

사용자의 2026-09-17 재개 요청에 따른 하나의 고정 후보이다. Exp507의 중지 기록 및 Exp494~507의 코드·결과를 보존한다. 목표는 동일 1,117개 데이터셋·128개 계열의 FPR≤0.1% 계열 평균 검출률에서 MiniRocket 대비 상대 10% 이상 개선하고, FP0 계열 평균을 악화시키지 않는 것이다. 기준 0.5458870214038597의 1.1배인 0.6004757235442457 이상이 필요하다.

고정된 표현과 점수

Exp502의 공식 MiniRocket, 원시·평균 중심화 제곱 표현, RobustScaler 10–90, 잔차 보존 OAS를 그대로 재사용한다. 기준 MiniRocket, 원시 OAS, 원시·제곱 OAS는 원래 점수와 순위를 재현해야 한다. OAS 공간에서 기존 비가중 거리의 가까운 min(3,n)개 참조를 선택한다. 각 특징의 기여 G_j=mean_k((q_j-r_kj)²/d_k)를 합하면 원래 평균 이웃 거리가 된다. d_k=0인 항의 기여는 0이다. 특징별 가중치 w로 G·w를 계산하되 이웃 선택과 OAS를 학습된 가중치로 바꾸지 않는다.

TRAIN 학습과 누출 방지

정상 TRAIN의 외부 5분할마다 표현·스케일러·OAS·참조·가중치를 적합 분할에서만 학습한다. 학습 부모는 seed=20260721+508로 최대 128개를 중복 없이 뽑아 정렬한다. 모든 적합 참조의 자기 자신 제외 평균 이웃 거리의 중앙값+1e-9로 G를 나눈다. 정상 부모와 해당 합성 변형 모두 거리 계산에서 같은 부모 참조를 제외한다. 부모 제외는 거리에서만 적용되며 표현·OAS의 별도 내부 교차 적합을 뜻하지 않는다. 외부 검증 부모는 전체 적합 과정에서 제외한다. 참조가 16개 미만이면 기존 square_joint 점수를 정확히 재사용하며, 그 외 점수 오류는 중단한다.

기존 네 변형은 local_level, local_scale, permuted_quarters, phase_randomized이다. 학습에는 seed=20260721+1508을 쓴다. 검증은 기존 seed=20260721+1709×(fold+1)를 유지한다. 각 변형의 표본 수와 가중치는 동일하다.

고정 최적화

sN=Nw, sA=Aw, t=0.1·logsumexp(sN/0.1)
loss=mean(softplus(0.25+t-sA))+0.1·mean((w-1)²)
w 초기값=1; 투영 범위=[0.25,4]
Adam 80회, 학습률 0.05, beta1=0.9, beta2=0.999, epsilon=1e-8

정상 최댓값을 부드럽게 근사하는 순위 학습 대리지표이다. 정식 partial AUC 최적화 알고리즘 또는 실제 오탐률 보장으로 부르지 않는다. 조기 종료나 TEST 기반 튜닝은 없다. 초기·최종 목적함수를 기록하고 수렴 또는 개선을 미리 주장하지 않는다.

학습에 넣지 않는 검증 변형

weak_level: 길이의 1/10 구간에 ±1.25, weak_scale: 같은 길이 구간에 0.5 또는 1.75배, sparse_spike: max(1,L//50)곳에 ±4, time_warp: 시간 좌표의 지수 0.65 또는 1.5를 적용한다. 변형 후 기존 방식으로 행 z-정규화한다. seed=20260721+2508+1709×(fold+1)로 검증 부모에만 적용하며 최적화에는 넣지 않는다. 유형 일반화와 강도 일반화를 함께 보는 보조 검사이며 미사용 실제 이상 검증은 아니다.

변경하지 않는 선별 조건

Exp495가 정한 50개 계열·계열당 한 데이터셋, 5분할을 유지한다. 검증 정상 최대 점수를 엄격히 초과해야 검출이다. 세 anchor 중 기존 네 변형 평균의 최솟값→네 변형 전체 평균→고정 순서로 best_anchor를 고른다. 순서는 MiniRocket, oas_distance, square_joint, tail_rank이다.

tail_rank가 전체 평가로 진행하려면 다음을 모두 만족해야 한다: 최저 변형 평균이 best_anchor보다 0.02 이상 높음; 네 변형 전체 평균 비악화; 정상 꼬리 지표의 계열 중앙값이 MiniRocket의 3배 이하; 검증 전용 네 변형 전체 평균이 세 anchor의 해당 평균 중 최댓값 이상. 정상 꼬리는 (max−median)/(q75−q25+1e-9), 분할 평균 후 계열 중앙값이다. 하나라도 실패하면 새 TEST 평가를 하지 않고 이번 후보를 기각한다. 이 조건을 결과 관측 후 완화하지 않는다.

진단과 전체 평가의 구분

기존 Exp502·507의 저장된 점수와 평가용 라벨로 높은 정상 점수와 검출 상보성을 후향 분석한다. 이 진단은 공개되지 않은 holdout 분석이 아니며, 합집합을 같은 오탐 예산의 운영 앙상블 성능으로 제시하지 않는다. FP0 이외에서는 합집합 오탐이 예산을 넘을 수 있다. 진단의 개별 라벨·점수·표본은 외부 모델에 보내지 않는다. 이미 고정한 후보의 가중치·임계값·데이터 제외에 사용하지 않는다. 점수만으로 파형 표현의 정보 손실 원인을 확정하지 않는다.

선별을 통과한 경우에만 같은 1,117개 전체에서 기준점수 재현, 새 후보 점수·인덱스·코드·프로토콜 해시 동결 후 새 후보의 TEST 성능을 계산한다. FP0, FPR≤0.1%·0.5%·1%, 계열 평균·데이터셋 평균·이상 표본 수 가중 평균과 계열 paired bootstrap 2,000회를 보고한다. 반복 노출된 개발 벤치마크이며 독립 holdout 성능은 아니다.

가속과 실행

공식 MiniRocket을 재작성하지 않는다. NumPy/SciPy float64가 정규 구현이다. 새 최적화 단계의 Numba·Torch CPU 경로를 같은 합성 입력과 시드로 비교하며 최초 호출·준비 후 시간, 전체 head 적합+질의 시간, 점수 허용오차 rtol=1e-10/atol=1e-8, 안정 순위, 정상 1000개 기준 예산 0/1/5/10의 후보 인덱스 일치를 기록한다. MLX·MPS는 실제 float64 지원 여부를 검사한다. 해당 경로가 불가능하면 이유와 버전을 기록한다. 전체 head에서 정확성과 1.1배 속도가 모두 확인된 경로만 공식 실행 전에 승격 가능하다. 병렬 CPU는 논리 CPU−1, 내부 스레드 1이다.

근거
