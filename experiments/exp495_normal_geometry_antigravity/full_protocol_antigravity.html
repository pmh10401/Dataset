TRAIN에서 고른 OAS 거리 후보의 전체 비교

정상 TRAIN 50개 계열의 5-fold 합성 변형 비교에서 oas_distance가 사전 선택 규칙에 따라 선택됐다. 후보나 파라미터를 다시 선택하지 않고 Exp494의 1,117개·128개 계열 전체에서 한 번 비교한다. 2개 기존 제외 대상과 상수 학습 행 1개 보충 규칙을 그대로 유지한다. TEST 선택기나 앙상블은 만들지 않는다.

대표적인 실제 검출률 목표는 오탐률 0.1% 이하 계열 평균 검출률의 상대 10% 개선이다. 오탐 0건 검출률이 기존보다 낮으면 채택하지 않는다. 네 오탐 한도와 계열 평균·데이터셋 평균·이상 표본 가중 평균을 함께 보고한다. 계열 단위 2,000회 paired bootstrap으로 주지표 상대 차이의 95% 구간도 보고한다. seed는 기존 SEED를 유지한다.

MiniRocket fit/reference/seed/전처리를 유지하고, 새로 계산한 대조군 점수와 전체 순위가 Exp494 저장 점수와 일치해야 한다. OAS 공간의 이웃 평균 거리가 후보 점수다. dtype float64 CPU가 기준이고 수치 허용오차는 rtol 1e-10, atol 1e-8이다. 전체 점수와 입력 인덱스 및 코드 해시를 저장한 뒤 TEST 라벨을 읽는다. 중단 시 검증된 점수만 재사용한다.

주평가 모집단이나 가중치를 결과에 따라 바꾸지 않는다. 이전 TEST 노출이 있으므로 이 비교는 개발 결과이며 미사용 자료 일반화 검증이 아니다. 실제 개선과 합성 검출률을 구분하고, 목표 미달이면 미달 사실을 남긴다. 공식 결과·원본 DB·이전 실험은 수정하지 않는다.
