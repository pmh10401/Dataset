Exp512: 고정 Exp511의 별도 탐색 TEST 평가

2026-09-18 사용자가 실제 TEST 평가를 별도 탐색 평가로 진행하도록 승인했다. Exp511의 TRAIN 기각과 코드·모델·설정은 보존한다. 이 평가는 TRAIN 승격 조건을 통과했다는 주장이 아니며, 결과에 따른 설정 변경·추가 후보·모델 자동 승격은 없다.

고정 모델과 모집단

Exp511 CrossfitRankHeads를 수정 없이 호출한다. 동일한 1,117개 데이터셋·128계열, 기존의 2개 제외 데이터셋과 비유한 행 제외, 전처리, TEST 인덱스를 그대로 사용한다. 기존 UWaveGestureLibraryZ_normal_8 상수 전처리도 그대로 재사용한다. 정상 참조 상한1000, seed=20260721+7919+4096을 적용한 후 기존 네 A/B 역할을 적용한다. n<32 폴백과 부모 상한128, 모든 목적함수·최적화 설정·정규화·산술평균 규칙은 Exp511과 같다.

일곱 점수 MiniRocket, oas_distance, square_joint, a_unweighted, separated_rank, crossfit_unweighted, crossfit_rank를 같은 TEST에 생성한다. 후보는 crossfit_rank 하나다. MiniRocket과 Exp502 square_joint는 과거 전체 점수와 rtol=1e-10, atol=1e-8 및 안정 순위를 재현한다. 참조·역할·부모 인덱스, 학습 가중치, 최적화 상태, 구성 모델별 점수와 해시를 로컬에 저장한다. 추론 배치는128이다.

점수 동결과 평가 경계

기존 TRAIN 검산·가속·코드 검토와 새 실행기 테스트·독립 검토를 확인한 후 코드맵·프로토콜·입력·선행 결과를 해시로 동결한다. 점수 생성 단계에는 TEST 라벨 조회 함수를 호출하지 않는다. 모든1,117개 점수와 메타데이터의 해시를 동결한 뒤에만 별도 평가 단계가 TEST 라벨을 연다. 오류 발생 시 데이터셋 제외·모델 대체·점수 보정은 하지 않으며 오류를 기록한다. 완료된 체크포인트는 같은 동결 상태에서만 재사용한다.

사전 평가 지표

기존 metric/summarize를 그대로 사용하여 FP0 및 FPR≤0.001/0.005/0.01에서 계열 동일 가중 평균, 데이터셋 동일 가중 평균, 이상 표본 수 가중 검출률을 계산한다. 라벨을 사용한 회고적 ROC 한계 성능이며 실제 배포 문턱의 오탐률 보장이 아니다. 주지표는 FPR≤0.001의 계열 평균이다. 목표는 MiniRocket 대비 상대10% 개선(검출률0.6004757235442457 이상)과 FP0 계열 평균 비악화이며, 관측 목표 달성과 통계적 불확실성을 구분한다.

Exp511 후보를 MiniRocket, Exp502 및 같은 네 분할의 비가중 평균과 비교한다. 네 한도의 계열별·데이터셋별 개선/동일/악화 개수를 기록하며 차이 판정은 절대1e-12를 허용한다. 128계열 단위 paired bootstrap 2000회, seed20260721, 백분위95% 구간으로 절대 차이와 상대 차이를 보고한다. 개선·악화 계열의 이름과 수치는 별도 CSV에 모두 남긴다. 이 구간은 반복 연구와 후보 선택 전체의 다중비교를 보정하지 않는다.

가속과 검증 범위

Exp511에서 검증한 NumPy/SciPy float64 경로를 그대로 사용한다. 기존 다섯 대조군 보존 경로의 Numba/Torch 속도 이점은1.1배에 못 미쳤고 MLX/MPS float64는 미지원이었다. 공식 변환·거리·평가 함수를 재작성하지 않는다. CPU 논리수−1 작업자, 내부 스레드1을 사용한다. 새 실행기는 정상 합성 입력의 경계32·작은 표본 폴백·배치·대조군·동결 변조 거부를 테스트한다. 독립 검산은 저장된 점수로 ROC·집계·paired bootstrap·계열 차이를 재계산하며 원본 표현과 가중치 기울기의 전면 독립 재학습은 아니다.

외부 검토에는 코드·설계만 제공하며 원본 파형·특징·점수·개별 라벨은 전달하지 않는다. 전체 결과를 본 뒤 모델을 수정하지 않는다. 이번 승인은 고정된 평가 한 번이며 새로운 실험 가설의 실행 승인이 아니다.
