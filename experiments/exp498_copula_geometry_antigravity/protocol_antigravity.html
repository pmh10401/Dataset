MiniRocket 주변 분포의 순위 정규화

MiniRocket 전처리·normal TRAIN reference cap1000·seed를 유지한다. 원본 PPV 각 열을 TRAIN에서 정렬한다. TRAIN 고유값이2개 미만인 열을 제외한다. q의 좌·우 삽입 인덱스를 l,r이라 할 때 u=(l+0.5(r−l)+0.5)/(n+1)를 [1/(n+1),n/(n+1)]로 제한한 뒤 scipy.special.ndtri(u)를 취한다. TEST/검증 표본끼리 순위를 매기지 않는다. 같은 값을 가진 TRAIN·query는 같은 변환이다.

후보 순서는 MiniRocket, oas_distance, rank_distance, rank_oas_distance, qt_oas_distance, clipped_rank_oas_distance, atom5_rank_oas_distance다. 기준 OAS와 모든 새 후보의 head는 가까운3개 정상 이웃의 평균 거리로 고정한다. rank_distance는 OAS 없이 순위 공간 거리, rank_oas_distance는 전체 잔차를 보존하는 기존 OAS를 순위 공간에 적용한다. qt는 공식 sklearn QuantileTransformer(output_distribution=normal,n_quantiles=min(64,n),subsample=None,random_state=SEED) 후 같은 ndtri 끝값으로 clip한다. clipped_rank는 Gaussian값을 추가로[-2,2]에clip한다. atom5는 고유값5개 미만 열을 제외한다. 새 공간에 RobustScaler를 추가 적용하지 않는다.

n<16 또는 해당 mask의 활성 열<8이면 해당 새 후보는 기존 oas_distance로 되돌아간다. 이 조건은 TRAIN만으로 정한다. 비유한 입력·변환·점수는 실행 오류로 처리한다. 검증/TEST 점수에 따른 재선택이나 fallback은 없다. mask로 사라진 특징의 이상 정보를 잃거나 범위 밖 쿼리가 같은 순위값으로 포화될 수 있다.

같은50개 계열,5-fold의 fit 정상만으로 encoder/scaler/mask/순위/OAS를 학습한다. 네 검증 변형은 held-out 정상에서 만든다. 각fold의 정상 최대 점수를 임계값으로 사용하는 기존 검출률을 유지한다. 정상 tail 진단 T=(max−median)/(Q75−Q25+1e-9)를 각 fold에서 계산하고, 계열별fold평균 후50계열 중앙값을 산출한다. 새 후보는 이 값이 MiniRocket의3배 이하일 때만 전역 선택에 참여한다. 정상 점수가 상수이면 T=0이며 자동 오류로 보지 않는다.

적격 후보 중 최저 변형 계열평균→전체 평균→후보 순서로 고른다. 새 후보는 MiniRocket와 기존 OAS 중 최선의 최저 변형 검출률보다0.02 이상 높고 전체 평균도 낮지 않을 때만 전체 평가에 진입한다. 그렇지 않으면 같은 규칙으로 anchor를 고르고 이미 검증된 결과를 재사용한다. 합성 검증은 실제 다른 클래스 이상과 다를 수 있으며, 작은fold로 FPR0.1%를 추정했다고 주장하지 않는다.

전체 평가에 진입하면1,117개·128개 계열을 유지한다. 원본1,119개 중 기존 제외2개를 동일하게 적용한다. 주지표는 관측FPR≤0.1% 계열평균TPR 상대10% 개선, FP0 비악화이다. 네오탐한도·세평균을 보고하며 점수·코드·입력해시를 저장한 뒤 TEST라벨을 읽는다. 이미노출된 개발TEST 결과는 새로운holdout 일반화보장이 아니다.

순위 및 기존 OAS는 float64 CPU가 기준이다. 전체 새로운 순위 fit+query stage에서 NumPy/Numba 시간을 변환·첫 컴파일 포함으로 비교하고 동일입력·seed에서 점수 rtol1e-10/atol1e-8, 전체순위·후보인덱스 일치를 확인한다. 공식QT는 다시 구현하지 않는다. PyTorch CPU/GPU·MLX·MPS도 평가하되 float64 미지원 GPU 때문에 정의를 바꾸지 않는다. CPU workers=논리CPU−1, 내부스레드1.
