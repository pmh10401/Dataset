Exp503 공간 피라미드 MiniRocket 뷰

이 문서는 실험 503의 고정 규칙이다. 시드와 재현 상수는 20260721이다. 전역 MiniRocket PPV는 구간 위치를 명시적으로 남기지 않으므로, 공식 MiniRocket만 사용해 사분 구간 연결 뷰를 시험한다. 사용자 정의 변환기 재작성은 금지한다. 이 프로토콜은 Exp502 전체 TEST 결과를 관측하기 전에 설계한다. 그리드를 넓히지 않는다.

1. 상태와 범위

  • 구현 위치는 experiments/exp503_spatial_pyramid_antigravity/만 해당한다.
  • 공식 통합과 시험 실행은 Codex가 담당한다. 이 문서를 쓰는 시점에는 파일럿·가속·전체 러너를 실행하지 않고 DB도 읽지 않는다. TRAIN 파일럿은 TEST 값과 TEST 라벨을 읽지 않는다.
  • 참고 원본(Exp449 표현, Exp495 기하, Exp502 헤드 패턴)은 읽기만 하고 수정하지 않는다.
  • TRAIN 파일럿은 적응형 개발 선별이다. 일반화 보장이 아니고, 노출된 개발 벤치마크이지 미공개 홀드아웃이 아니다.
  • 코드·후보·프로토콜 해시는 TEST 값을 읽기 전에 고정한다. 이후 전체 채점은 그 고정 뒤에 TEST 값을 읽고, 모든 점수와 메타를 고정한 뒤에만 TEST 라벨을 읽는다. TEST로 적합하지 않는다.

2. 목적과 가설

기존 전처리가 행 단위 전역 z-정규화를 이미 적용한 뒤, 공식 MiniRocket(n_kernels=4096)은 시계열 전체에서 PPV 4032개를 만든다. 이 표현은 커널 응답의 시간 평균 비율이라 앞·뒤 구간의 위치가 특징 칸에 남지 않는다. 가설은 같다. 같은 정규화 행을 네 구간으로 나누고, 구간마다 같은 MiniRocket을 적용한 뒤 고정 순서로 이어 붙이면, 국소 진폭·수준을 유지한 채 구간 위치가 4032개 추가 특징으로 드러난다. 이 뷰의 OAS 거리, 그리고 원시계열 4032와 이은 결합 뷰가, 같은 오경보 예산에서 MiniRocket LocalGap과 원시계열 OAS보다 가족 단위 재현율을 올리는지 측정한다.

3. 고정 입력

  • 입력 행은 기존 전처리의 전역 행 z-정규화를 이미 거친다. 실험 503이 다시 정규화하지 않는다.
  • 기준선은 기존 make_representation_antigravity('minirocket_local_gap', 20260721)이다. 실제 PPV 차원은 4032이다. 스케일은 RobustScaler 10–90, 점수는 기존 정확한 LocalGap이다.
  • 원시계열 OAS 대조는 기존 잔차 보존 OASGeometry와 평균 최근접 min(3, n) 유클리드 거리이다. 스케일은 LocalGap이 맞춘 바로 그 RobustScaler를 공유한다.
  • 적합에 쓰는 정상 행 식별자는 원 인코더와 구간 인코더가 동일하다. 데이터셋마다 후보를 고르지 않고, TEST로 맞추지 않으며, 특징 가중치를 쓰지 않는다.
  • n ≥ 2가 필요하다. 원천 참조 상한 1000과 그 시드 추출은 이후 공식 전체 러너가 담당한다. 헤드 자체는 받은 행 전부를 쓴다.
  • 행렬은 유한하고 비어 있지 않은 2차원이어야 한다. 질의 길이는 적합 입력 길이와 같아야 한다.

4. 후보와 고정 순서

이름특징스케일점수
MiniRocket원시계열 4032 PPVLocalGap RobustScaler 10–90정확한 LocalGap
oas_distance원시계열 4032 PPV위와 동일 스케일러 공유OAS 후 평균 3NN 유클리드
pyramid_distance사분 연결 4032 PPV해당 특징만의 RobustScaler 10–90같은 OAS, 같은 3NN 평균
pyramid_joint원 4032 + 사분 4032결합 특징만의 RobustScaler 10–90같은 OAS, 같은 3NN 평균

순서 MiniRocket, oas_distance, pyramid_distance, pyramid_joint는 동점 처리에 쓰이며 바꾸지 않는다. 헤드 API는 SpatialHeads(rows)와 score(rows) → dict 네 이름이다. 진단 메타데이터는 폴백 여부, quarterlength, quarterfeaturedim을 포함한다.

5. 사분 구간 구성

  1. 각 원 행을 np.array_split(row, 4)로 나눈다. 길이가 4로 나누어떨어지지 않으면 앞쪽 구간에 나머지 표본이 한 개씩 더 붙는다. 이 규칙은 NumPy 기본이며 고정한다.
  2. 공통 구간 길이는 Lq = max(9, L // 4)이다. MiniRocket 어댑터의 최소 길이 9를 맞추기 위함이다. 길이 1부터 8인 짧은 구간도 이 길이로 올린다.
  3. 구간마다 독립적으로 np.interp한다. 원 격자 linspace(0, 1, 구간길이), 목표 격자 linspace(0, 1, Lq)이다. 끝점은 길이 2 이상에서 보존되고, 상수 구간은 길이 1을 포함해 상수로 남는다. 어댑터의 0 패딩은 상수 구간에 0을 섞으므로 쓰지 않는다.
  4. 구간을 행 안에서 독립적으로 중심화하거나 척도화하지 않는다. 전역 z 이후의 국소 진폭과 수준이 증거이다.
  5. 네 구간을 표본 우선으로 편다. 한 행의 구간 0·1·2·3이 연속하고, 그다음 행이 이어진다. 인코딩 뒤에는 (n, 4 × 1008)로 다시 맞추며 구간 순서를 유지한다.

선형 보간 식은 다음과 같다. 목표 시각 t_j = j / (Lq − 1), 원 시각 s_k = k / (S − 1) (구간 길이 S ≥ 2). np.interp는 구간별 선형 연결이며, 왼쪽 채움은 첫 값, 오른쪽 채움은 마지막 값이다. S = 1이면 원 격자가 [0]뿐이므로 모든 목표 점이 그 상수로 채워진다. S = Lq이면 항등 사상이다.

6. 공유 구간 인코더

  • 구간 인코더는 하나뿐이다. 적합 정상 행의 네 구간을 모두 쌓은 행렬에만 맞춘다. 질의 행·접힌 행·TEST 행은 이 적합에 들어가지 않는다.
  • 구성은 공식 aeon MiniRocket(n_kernels=1024, n_jobs=1, random_state=20260721)를 기존 _SingleRepresentationAntigravity 어댑터에 넣은 것이다. 커널 1024는 그룹 84를 기준으로 구간당 1008 특징을 만든다. 네 구간 연결은 4032로, 원시계열 PPV 차원과 같다. 적합과 질의 변환은 형상 (4n, 1008)을 요구하며 특징 수 폴백은 없다.
  • 원 인코더는 따로 맞춘다. 기존 minirocket_local_gap 경로를 그대로 쓴다.
  • 커널은 길이와 시드에 의존하고, PPV 임계값은 적합 데이터에 의존한다. 공유 적합은 네 위치의 구간을 한 분포로 모아 임계값을 정한다. 위치 정보는 네 블록의 칸 순서로만 남는다. 위치마다 인코더를 따로 맞추면 임계값이 위치를 흡수하므로 이 실험의 뷰가 아니다.
  • 고정 aeon에서 n_kernels=1024가 1008 특징을 반환하지 않으면 차단 조건이다. 커널 수나 피라미드 단수를 임의로 바꾸지 않는다.

7. OAS 거리 헤드

각 OAS 후보는 자기 스케일(원 대조만 기준선 스케일러 공유) 뒤에 같은 잔차 보존 OASGeometry를 맞춘다. 잘린 PCA 거리로 직교 잔차를 지우지 않는다. 질의 점수는 변환된 정상 참조에 대한 유클리드 거리 행렬에서 행마다 가장 가까운 min(3, n)개의 평균이다. LocalGap은 MiniRocket 기준선에만 쓴다.

결합 후보는 원 4032와 사분 4032를 열 방향으로 이어 8064 특징을 만든 뒤, 그 결합 공간에서 하나의 RobustScaler와 하나의 OAS를 맞춘다. 특징 가중치는 없다.

8. 길이와 폴백

  • 원 길이 L < 4이면 array_split이 빈 구간을 만든다. 빈 구간은 금지한다. 새 후보 점수는 원 OAS 앵커와 수치적으로 같고, 진단에 폴백을 기록한다. 다른 폴백은 없다.
  • 길이 4 이상이면 가장 짧은 구간 길이는 적어도 1이다. 길이 1–8 구간은 Lq ≥ 9로 보간하며 상수를 보존한다.
  • 질의 길이가 적합 길이와 다르면 오류이다. 길이가 바뀌면 분할과 Lq가 바뀌므로 맞춘 인코더를 쓸 수 없다.

폴백에서 새 후보가 원 OAS와 같으면 프록시 재현율도 같다. 최소 이득 0.02 규칙 때문에 새 후보는 앵커를 대체하지 못한다. 이는 의도된 동작이다.

9. 적합과 질의 격리

  • 인코더, 스케일러, OAS, 정상 참조는 생성자에서만 적합한다. score는 변환만 한다.
  • 5겹 파일럿에서 각 겹의 구간 스택은 적합 인덱스 행만 담는다. 홀드 정상 행이 구간 인코더 적합에 들어가면 안 된다.
  • 배치를 나누어 질의해도 같은 행의 점수는 같아야 하고, 저장된 참조 행렬은 바뀌지 않아야 한다.

10. TRAIN 파일럿 선별

  • 모집단은 Exp495 진단 매니페스트의 메타데이터로 고른 50가족, 가족당 한 데이터셋이다.
  • 기존 5겹 교차 적합 계획을 쓰고, 시드는 공통 SEED이다. 각 겹은 적합 행으로만 헤드를 만들고 홀드 정상으로만 임계값을 잡는다.
  • 임계값은 후보마다 홀드 정상 점수의 최댓값이다. 엄격한 경험 오경보 0이다.
  • 네 가지 TRAIN 손상은 기존 Exp495 perturbations와 KINDS이다. 손상 시드는 SEED + 1709 × (겹번호)이다.
  • 가족 평균은 먼저 겹 평균, 그다음 가족 평균이다. 전체 요약은 50가족의 평균이다.
  • 정상 꼬리는 홀드 정상 점수에서 (max − median) / (q75 − q25 + 1e-9)이고, 겹 평균 뒤 가족 중앙값을 쓴다. 새 후보의 이 중앙값은 MiniRocket 값의 3배를 넘으면 부적격이다.
  • 적격 집합은 두 앵커와, 꼬리 조건을 통과한 새 후보다.
  • 선택 키는 손상별 평균 재현율의 최솟값, 그다음 그 평균, 그다음 고정 후보 순서이다. 코드는 -names.index를 max와 쓰므로 더 이른 후보가 동점을 가져간다. 두 앵커 중 이 키의 최댓값이 best_anchor이다.
  • 무제한 승자가 앵커가 아니면, 최솟값이 앵커 최솟값보다 0.02 이상 커야 하고 전체 평균은 줄지 않아야 한다. 둘 중 하나라도 실패하면 앵커를 고른다.
  • 같은 DB, 원천 바인딩, 코드맵 codemap_exp503_antigravity.json, 이 프로토콜 해시가 매니페스트에 묶인다. 완료된 파일럿 결과는 덮어쓰지 않는다.

11. 전체 목표

공식 전체 러너는 지금 요청하지 않는다. 나중에 돌릴 때의 고정 목표는 다음과 같다.

  • 같은 1117 데이터셋, 128 가족.
  • 일차 목표는 가족 매크로 경험 오경보율 0.1% 이하에서 MiniRocket 대비 상대 TPR 10% 이상 개선이고, 오경보 0 예산 비회귀이다.
  • 나머지 오경보 예산과 세 가지 가중은 모두 보고한다. 그 전부가 개선될 필요는 없다.
  • 이후 전체 채점은 코드와 후보를 고정한 뒤에 TEST 값을 읽고, 모든 점수와 메타를 고정한 뒤에만 TEST 라벨을 읽는다. TEST로 적합하지 않는다.

파일럿 승격은 이 목표의 대용이 아니다. TEST로 후보를 다시 고르지 않는다. TRAIN 파일럿은 TEST 값과 TEST 라벨을 읽지 않는다.

12. 가속 정책

  • 공식 MiniRocket은 이미 Numba이다. 텐서나 커스텀 커널로 바꾸지 않는다.
  • 시간 측정 단계는 헤드 적합과 질의 전체이다. 교체하는 구성 요소만 구간 재표본 헬퍼이다. NumPy(기본)·Numba·Torch CPU를 같은 격자로 비교한다. 합성 적합 64×128, 질의 1024×128, 시드 503. 콜드·웜과 변환 오차를 기록한다. 길이 128은 구간 32를 32로 보내므로 보간이 항등에 가깝다.
  • 모든 점수가 유한하고 rtol=1e-10, atol=1e-8로 가까우며, 안정 정렬 순위와 정상 1000·예산 0/1/5/10의 후보 인덱스가 같아야 한다. 실제 보간은 길이 11과 131에서 적합 8행·질의 1024행·앞 1000 의사 정상으로 같은 검사를 보충 기록한다.
  • 벤치마크 안에서만 구간 헬퍼를 교체하고 try/finally로 되돌린다.
  • 패리티와 속도 증거가 없으면 가속 생산 경로를 고르지 않는다. 길이 11과 131의 보간 패리티가 실패해도 가속기를 고르지 않고 정규 NumPy를 유지한다. 기본은 NumPy 재표본이다.
  • MLX/MPS float64 GPU는 이전 조사에서 쓸 수 없었다. Exp495 가속 JSON의 경로 해시를 상속 프로브로 기록한다. 이 단계에서 가속 스크립트를 실행하지 않는다.
  • 정확성이 가속 새로움보다 앞선다.

13. 수학 검토

구현 전에 확인한 내용이다. 그리드를 넓혀야 하는 차단 조건은 없다. 다만 고정 aeon이 구간 인코더에서 1008 특징을 내지 않으면 커널 수를 임의로 바꾸지 말고 중단한다.

  1. 전역 z만 유지하고 구간 z를 하지 않는 이유: 구간 평균을 빼면 국소 수준이 사라지고, 구간 분산으로 나누면 국소 진폭이 사라진다. 둘 다 이 실험이 보려는 증거이다.
  2. 공유 임계값: MiniRocket 커널은 시드와 길이에 의존하지만 편향은 적합 응답의 분위수이다. 네 위치를 모아 맞추면 같은 특징 칸이 같은 임계값을 쓰고, 위치 차이는 연결 순서에만 남는다.
  3. 차원 맞춤: 원 4096 커널 → 4032 PPV, 구간 1024 커널 → 1008 PPV, 네 블록 → 4032. 피라미드 거리 공간의 차원이 원 OAS와 같아 스케일 비교가 직접적이다. 결합은 8064이다.
  4. 보간: 길이 1 상수를 9칸으로 복제하는 것은 0 패딩과 달리 값을 보존한다. 길이가 다른 구간을 같은 Lq로 보내는 유일한 조각별 선형 끝점 고정 사상은 np.interp와 같다.
  5. OAS 잔차: 표본이 특징보다 훨씬 적을 때 잘린 고유공간만 쓰면 직교 잔차가 사라진다. 기존 OASGeometry는 그 잔차를 남기므로 그대로 쓴다.
  6. 피라미드 단을 2·8로 늘리거나 구간별 인코더를 두는 확장은 이 프로토콜 밖이다.

14. 금지

  • TRAIN 파일럿에서 TEST 값 또는 TEST 라벨을 읽는 일, TEST로 적합하는 일, 데이터셋마다 후보를 고르는 일. TEST 적합은 언제나 금지이다. 이후 전체 채점이 TEST 값을 읽는 것은 코드·후보 고정 뒤에만 허용하고, TEST 라벨은 모든 점수와 메타를 고정한 뒤에만 허용한다.
  • 공식 MiniRocket을 재작성하거나, 새 패키지를 설치하거나, 특징 가중치를 넣는 일.
  • 구간 독립 중심화·척도화, 빈 구간, 길이 불일치 질의를 조용히 통과시키는 일.
  • 파일럿 결과를 덮어쓰거나, 완료 전에 개선을 주장하거나, 가속 미실행 상태에서 생산 경로를 바꾸는 일.
  • 이 프로토콜에 없는 후보·단수·커널 수를 추가하는 일.
