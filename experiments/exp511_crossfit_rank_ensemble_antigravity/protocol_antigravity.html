Exp511: A/B 역할 분리를 유지한 네 모델 평균

2026-09-18 사용자가 승인한 후보 하나를 검증한다. 가중 앙상블을 기존 Exp502, 단일 분할 Exp510, 같은 네 분할의 비가중 앙상블과 비교한다. 과거 실험의 코드·결과·프로토콜·코드맵은 보존한다.

1. 모집단과 역할

Exp510과 동일한 정상 TRAIN 50계열·50데이터셋, SEED=20260721의 외부 5분할 F/C를 사용한다. 전체 정상 TRAIN에서 정한 기존 목표 길이와 행별 z 정규화를 그대로 상속한다. 이 전처리에는 C도 포함되어 있으므로 전체 전처리를 A 전용이라고 주장하지 않는다. C의 점수·변형은 적합과 가중치 학습에 사용하지 않는다.

n=|F| ≥ 32: order=default_rng(SEED+2510).permutation(n)
경계 = [0, floor(n/4), floor(2n/4), floor(3n/4), n]
B_j = sort(order[경계_j:경계_(j+1)]), j=0,1,2,3
A_j = sorted(F 내부 전체 인덱스에서 B_j를 제외한 인덱스)

각 행은 B에 한 번, A에 세 번 참여한다. 첫 모델의 A/B는 Exp510과 정확히 같으며 해당 모델을 재사용한다. 겹치는 A를 쓰므로 네 모델이 통계적으로 독립이라고 주장하지 않는다. 동일 파형을 가진 서로 다른 행의 중복 제거는 하지 않는다. n<32이면 두 앙상블 점수는 기존 square_joint를 정확히 복사하고 새 학습을 수행하지 않는다.

2. 고정된 구성 모델

각 모델은 자기 A에서만 기존 Exp502 원시·중심화 제곱 MiniRocket 표현, RobustScaler 10–90, 잔차 보존 OAS와 참조를 적합한다. 가중치는 자기 B에서만 학습한다. B가 128개를 넘으면 Exp510의 SEED+1510으로 정렬된 128개 부모를 고른다. 기존 4종 학습 변형과 SEED+1508을 그대로 사용한다. 적합 후 A+B로 다시 맞추지 않는다.

d_k=OAS 공간의 유클리드 길이(제곱거리 아님)
G_j(q)=mean_k((q_j-r_kj)^2/d_k), d_k=0이면 기여 0
이웃 k=min(3,|A|): 비가중 거리 기준으로 고정 선택
scale=median_A(mean 자기 제외 min(3,|A|-1) 거리)+1e-9
u(q)=sum(G(q))/scale, v(q)=G(q)·w/scale
crossfit_unweighted(q)=mean(u_0(q),u_1(q),u_2(q),u_3(q))
crossfit_rank(q)=mean(v_0(q),v_1(q),v_2(q),v_3(q))

점수 정규화는 각 A의 기존 비가중 자기 제외 척도뿐이다. B나 C의 분위수, TEST, 적응형 가중치 또는 점수 순위 변환으로 재정규화하지 않는다. 가중·비가중 앙상블은 같은 네 표현·참조·척도를 공유한다.

Exp509 solve의 목적함수·L-BFGS-B 설정·범위를 그대로 재사용한다. w 초기값1, 범위[0.25,4], regularization=temperature=0.1, margin=0.25, maxiter=2000, maxfun=5000, maxls=40, maxcor=20, gtol=1e-8, ftol=1e-15. 유한한 최종 반복값을 사용하며 수렴 상태·기울기·손실·오차 상한을 기록한다. 재시작·설정 탐색·수렴 기반 모델 교체는 없다.

3. 대조군과 검증

순서: MiniRocket, oas_distance, square_joint, a_unweighted, separated_rank, crossfit_unweighted, crossfit_rank. 앞의 다섯 점수는 동결 Exp510의 분할별 저장 점수·안정 순위·검출 대상을 재현한다. 검증 변형의 부모는 C이며 기존 4종은 SEED+1709×(fold+1), 학습 제외 weak_level/weak_scale/sparse_spike/time_warp는 SEED+2508+1709×(fold+1)를 사용한다.

검출은 해당 점수가 보류 정상 C의 최댓값을 엄격히 초과할 때다. 검출률은 분할 평균 후 계열 동일 가중 평균, 정상 꼬리는 (max−median)/(q75−q25+1e-9)를 분할 평균한 뒤 계열 중앙값이다. 분위수는 NumPy 기본 linear 방법이다.

4. 네 가지 필수 승격 조건

① 기존 4종 중 최저 계열 평균 검출률이 여섯 대조군의 해당 최저값 중 최댓값보다 0.02 이상 높다. ② 기존 4종 평균이 여섯 대조군 평균의 최댓값 이상이다. ③ 학습 제외 4종 평균도 여섯 대조군 평균의 최댓값 이상이다. ④ 정상 꼬리가 3×max(MiniRocket 꼬리,1e-9) 이하이다. 0.02 개선값을 1에 맞춰 완화하지 않는다. 모두 통과해야 전체 평가로 진행한다. 실패하면 square_joint를 유지하고 Exp511을 종료한다.

5. 조건부 전체 평가

검산된 TRAIN 통과 이후에만 동일 1,117데이터셋·128계열의 기존 전처리·제외 규칙·TEST 인덱스를 사용한다. 정상 참조 상한1000과 SEED+7919+4096의 선택을 먼저 적용한 뒤 네 역할 분할을 한다. 코드·규칙을 TEST 점수 생성 전에, 전체 점수·메타데이터 해시를 TEST 라벨 조회 전에 고정한다. 기존 MiniRocket·Exp502 점수를 재현한다. FP0, FPR≤0.001/0.005/0.01, 계열 평균·데이터셋 평균·이상 표본 수 가중 평균과 계열 paired bootstrap 2000회(SEED)를 보고한다. 주목표는 FPR≤0.001 계열 검출률≥0.6004757235442457 및 MiniRocket 대비 FP0 비악화다.

전체 평가는 점수 동결 후 TEST 라벨로 계산하는 회고적 ROC 한계 성능이다. 학습 정상으로 보장한 운영 문턱이나 미사용 holdout 결과가 아니다. TRAIN 합성 결과에서 실제 TEST 개선을 추정하지 않는다.

6. 검증과 가속

역할 중복·누락, 첫 모델의 Exp510 동등성, B 변경 시 해당 A 적합 불변, 네 점수의 산술 평균, 배치·순서 불변, 작은 표본·상수 입력·부모 상한·여섯 대조군 기준을 검사한다. 각 모델의 가중치·기울기·학습 점수, C와 변형의 구성 점수·앙상블 점수를 로컬에 보존한다. 독립 검산에서 분할·손실·제약 반영 기울기 조건·산술 평균·대조 재현·집계·결정을 재계산한다. 원본 기여 행렬부터 기울기·표현 전체를 다시 만드는 검증은 아니다.

가속은 공식 MiniRocket/SciPy를 보존하며 합성 fit64×128/query1024×128, seed511로 전체 적합·추론의 NumPy/Numba/Torch CPU를 최초·준비 후 비교한다. 허용오차 rtol1e-10/atol1e-8, 안정 순위와 정상1000개에 대한 예산0/1/5/10 후보가 같고 전체 단계 1.1배 이상일 때만 가속 후보를 검토한다. MLX/MPS float64 지원은 실제 연산으로 확인한다. 미충족 시 NumPy/SciPy를 유지한다. CPU 병렬은 논리CPU−1, 내부 스레드1이다. 합성 자료와 코드만 외부 독립 검토에 전달한다.
