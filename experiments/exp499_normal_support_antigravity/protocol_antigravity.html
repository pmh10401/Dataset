OAS 공간의 정상 지지집합

Grok과 비교한 비선형 정상 분포 가설을 순위 정규화 이후의 독립 실험으로 검토한다. 낮은 유효 rank만으로 비선형 구조가 없다고 결론 낼 수는 없다. 기존 가까운3점 평균 거리가 드문 정상 모드를 불리하게 평가할 수 있다는 가설을, 가장 가까운1점과 RBF OneClassSVM으로 비교한다. 추가 데이터·TEST 학습·이상 TRAIN 라벨은 사용하지 않는다.

MiniRocket, RobustScaler10–90, 기존 잔차보존 OAS, TRAIN 참조 cap1000과seed를 유지한다. OAS 공간의 정상 참조 간 제곱거리행렬 D를 구하고 대각선을 제외한 양수 거리(1e-12 초과)의 중앙값 m을 사용한다. alpha(gamma factor)는.25 또는4, gamma=alpha/m이다. sklearn OneClassSVM(kernel=precomputed,nu=.01 또는.1,tol=1e-5,max_iter=100000,cache_size=128)으로 exp(−gamma*D)를 학습한다. fit_status_가0이 아니거나 양수 dual weight 검증이 실패하면 오류로 중단한다. nu를 실제 오탐률로 해석하지 않는다.

query 점수는 max(0,−logsumexp(log(normalized dual weight)−gamma*d²))이다. 가중치는 양수이며 합1로 정규화한다. 로그 공간에서 직접 계산해 먼 표본의 RBF가0으로 내려가 서로 같은 점수가 되는 수치 문제를 피한다. 일반 범위에서는 공식 score_samples의 단조 변환과 같고, 새로운 kernel 지지모델의 순위를 보존한다. MiniRocket 점수 자체를 단조 변환하는 실험이 아니다.

후보 순서는 MiniRocket, oas_distance(3NN), oas_nearest(1NN), kernel_g025_n001, kernel_g025_n010, kernel_g4_n001, kernel_g4_n010이다. n<16 또는 TRAIN 양수 거리 쌍이 없으면 kernel 후보들은 oas_distance를 사용한다. 1NN은 n≥2 전체에서 정의한다. fallback은 TRAIN 조건만으로 결정하며 비유한 query 때문에 모델을 바꾸지 않는다.

Exp498과 같은50개 계열·5-fold·네 변형·held-normal 최대 점수 기준과 양수 IQR 정상 tail 진단을 유지한다. 모든 학습은 fit 정상으로만 한다. 새 후보의 tail 진단 계열 중앙값은 MiniRocket의3배 이하여야 한다. 적격 후보 중 최저 변형 평균→전체 평균→후보 순서로 고른다. 최선 anchor(MiniRocket 또는 OAS3NN)보다 최저 검출률0.02 이상 개선되고 전체평균이 낮지 않아야 전체 평가로 진입한다. 아니면 anchor 결과를 재사용한다.

전체 평가의 모집단은1,117개·128개 계열이다. 주지표는 관측FPR≤0.1% 계열평균TPR 상대10% 개선이며 FP0 비악화를 요구한다. 점수·해시 고정 후 TEST라벨을 읽고 네오탐한도·세평균을 보고한다. 노출된 개발TEST이므로 새holdout 또는 운영오탐보장이 아니다.

공식libsvm CPU를 다시 작성하지 않는다. float64 거리·kernel·logsumexp·전체fit/score 단계의Numba/PyTorch CPU 시간과 수치·순위·후보인덱스 parity를 평가한다. MLX/MPS float64 지원 실패 기록을 이어받는다. CPU workers=논리CPU−1, 내부1스레드다.

근거: 공식 OneClassSVM 문서, 공식 logsumexp 문서. 실제 설치 버전에서 score_samples와 log-domain 식을 합성 표본으로 확인했고 최대 차이는1.34e-15였다. 이 확인은 실제 검출률 증거가 아니다.
