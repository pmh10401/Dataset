# AI-Driven Equipment Intelligence: 다중 이상 증거와 안정성 선별을 이용한 설비 이상 탐지

## 초록

반도체 설비의 이상 탐지는 정상 운전 데이터만 충분하고 고장 라벨은 희소한
환경에서 수행되는 경우가 많다. 본 연구는 정상 TRAIN 시계열만으로 다중 이상
증거를 산출하고, 저주파 후보와 TRAIN 생략 재학습 기반 안정성 선별을 결합하는
AI-Driven Equipment Intelligence 이상 탐지 기술을 제안한다. 이 방법은 고정된
경보 경로를 유지하면서 각 TEST 샘플에 연속 이상 점수를 부여하여 임계값 기반
성능과 순위 기반 AP/AUROC를 함께 평가할 수 있다. 1,117개 공개 단변량 시계열
데이터셋, 195,900개 TEST 샘플에서 여섯 공개 one-class 기준선과 후향적으로
비교하였다. 제안기술은 2,276개 경보에서 Micro F1 0.6306, Macro F1 0.6229,
AP 0.6741, AUROC 0.9611을 기록하였다. 동일 경보 예산에서 가장 높은 기준선인
RBF One-Class SVM 대비 Micro F1은 0.1221, Macro F1은 0.1581 높았다. 일곱
방법이 모두 완주한 922개 데이터셋의 공통지원에서도 제안기술은 AP 0.6697,
AUROC 0.9642를 기록하였다. 데이터셋 단위 paired bootstrap에서 모든 기준선의
Macro F1 차이(기준선−제안기술) 95% 구간은 0보다 작았다. 다만 본 평가는 공개
벤치마크에 대한 후향적 연구이며 실제 반도체 설비 고장 확률이나 현장 운영
효과를 입증하지 않는다.

**주요어:** 설비 이상 탐지, one-class learning, 시계열, 연속 이상 점수,
안정성 선별, 예지보전

## 1. 서론

설비 이상은 발생 빈도가 낮고 형태가 다양하며, 정상 상태의 운전 데이터에 비해
고장 라벨이 제한적이다. 이 때문에 지도학습 분류기를 직접 적용하면 고장 유형의
불완전한 표본, 데이터 불균형, 설비별 운전 조건 차이의 영향을 크게 받는다.
실제 적용을 고려한 이상 탐지기는 정상 데이터만으로 학습할 수 있어야 하고,
경보 수를 통제하면서도 경보 내부의 우선순위를 제공해야 한다.

공개 연구에서는 최근접 이웃 거리[1], LOF[2], One-Class SVM[3], Isolation
Forest[4], Deep SVDD[5], DROCC[6]와 같은 대표적인 one-class 방법이 제안되었다.
각 방법은 서로 다른 이상 가정을 사용하므로 단일 모델의 점수만으로 다양한
시계열 이상을 포착하기 어렵다. 또한 이진 경보만 제시하면 임계값 이후의 상대적
위험 순위를 AP와 AUROC로 평가하기 어렵다.

본 연구의 기여는 다음과 같다.

1. 다섯 개의 hard-evidence 원천을 결합하고 동결된 경보 경로를 보존하는
   연속 이상 점수를 정의하였다.
2. 저주파 분해 기반 후보를 데이터셋당 하나, 전체 최대 30개로 제한하고,
   TRAIN 일부를 생략한 재학습에서 반복 생존하는 후보만 최종 경보에 추가하였다.
3. TEST 라벨을 점수 동결 이후에만 읽는 평가 경계를 적용하고, 1,117개 공개
   데이터셋에서 여섯 공개 기준선과 동일 경보 예산·conformal·연속 점수 기준으로
   비교하였다.

## 2. 관련 연구

kNN 거리 기반 이상 탐지는 TEST 샘플과 정상 TRAIN 이웃 간 거리를 직접 이상
점수로 사용한다[1]. LOF는 국소 밀도 차이를 사용해 주변보다 희박한 샘플을
탐지한다[2]. One-Class SVM은 정상 표본을 포함하는 경계를 추정하고[3],
Isolation Forest는 무작위 분할에서 적은 깊이로 고립되는 샘플을 이상으로 본다[4].
Deep SVDD는 신경망 임베딩을 정상 중심에 모으는 목적함수를 사용하며[5], DROCC는
정상 표본 주변의 합성 adversarial 음성 영역을 이용해 강건한 경계를 학습한다[6].

본 연구는 이 방법들을 대체 구현으로 간주하지 않고 고정된 공개 비교군으로
사용한다. 제안기술은 여러 증거의 합의, 제한된 후보 확장, 재학습 안정성을 하나의
경보 경로로 결합한다는 점에서 단일 점수원 기반 비교군과 구별된다.

## 3. 제안 방법

### 3.1 데이터 경계와 전처리

각 데이터셋에서 정상 TRAIN만 학습과 calibration에 사용한다. TEST에서는 시계열
값과 연속 인덱스만 점수 산출에 사용하며 라벨은 점수·manifest가 동결된 이후
평가 단계에서 처음 읽는다. 전처리 길이는 TRAIN 길이 중앙값만으로 정하고
`[8, 2048]`로 제한한다. 비유한 값은 행 내부에서 복구하고 각 행을 독립적으로
정규화한다.

### 3.2 다중 hard evidence

다섯 개의 사전 고정 점수원에 대해 정상 TRAIN-OOF upper-tail p-value를 구한다.
점수원 `j`의 이상 강도를 `u_j = 1 - p_j`로 두고, 다섯 값 중 두 번째로 큰 값을
hard evidence 강도 `u_H`로 사용한다. 이는 최소 두 개 증거가 강해야 큰 값이 되는
2-of-5 연속 대응이다. 별도의 동결된 route 재현 규칙이 자동 hard 경보 집합을
결정한다.

### 3.3 저주파 후보 확장

FFT 기반 다중 depth 분해에서 저주파 채널의 정상 TRAIN 거리 분포를 OOF 방식으로
보정한다. 두 개 이상의 인접 depth에서 통과한 샘플만 후보가 될 수 있다. 이미
hard 경보가 있는 데이터셋은 후보 확장에서 제외하고, 나머지 데이터셋에서 로컬
후보 하나만 유지한 뒤 전 모집단에서 강한 최대 30개를 선택한다. 저주파 연속
강도 `u_L`은 유효 depth들의 두 번째로 강한 upper-tail 증거다.

### 3.4 TRAIN 생략 안정성 선별

선택된 후보마다 정상 TRAIN의 10%를 결정론적으로 생략하는 최대 16개 view를
만들고 동일한 저주파 판단을 재학습한다. `V`개 view 중 최소
`ceil(7V/8)`개에서 후보가 생존하면 stable, 그렇지 않으면 unstable로 분류한다.
최종 제안 구성은 자동 hard 경보와 stable 후보를 합친다.

### 3.5 경보 보존 연속 점수

사용 가능한 hard와 저주파 강도의 최댓값을 `u = max(u_H, u_L)`로 둔다. 두
증거가 모두 없으면 중립값을 사용한다. 최종 이진 경보 마스크 `a`를 변경하지
않도록 연속 점수 `s`를 다음처럼 정의한다.

```text
s = 0.5 + 0.5u,  if a = 1
s = 0.5u,        if a = 0
```

따라서 `s >= 0.5`는 동결된 이진 경보와 정확히 같다. 이 점수는 샘플의 순위를
비교하기 위한 composite anomaly score이며 보정된 고장 확률이 아니다.

## 4. 실험 설계

### 4.1 모집단과 비교군

평가 모집단은 1,117개 공개 단변량 시계열 데이터셋과 195,900개 TEST 샘플이다.
비교군은 kNN distance, LOF novelty, RBF One-Class SVM, Isolation Forest,
Deep SVDD 1D, DROCC 1D의 여섯 방법이다. Deep SVDD와 DROCC는 시계열 입력을
위해 동일한 사전등록 1D encoder를 사용한다. 실행 조건을 만족하지 못한 방법은
다른 검출기로 대체하지 않고 abstain으로 기록한다.

### 4.2 평가 프로토콜

첫째, 제안기술의 데이터셋별 경보 수와 동일한 상위 `k`개 기준선 점수를 선택하는
matched-alert-budget을 주 비교로 사용한다. 둘째, 기준선 TRAIN-OOF 점수로
`alpha ∈ {0.005, 0.01, 0.02}` upper-tail conformal 경보를 계산한다. 셋째,
연속 점수의 AP와 AUROC를 전체 이용 가능 모집단과 모든 7개 방법이 완주한
공통지원 922개 데이터셋에서 보고한다.

Micro 지표는 모든 TEST 샘플의 confusion count를 합산한다. Macro 지표는
데이터셋별 지표를 동일 가중 평균한다. 불확실성은 1,117개 데이터셋을 동일
인덱스로 2,000회 재표집한 paired bootstrap으로 평가한다.

## 5. 결과

### 5.1 동일 경보 예산 비교

제안기술은 2,276개 경보에서 precision 0.8581, recall 0.4985, Micro F1
0.6306, Macro F1 0.6229를 기록하였다. 동일 경보 예산 기준선 중 가장 높은
Micro 및 Macro F1은 RBF One-Class SVM의 0.5086과 0.4649였다. 따라서
제안기술의 절대 이득은 각각 0.1221과 0.1581이다. 나머지 네 전통/심층 기준선과
비교해도 제안기술의 Micro 및 Macro F1이 높았다.

### 5.2 연속 점수 비교

전체 이용 가능 점수에서 제안기술 AP는 0.6741, AUROC는 0.9611이었다. 모든
방법이 완주한 공통 922개 데이터셋, 186,150개 TEST 샘플에서도 제안기술 AP는
0.6697, AUROC는 0.9642였다. 공통지원에서 가장 높은 기준선은 kNN distance로
AP 0.4872, AUROC 0.9142였다. ROC와 Precision–Recall 곡선은 동일한 922개
데이터셋과 동일 TEST 행에서 계산하였다.

### 5.3 통계 및 ablation

matched-alert-budget Macro F1의 `기준선−제안기술` paired bootstrap 95%
구간은 여섯 기준선 모두 0보다 작았다. 가장 가까운 RBF One-Class SVM의 차이는
−0.1581이고 95% 구간은 [−0.1827, −0.1343]이다. Ablation에서 hard-only의
Micro F1은 0.6284였고, 안정성 선별을 포함한 최종 구성은 0.6306이었다. 후보를
무조건 모두 추가한 구성보다 false positive가 4개 적었으며 true positive는
같았다.

## 6. 논의

결과는 서로 다른 이상 증거의 합의와 제한적 후보 확장이 단일 one-class
기준선보다 높은 경보 품질을 제공할 수 있음을 시사한다. 경보 보존 연속 점수는
기존 운영 경보 결정을 바꾸지 않으면서 AP/AUROC와 우선순위 분석을 가능하게
한다. 또한 공통지원 결과를 별도로 제시함으로써 심층 방법의 abstention으로 인한
지원 차이를 통제하였다.

그러나 이 결과를 실제 반도체 설비의 고장 예지 성능으로 직접 해석해서는 안
된다. 공개 데이터셋은 실제 설비의 유지보수 비용, 센서 drift, 공정 recipe 변화,
다변량 상호작용을 충분히 반영하지 않는다. 제안 점수 역시 고장 발생 확률로
보정되지 않았다. DROCC의 MPS 동등성은 사용자 확인에 근거하며 기계 판독 가능한
독립 parity 산출물이 없다.

## 7. 결론

본 연구는 정상 TRAIN만으로 다중 hard evidence, 저주파 후보, TRAIN 생략
안정성을 결합하고 동결된 경보를 보존하는 연속 이상 점수를 제안하였다. 대규모
공개 후향 비교에서 제안기술은 여섯 공개 기준선보다 높은 F1, AP, AUROC를
보였다. 다음 단계는 실제 설비의 시간 순서가 보존된 전향 검증, 비용 기반 임계값
선정, 점수 확률 보정, 다변량 센서 및 정비 이력 결합이다.
