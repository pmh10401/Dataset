# 데이터 공개 범위와 연구 한계

## 공개한 자료

- 전체 방법·프로토콜 공식 요약 JSON/CSV
- 데이터셋 단위 집계 지표 26,808행
- paired bootstrap 원본 결과
- 공통지원 ROC/Precision–Recall exact 좌표와 표시용 좌표
- 논문용 표 6개와 SVG 그림 5개
- 공식 HTML 보고서
- 사전등록·설계·구현 근거 스냅샷

## 공개하지 않은 자료

- 원시 SQLite DB
- 개별 TRAIN/TEST 시계열 값
- 개별 TEST 정답 라벨
- 대용량 학습 checkpoint와 중간 score shard
- 사내 반도체 설비 데이터

원시 데이터의 재배포 권리와 대용량 저장 문제를 별도로 검토해야 하므로 이
GitHub 패키지는 파생 집계 자료만 제공한다. 데이터셋별 지표 파일은 결과 감사를
위한 것이며 원시 시계열을 복원할 수 있는 값을 포함하지 않는다.

## 핵심 한계

1. **후향 평가:** 방법과 경로는 라벨 접근 전 동결했지만, 결과 자체는 공개
   벤치마크의 사후 평가다.
2. **도메인 차이:** 공개 단변량 시계열은 실제 반도체 설비의 다변량 센서,
   recipe 변화, 정비 이력과 비용 구조를 완전히 대변하지 않는다.
3. **확률 미보정:** 제안 연속 점수는 ranking score이며 고장 확률이 아니다.
4. **지원 차이:** Deep SVDD와 DROCC는 922/1,117개 데이터셋만 완주했다.
5. **가속 근거:** DROCC MPS 결과의 동등성은 사용자 확인이며 독립된 기계 판독
   parity 산출물이 없다.
6. **현장 지표 부재:** lead time, false alarm 처리비, downtime, 유지보수 절감액은
   평가하지 않았다.
7. **단변량 범위:** 센서 간 상호작용과 원인 위치 식별을 직접 다루지 않는다.

## 후속 연구 체크리스트

- [ ] 시간 순서를 보존한 실제 설비 전향 검증
- [ ] 설비·chamber·recipe 단위 domain shift 분석
- [ ] 경보 lead time과 유지보수 비용 기반 효용 평가
- [ ] 연속 점수의 확률 보정 및 calibration curve
- [ ] 다변량 센서 융합과 원인 기여도 분석
- [ ] 독립 MPS/CPU parity 산출물 보관
- [ ] 외부 재현용 원시 데이터 접근 절차 정리
